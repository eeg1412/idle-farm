# 庄园角色与表情设定

四种表情用于同一角色立绘切换，保留站姿、手势、发型、服装、道具和头部角度。高兴与微笑的区别可以只在眼神和脸颊。不高兴表现为失落、嫌弃或无奈，生气则有明确的对象和反应。

`立绘/` 中的原图必须保留从发顶到鞋底的完整全身像；页面素材统一从对应全身原图裁切，保留裁切来源与坐标。
