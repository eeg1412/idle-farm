# 页面背景音乐乐谱

## 来源与范围

用户要求每个页面按其用途使用不同 BGM，大地图保持现有音乐。本文件记录 18 首页面曲；庄园对应 `farm`，原旋律、560 毫秒步进及配器由原播放路径保留，不在新乐谱模块中重写。

18 首曲目的旋律、和声编排、节奏与声部均为本次直接编写的原创数据乐谱，没有引用现成歌曲、录音、采样、外部音乐服务或第三方音源。数据位于 `src/content/page-bgm.js`，由项目 Web Audio 合成器发声；这里的木琴、拨弦、风铃、笛声等描述是波形与包络形成的音色意向，不是对应真实乐器的录音。

整体音乐方向为温暖的日式田园游戏配乐。各曲明确书写 16 小节，不以同一旋律移调形成页面差异。每曲都有主题陈述、变化、展开和收束；最后一小节回到主和弦或保留归回首小节的和声空间。循环长度以 `loopBeats × 60 / bpm` 计算，全部位于 40–80 秒内。

## 数据接口与音量

- `pageTracks` 包含表内 18 个 ID，`farm` 保留给原播放路径。
- 每首输出 `title`、`bpm`、`beatsPerBar`、`loopBeats` 与 `voices`。每个声部输出 `type`、`level`、`attack` 与按起拍排序的 `notes`；音符为 `[beat, MIDI 音高, duration]`。
- `beat` 与 `duration` 以四分音符拍计，`attack` 以秒计。`level` 是音符 gain 包络的峰值，播放引擎随后应用用户音乐音量。
- `pageTrackIds` 显式覆盖 19 个页面名，`trackForPage(page)` 将页面名转换为曲目 ID，未知页面返回 `farm`。
- 每首均有主旋律、和声／分解与低音三个声部。原音乐主旋律峰值为 `0.035`，根音为 `0.025`；新曲主旋律为 `0.020–0.027`，单个伴奏音为 `0.004–0.011`，低音为 `0.009–0.016`。双音伴奏使用更低的单音电平。设置、统计的音符密度和电平低于其他页面。该电平安排按源数据控制叠加，不构成已试听的响度结论。
- 所有背景音乐在音乐总线统一乘 `1.6`（约 +4.08dB），再受玩家音乐音量设置与前后台状态控制；包含大地图原曲。该整体调音来自用户「整体提高BGM的音量」反馈，音效、雨声和对白总线保持原电平。
- 页面切换曲目时新旧曲交叉淡化 1.5 秒：旧曲继续演奏，其独立增益在 1.5 秒内线性降到 0 后停止排音并回收；新曲同时开始演奏，其独立增益在 1.5 秒内由 0 线性升到 1。淡化未完成时再次切换，正在淡入的曲目从当前增益开始淡出，已在淡出的曲目各自按原时间表淡完后回收。首次播放不淡入。关闭音乐、进入后台或音频上下文未运行时，当前曲与全部淡出中的曲目均以 40ms 短淡出立即停止。
- 乐谱在模块加载时一次性展开固定数据，不访问 DOM、真实时钟、随机源或游戏世界，不创建计时器、音频上下文和外部资源请求。页面切换、音乐音量、首次解锁、后台静音和活动节点回收由播放引擎负责。
