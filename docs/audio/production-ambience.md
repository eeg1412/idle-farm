# 生产环境音

| 当前页面 | 启用条件 | 声音 |
| --- | --- | --- |
| 加工 | 至少一个加工位有真实进行中批次 | 与精制共用同一机械加工节律 |
| 精制 | 至少一个精制位有真实进行中批次 | 机械加工节律 |
| 矿洞 | 至少一处矿洞有真实进行中批次 | 固定多名矿工远近错落敲击的预混音 |
| 田地 | 至少一块田地有真实进行中批次 | 低音量、持续不断流的柔和洒水声 |
| 畜牧 | 至少一处畜牧设施有真实进行中批次 | 偶尔响起的牛叫，间隔随机，与在养品种和数量无关 |

进行中批次要求start≤clockMs<end；只选择配方、待料或空置不发声。

生产环境音全局只有一层，同一时刻只有一个场景发声：循环场景为一个循环声源；畜牧为一条输出链上随机触发的短叫声，同时至多2声重叠。机器／设施数量不改变声源数、音量或发声频率。停止生产或离开当前页后停止；同页重绘与弹窗沿用当前场景，相同状态不重启。开屏加载、离线恢复、后台及音效静音时停止，恢复后不补播错过的声音。

切换环境时先结束旧声源，再开始最新场景。加工与精制归一为同一声音及缓存键，互切沿用声音。矿洞将固定数量的错落敲击和短回声写进一个循环缓冲，不为虚拟矿工单独建播放源。畜牧用共振峰合成（谐波声源经元音共振峰塑形）生成牛叫声。每声随机决定音高、体型（共振峰偏移）与长短，至多5个变体，首次需要时才合成，每个调度节拍至多新合成一个。2条独立流（2头牛，各为最短4／5秒加平均10／14秒的指数分布随机间隔）；一声响起后另一头有15%概率在0.1–0.7秒内应和。所有叫声同一电平，不做远近区分；播放速率随机0.9–1.1；同时至多2声，单句峰值上限0.022×该声种电平。气息噪声只作起音处轻微送气（系数0.04，起音后衰减至两成），不得盖过音调。调度只用一个约90ms计时器，合成不发生在点击帧内。随机只用于声音调度，不读取或修改经营随机种子。田地周期噪声经过滤波暖机后循环，不在每轮首尾淡到零；播放开始和停止保留短淡入淡出。

机械和水流各4秒，矿洞10秒；畜牧至多5个牛叫变体。缓存为三份循环加畜牧变体、采样率不超过24kHz、单声道，Float32 PCM合计上限约2,940,000字节（三份循环1,728,000字节＋畜牧5个变体、每个不超过约2.5秒）；畜牧单段峰值上限0.02×该声种电平，不随设施数增加。水流峰值上限0.007且只降不放大；比初版0.026峰值上限至少低11.4dB，降低高频并将强脉动改为轻微起伏。

该声音使用既有音效音量控制，不新增音量设置，不改变默认静音、BGM及音乐增益、雨声、对白与主动操作反馈。自动收获和生产完工仍不触发事件音。声音由Web Audio程序生成预混缓冲，不读取或修改经营随机种子、生产数量、任务统计与存档。
