## 7.2 原料基价

g=代际秒（05物品表第3列，表头“基础秒数”，即式样所称“耗时”；02养殖表“耗时”；≤300）；t=生产周期秒（作物t=g，畜牧t=4g，水产取02养殖表“生产秒”，≤14,400）；out=基础产量（作物2、鱼1、畜牧按表）；σ为行业溢价千分比sectorPremium：C=1000，L=1050，F=1150。

    N(id)=σ×5×g²×(g+127)                       （BigInt）
    代际值 u=N/(1000×20016)                      （单设施1级基础金/秒）
    price=ceilDiv(N×t,1000×20016×out)            （t=durationMs/1000）

g决定“这是第几代品项”，t只决定一批多久；每秒收益只由g与行业决定，长周期不改变每秒收益。作物产量恒为2、单价只随g增长，全线严格递增；同g的支线与主线同价并列；C51—C68按自身g插入同一曲线。畜牧溢价5%、水产溢价15%，C、L、F单价各自严格递增。设施购买/升级三行业相同，不再有κ或牧渔10倍系数，也不再有包络插值、frozenPrices或11/12倍。

验算：C01 N=1000×5×144×139=100,080,000，price=ceilDiv(100,080,000×12,1000×20016×2)=30，u=5。

## 7.3 配方定价

全部437条按拓扑顺序计算，无冻结项。V为输入数量×已生成输入基价之和；t为配方周期秒；N_ref为上游全部原料（递归）中最大的N（7.2，含行业溢价）；m、ω以千分比计：

    price=ceilDiv(m×V×20016000+ω×t×N_ref,1000×20016000)

| 类别 | m（材料加成‰） | ω（工时系数‰） |

| P / PL / PF | 1300 | 750 |

## 7.4 研发生成规则

每项研发id对应其产物品项，按代际值e定价（不再用单线产值U）：原料e=u=N/(1000×20016)（7.2，含行业溢价）；配方e=φ/1000×N_ref/(1000×20016)，N_ref同7.3，φ为类别系数recipeEraFactor（千分比）：

| 类别 | φ（‰） |
| --- | ---: |
| I / IL / IF | 1100 |
| P / PL / PF | 1250 |
| PD | 1500 |
| PT | 2000 |

配方的e取自上游最高代际，配方总是出现在它所用原料的同一时期，避免研发前置倒挂。

    log10 B(e)：在log10(e)上对7.7锚点(e锚点,基准值B)取log10后分段线性插值；两端沿首段/末段外推
    Total0(id)=2×B(e)
    配方封顶：依赖者(y)={x | y∈research[x].requires，x不在7.8覆盖表}
              按requires的逆拓扑序，y为配方且不在覆盖表时 Total(y)=min(Total0(y),依赖者Total的最小值)
              原料节点不封顶：Total=Total0；无依赖者时 Total=Total0
    材料目标值=Total/3；份额=材料目标值/耗材种类数（耗材种类取基准，不增删；Total取封顶后的值）
    capSeconds(e)：对7.7第3列“材料时限秒”在log10(e)上作log10线性插值，区间外取端点值
    数量上限：耗材为原料C/L/F  k=floor((800×Total/300)^(1/6))
                                cap=floor(10×capSeconds×out×M(k)/t)，M(k)=1+k+floor(k²/64)；t为该耗材的生产周期秒，out取该耗材
              耗材为配方产物    j=floor((2000×Total/A_s)^(1/6))，A_s：I类耗材750，P类耗材950
                                cap=floor(4×capSeconds×W(1+j)/t)，W(L)=1+(L−1)+floor((L−1)²/64)；t为该耗材配方周期秒
    qty_i=max(1,min(round(份额/基价_i),cap_i))        基价为品质1价
    coins=round3(Total−Σqty_i×基价_i)，最低10

- round为四舍五入（.5进位）；round3为四舍五入到3位有效数字，结果写成十进制整数字符串。分段幂函数用Math.pow计算，生成结果是数据，确定可复现。六次方根先用Math.pow求近似，再用BigInt校正到k⁶≤x<(k+1)⁶。
- 7.8仅P01一项用覆盖值整体替换coins与costs（种类与前置不变），不再走上式；其余522项全部走上式。
- 运行时recipeDiscount、qualityDiscount、牧渔研究折扣只作用于实物件数，金币照付，规则不变。
- 含义：材料上限按“10条k级设施或4个(1+j)级工位在capSeconds内的产量”封顶，k、j随Total的六次方根增长；capSeconds早段300秒、中段1,200秒、后段14,400秒。上限按out/t折算，长周期品项件数自动变少；时限不足一批时max(1,…)保底1件，实际等待向上取整到整批。早段材料价值约占总价1/3，后段金币约等于总价。同类品种的研发价随e严格递增。
- 若实测材料等待过长或过短，只调7.7第3列，不改结构。

## 7.6 经营效果与实际限制

后续在明确授权后，才使用新价、新科技效果、新品质金币与品质RP、新研发量、工位倍数、原周回重建与24/48/72h离线，评估新档在每日2次、每日1次、每3天1次回访（出售间隔4天）下的三行业原料收入占比、首次出售、RP与科技次序、现金/原料/工位等待、全图鉴进度、重建损失和品质倒挂。LT-v4校准目标（手算首版，非实测，见[实施说明第8节](../reviews/2026-11-16-economy-balance-pass2.md#8-验收指标与模拟校准)）：三行业从第1天起各占原料收入20%—55%；L01/F01/首个复合商品约第8—15/12—25/20—45分钟；首售第1—2天约400RP；C50、L10、F10第60—90天；全图鉴6—9个月；24项科技全满12—18个月。

直接机会增值与全链增值分开；加工/精制/原料设施秒分列。投资回收计金币、耗材现值、库存重估及可持续产量。任务现金与经营收入分账。任何完成天数只能由实际情景证据报告，静态总价、工时或局部函数不能替代整条调用链和可操作体验。

长期内容仍限定于现有科技、品质、设施、工位等级、研究与任务。若重复或深度不足，应如实保留结论，不以不存在的功能或放大数值补证。发现偏差先定位价格/行业溢价/RP系数/科技效果/设施费/工位费/品质取整/研发锚点或材料时限/任务流入，版本化调整明确参数，不暗改研发量或加日期锁。
