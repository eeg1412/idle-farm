# 畜牧、水产及专用中间产物

[返回目录](README.md) · [目录输入](05-catalog.md) · [统一定价与批量](07-balance-validation.md)

本页定义 30 种畜牧对象、30 种鱼、60 个原产物与 60 条专用加工配方。养殖对象由研发解锁，表中原产物才进入仓库。每种对象固定对应一种原产物；动物和亲鱼留在对应设施，按设施的当前生产周期重复产出。游戏中的鱼塘统一表示可配置的养殖设施，淡水、咸淡水和海水品种共用鱼塘设施规则。

鱼塘按河／海养殖展示使用两套固定背景。每个鱼种交鱼苗、成长、成熟三期独立 idle，按显式游戏体型配置显示小型三只、中型两只、大型一只；成熟淡出后下一周期鱼苗淡入。展示不设保底，跟随真实批次时长分三档：≥4秒三期完整，3–4秒只播鱼苗与成熟，不足3秒只常显成熟鱼。场景分为背景、鱼体、水色半透明遮罩、动态水波四层；水色和波纹按各背景真实水域裁切。真实生产由生成目录、设施等级与科技决定，不因展示只数或展示档位增加收成。完整资源与时序实现见[鱼塘动画开发规范](../development.md#鱼塘动画)。

### 鱼塘背景分类

| 展示养殖环境 | ID／鱼种 |
| --- | --- |
| 河水鱼塘 `river` | F01 鲫鱼、F02 鲤鱼、F04 虹鳟、F05 鳜鱼、F07 鳗鱼、F10 鲟鱼、F11–F20 |
| 海水鱼塘 `sea` | F03 花鲈、F06 银鲑、F08 真鲷、F09 大菱鲆、F21–F30 |

这是本项目的养殖展示选择，不是物种只能在一种水域出现的判断。花鲈支持海淡水养殖，本项目采用海水场景；农业农村部记录了其海水繁育及海淡水养殖用途。[农业农村部花鲈资料](https://yyj.moa.gov.cn/kjzl/201904/t20190428_6228539.htm)

银鲑采用海水成鱼养殖场景；鳗鱼采用内陆池塘养成场景。两者的生活史和养殖方式不能简化成绝对淡水／海水属性，游戏三期仍是展示抽象，不新增迁塘或盐度经营。[FAO 银鲑养殖资料](https://www.fao.org/fishery/docs/DOCUMENT/aquaculture/CulturedSpecies/file/en/en_cohosalmon.htm)、[FAO 鳗鱼养殖资料](https://www.fao.org/fishery/docs/CDrom/aquaculture/I1129m/file/en/en_japaneseeel.htm)
