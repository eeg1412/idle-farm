# 放置农场 · 农业、畜牧与水产设计式样书

当前经济正式版本为 **LT-2026-11-v10**。运行目录 `src/content/game-data.json` 提供基础批量、生产周期、品质 1 售价及逐项研发价格。第 5 节与第 6 节声明生产、研发的输入，第 7 节定义统一的工时模型。1.14 快照保留发布过的 ID、拓扑及历史经济数据。

## 分类

| 类别 | 原料 | 专属中间产物 | 说明 |
| --- | --- | --- | --- |
| 农业 | C01–C68 | I01–I127 | 农田生长 |
| 畜牧 | L01–L10 | IL01–IL10 | 畜牧场每种动物只对应一种可交易产出 |
| 水产 | F01–F10 | IF01–IF10 | 鱼池每种鱼只对应一种可交易产出 |

单类、双类、三类按**生产配方直接使用的中间产物来源**判定。例如面粉与全蛋液属于双类，加入鲫鱼鱼糜才属于三类。商品生产只消耗中间产物，一级工位按目录基础批量入库（L 级工位的扣料与目录基础批量各乘 W）。三类原料与中间产物可以分别出售。品质为玩家成长等级，商品档次由来源种类和备料量决定。

基础游戏式样记录画布技术栈、存档事务与交互。数值历史依据见各版本设计方案。
