## 分类

| 类别 | 原料 | 专属中间产物 | 说明 |
| --- | --- | --- | --- |
| 农业 | C01–C68 | I01–I127 | 农田生长 |
| 畜牧 | L01–L10 | IL01–IL10 | 畜牧场每种动物只对应一种可交易产出 |
| 水产 | F01–F10 | IF01–IF10 | 鱼池每种鱼只对应一种可交易产出 |

单类、双类、三类按**生产配方直接使用的中间产物来源**判定。例如面粉与全蛋液属于双类，加入鲫鱼鱼糜才属于三类。商品生产只消耗中间产物，每批入库 1 件。三类原料与中间产物可以分别出售。品质为玩家成长等级，商品档次由来源种类和备料量决定。

本式样书的完整目录与研发数值以第 5、6 节为准。前版式样书继续作为共有玩法、画布技术栈、存档与交互的基础规格。与扩展冲突的农业旧数值、周回字段与图鉴总量按本版执行。
