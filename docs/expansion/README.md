## 分类

| 类别 | 原料 | 专属中间产物 | 说明 |
| --- | --- | --- | --- |
| 农业 | C01–C68 | I01–I127 | 农田生长 |
| 畜牧 | L01–L10 | IL01–IL10 | 畜牧场每种动物只对应一种可交易产出 |
| 水产 | F01–F10 | IF01–IF10 | 鱼池每种鱼只对应一种可交易产出 |

单类、双类、三类按**生产配方直接使用的中间产物来源**判定。例如面粉与全蛋液属于双类，加入鲫鱼鱼糜才属于三类。商品生产只消耗中间产物，1级工位每批入库 1 件（L级工位投入×L、产出L件）。三类原料与中间产物可以分别出售。品质为玩家成长等级，商品档次由来源种类和备料量决定。

完整目录、固定生产拓扑与523项研发原值见第5、6节；第5节旧售价与第6节研发金币/数量须经第7节LT-v3算法覆盖后才是运行数值。第1节LT-v3经营与迁移规则优先于前版费用、品质、离线和RP算例。前版继续作为共有画布技术栈、存档事务、交互和未修改玩法的基础，不能用旧数值覆盖LT-v3，也不以式样完成代替实际验收。
