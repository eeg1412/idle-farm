## 分类

| 类别 | 原料 | 专属中间产物 | 说明 |
| --- | --- | --- | --- |
| 农业 | C01–C68 | I01–I127 | 农田生长 |
| 畜牧 | L01–L10 | IL01–IL10 | 养殖场每种动物只对应一种可交易产出 |
| 水产 | F01–F10 | IF01–IF10 | 鱼池每种鱼只对应一种可交易产出 |
| 矿业 | M01–M10 | IM01–IM16 | 矿洞开采；含6种使用现存旧产业备料的交叉加工 |

单类、双类、三类按**生产配方投入追溯得到的实际行业来源并集**判定。例如面粉与全蛋液属于双类，加入鲫鱼鱼糜才属于三类。商品生产只消耗中间产物，一级工位按目录基础批量入库（L 级工位的扣料与目录基础批量各乘 W）。四类原料与中间产物可以分别出售。品质为玩家成长等级，商品档次由来源种类和备料量决定。

基础游戏式样记录画布技术栈、存档事务与交互。数值历史依据见各版本设计方案。


矿业新增10原料、16中间产物、14商品，全部保留旧ID与生产／研发拓扑。IM交叉加工携带所有上游来源；PM商品含矿业且只消耗中间产物，等级按真实来源数登记；旧PD/PT分类语义保持。33项经营改良共1,474级、5,798,060高级点；73任务为16主线、19产业支线、38长期，高级点奖励总额仍40,152。
