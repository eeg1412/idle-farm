# 1. 经营、设施、品质、科技和周回

本页正式经济设计版本为 **LT-2026-11-v3**，替换LT-2026-11-v2的售价、设施、工位、研发、品质金币、增产、代管、RP常数与任务奖励。本版在用户授权范围内新增工坊工位升级与45项任务；不新增货币、按钮类型或流程，不改物品/配方ID、配方输入种类、研发前置、周期、基础产量与出售牧场流程。全部金额和数量用BigInt。经营效果尚未运行验收，静态数量、费用和工作量不能证明完成天数。

## 1.1a 工坊工位等级

工位字段station.level为十进制字符串，新建工位、旧档工位与出售牧场后重建的工位均为'1'。

    每批产出=L件（L=station.level）
    每批投入=配方每种输入数量×L（输入种类不变）
    周期=配方周期（仍受工坊提速、对应加工提速与精制专精影响，与L无关）
    购买：加工位750×25ⁿ，精制位950×25ⁿ；上限48/32
    j=L−1
    升级累计total(L)=A×[j(j+1)(2j+1)/6+floor(j⁶/24000)]，A_I=750，A_P=950
    quote=total(target)−total(current)

| ---: | ---: | ---: | ---: |
| 2 | 750 | 950 | 750 |
| 3 | 3,750 | 4,750 | 3,000 |
| 5 | 22,500 | 28,500 | 12,000 |

| ---: | ---: | ---: |
| 2 | 750 | 950 |

| 4 | 468,750 | 593,750 |
| 5 | 11,718,750 | 14,843,750 |

规则：

1. 升级仍支持+1、+10、+100与最高可升，报价按端点累计差，“最高可升”先倍增上界再二分，以一次交易提交。
2. 升级只改station.level，不改当前批次：开批时已按旧等级扣料，batch.amount与batch.inputs是开批快照，因此升级从下一批起生效。
3. 缺料时等待整批（需求=配方数量×L），不做部分批次；不新增降级按钮。
4. 换配方或清空按batch.inputs原样退回，等级保留。
5. 工位购买与升级不打折，不新增折扣科技；workshopSpeed、加工提速、精制专精仍只影响周期。
6. 出售牧场重建加工、精制各1个空闲工位，level均为'1'。

## 1.2 解锁与独立品质

研发仅依赖逐项列出的前置、金币与材料，不加日期、隐含品类或品质等级锁。研发前置与耗材种类保持[第6节](06-research.md)原明细；523项的金币与耗材数量按[7.4研发生成规则](07-balance-validation.md#74-研发生成规则)由单线产值U分段生成，[7.8研发引导覆盖](07-balance-validation.md#78-研发引导覆盖)的5项除外。材料与金币齐备时一次扣清、立即解锁。研究没有跨轮提交进度或额外计时器。周回清库存、保留已解锁研究。

525项各自从品质1独立成长，无等级上限，须已解锁才能提升。同ID全库存随本ID当前品质统一计价，上游品质不传成品，不记录历史投入价值。仍支持+1、+10、+100和最高可升。基价p、品质q的整金币单价不变：

    P(p,q)=p+floor(12×p×(q−1)/100)+floor(p×max(q−10,0)²/1000)

使用BigInt累计线性溢价后取整，不新增分币余额或显示。LT-v3全部基价≥30，每升1级单价至少+3金币；小麦p30品质1/2/3/4分别30/33/37/40金币。报价仍显示实际差额。

升至q的目标品项自耗2q+1件，额外材料如下（不变）：

| 品质对象 | 额外材料 |
| --- | --- |
| 作物 | q件面粉 |
| 畜牧原料 | q件小麦 |
| 水产原料 | q件面粉 |
| 加工品与商品 | 配方各直接输入数量×q |

品质金币对全部品类使用同一公式（删除cropReferences与L/F另乘10）：

    U_num/U_den=price×output×1000/durationMs        （品项单线产值U的精确有理数；price为基价，output为基础产量，配方output=1）
    Qc(q)=200×[(q−1)q(2q−1)/6+floor((q−1)⁶/24000)]   （Qc(1)=0）
    coins(current→target)=ceilDiv(Qc(target)×U_num,U_den)−ceilDiv(Qc(current)×U_num,U_den)

例：小麦U=30×2×1000/12000=5，品质1→2为200×5=1,000金币；品质1→10累计为200×(285+22)×5=307,000金币，其中9→10本级93,000金币。相同品项需求合并后用原适用折扣；累计端点差保证多级与逐级报价一致，自耗不封顶。累计材料件数O(q²)，按当前价计算的单次自耗机会成本可达O(q³)，不可混称。

当前直接机会增值=成品独立售价−各直接材料当前售价×数量。小麦品质10新价62，面粉品质1为95，磨粉（2小麦→1面粉）机会增值为95−124=−29。独立品质允许这种专业化取舍；材料仍可用于研发/任务，不增加自动停机或动态成品重定价。品质回收同时看耗材机会成本、实际涨价、库存重估及持续产量。

## 1.4 离线、活动与出售牧场

代管L级上限使用整数毫秒（等于720+36×min(L,20)+48×max(L−20,0)分钟）：

    43200000+36×60000×min(L,20)+48×60000×max(L−20,0)

0/20/50级为12/24/48h，替换8/24/36h；B50累计95,600RP已包含总价。在线离线使用相同生产速率、供料和优先级；延长上限不补造断料产量，超限截断与时钟锚点沿用现有推进语义。

每次真实完工按当时独立unitPrice×实际数量记本轮productionValue，并增加内部跨轮整金币T=lifetimeProductionValue。credit=prestigeCredit只是内部精度余额，不是可消费货币：

    activityScale=49，creditPerPoint=500000000
    oldQ=isqrt(49×T)
    T+=deltaT
    credit+=(isqrt(49×T)−oldQ)×(10000+200×事件评估等级)

活动权益（T/credit 及评估倍率）的 RP 仅在原sellFarm确认与原子重置事务中发点；任务 RP 奖励（[1.5](#15-任务金额与迁移)的 8 项）另在任务结算的成功提交事务中直接计入 researchPoints，不经过 T/credit，也不受评估倍率影响：

    researchPoints+=credit//500000000+尚未领取的旧制冻结奖励
    credit%=500000000

评估0级时累计RP≈0.00014×√T：T=1e8/1e12/1e16/1e20分别约1/140/14,000/1,400,000RP。跨轮保留T/credit，评估只影响升级后的完工事件，不重乘历史余额。销售和任务奖金不加活动或T。链上各真实完工可重复计活动，它不是净利润。同事件倍率路径拆轮不改变累计实发加余数；同倍率离线区间可合并权益差。

任意本轮产值均可出售，包括0；活动权益 RP 只在出售领取；任务 RP 仅随任务自动结算在成功提交时到账。两者都不增加园内领取按钮。completedRuns照旧增加，任务照旧在成功提交路径结算。周回保留研发、品质、科技、RP、T/credit、历史统计（含stats.batchSales）和历史任务；清库存/设施及等级/工位及等级/本轮金币与本轮统计，恢复600金币、两块一级小麦田、加工与精制各一个level '1'的空闲工位。原安排/优先级/在制清空，不返还在制投入，购买序号按原规则重置；原重建步骤保持。

## 1.5 任务金额与迁移
