三个类别分别累计额外购买次数；免费起始地不占额外序号。已额外购买n座时，下一座农业参照价为ceilDiv(60×6^n,5^n)，畜牧和水产先乘10，再用各自永久折扣。加工48位、精制32位，购买步骤和每工位每批1件保持。金额和数量用BigInt，升级累计端点先折扣取整再求差。

    k=level−1
    output=baseOutput+k+floor(k²/64)+2×对应增产等级
    x=max(0,k−14)
    S(k)=30×k(k+1)(2k+1)/6+floor(5000×x⁷/(x²+1024))
    total(level)=ceilDiv(factor×S(k)×(10000−discountBP),10000)
    quote=total(target)−total(current)

农业factor=1，畜牧/水产factor=10。农业15→16/16→17/17→18/18→19/19→20分别6754/8298/18633/77904/304439金币；远端保持五次量级。

购买后设施为空，免费安排已解锁对象开始生产并自动续批。换种/换养立即终止未完工旧批次并开始新对象，旧批次无收成；再次选择当前对象保留进度。成功升级立即改当前未完成批次产量，保留起止和成长进度，不提前收成。真实完工按实际数量记生产、任务与活动一次。已开批时刻继续锁定，不因后来速度升级重排。

工坊换配方立即结束旧未完工批次，按现有实际投入明细退回数量，旧批次无产出；缺明细的早期存档不猜测退款。再次选择当前配方保留投入和进度。同刻完工先全部入库，再按优先级派工。原料周期最长5分钟；安排和续批无新增经营费用。

## 1.2 解锁与独立品质

研发仅依赖逐项列出的前置、金币与材料，不加日期、隐含品类或品质等级锁。523项研究coins/costs/requires全部保持1.14现值；材料与金币齐备时一次扣清、立即解锁。研究没有跨轮提交进度或额外计时器。周回清库存、保留已解锁研究；[第6节](06-research.md)仍是全部研究的原始明细。

    P(p,q)=p+floor(12×p×(q−1)/100)+floor(p×max(q−10,0)²/1000)

使用BigInt累计线性溢价后取整，不用每级最低1金步长，不新增分币余额或显示。小麦p3、品质1/2/3/4分别3/3/3/4金币；单级可能零增价，报价必须显示实际差额，不能宣称每级必涨整金。

升至q的目标品项自耗2q+1件，额外材料如下：

| 品质对象 | 额外材料 |
| --- | --- |
| 作物 | q件面粉 |
| 畜牧原料 | q件小麦 |
| 水产原料 | q件面粉 |
| 加工品与商品 | 配方各直接输入数量×q |

作物及各I/P类金币为(20+4×本品新基价)×q²；L/F为对应农业锚点品质金币的10倍，cropReferences不变。相同品项需求合并后用原适用折扣；累计端点差保证多级与逐级报价一致，自耗不封顶。累计材料件数O(q²)，按当前价计算的单次自耗机会成本可达O(q³)，不可混称。

当前直接机会增值=成品独立售价−各直接材料当前售价×数量。小麦品质10新价6，面粉品质1仍10，磨粉机会增值为−2。独立品质允许这种专业化取舍；材料仍可用于研发/任务，不增加自动停机或动态成品重定价。品质回收同时看耗材机会成本、实际涨价、库存重估及持续产量；零涨价等级不能假报有限现金回本期。

## 1.4 离线、活动与出售牧场

代管L级上限使用整数毫秒：

    8×3600000+24×60000×min(L,40)+72×60000×max(L−40,0)

0/40/50级为8/24/36h，B50累计95,600RP已包含总价。在线离线使用相同生产速率、供料和优先级；延长上限不补造断料产量，超限截断与时钟锚点沿用现有推进语义。

每次真实完工按当时独立unitPrice×实际数量记本轮productionValue，并增加内部跨轮整金币T=lifetimeProductionValue。credit=prestigeCredit只是内部精度余额，不是可消费货币：

    oldQ=isqrt(30000000×T)
    T+=deltaT
    credit+=(isqrt(30000000×T)−oldQ)×(10000+200×事件评估等级)

仅在原sellFarm确认与原子重置事务中发点：

    researchPoints+=credit//10000000+尚未领取的旧制冻结奖励
    credit%=10000000

跨轮保留T/credit，评估只影响升级后的完工事件，不重乘历史余额。销售和任务奖金不加活动或T。链上各真实完工可重复计活动，它不是净利润。同事件倍率路径拆轮不改变累计实发加余数；同倍率离线区间可合并权益差。3000活动对应300基础RP仅是首笔出售算例，不是领取门槛。

任意本轮产值均可出售，包括0；RP只在出售领取，不增加园内领取按钮。completedRuns照旧增加，任务照旧在成功提交路径结算。周回保留研发、品质、科技、RP、T/credit和历史任务；清库存/设施/本轮金币及统计，恢复60金币、两块一级小麦田、加工与精制各一个空闲工位。原安排/优先级/在制清空，不返还在制投入，购买序号按原规则重置；原重建步骤保持。
