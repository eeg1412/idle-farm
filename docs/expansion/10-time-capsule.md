# 10. 时空胶囊

时空胶囊是独立记账的账号资源，用于让一类生产建筑整体快进一段时间。本节定义来源、持有上限、使用规则、界面与存档。数值依据见 [§10.8](#108-数值依据)。

## 10.1 记账与持有

| 项目 | 规格 |
| --- | --- |
| 记账 | `world.capsules`，非负 BigInt，存档写十进制字符串；与金币一样独立记账，不是目录物品 |
| 持有上限 | 144,000 个（折合快进 24 小时） |
| 超出上限 | 任何来源入账后超过上限的部分作废；入账反馈显示实际入账数量 |
| 出售庄园 | 保留，不清零 |
| 不参与 | 仓库出售、送礼、订单候选、图鉴、库存估值、行情、品质、科技费用 |
| 图标 | `wiki/icons/time-capsule.webp`（素材键 `time-capsule`，见[图标任务卡](../tasks/2026-11-22-time-capsule-icon.md)），经 `assetUrl` 取址并纳入 `runtimeAssetPaths()` |

## 10.2 换算与单次上限

| 项目 | 规格 |
| --- | --- |
| 换算 | 100 个 = 该类建筑全体快进 1 分钟（1 个 = 0.6 秒） |
| 使用单位 | 建筑类别：田地、畜牧、鱼塘、矿洞、加工、精制，各自独立使用 |
| 单次上限 | 12,000 个（2 小时） |
| 步进 | 100 个（1 分钟） |
| 使用次数 | 不限次数，可连续使用 |

## 10.3 快进规则

1. 快进只推进所选类别全部已安排配方的槽位；世界时钟不前进。不换日，不推进订单尝试计时、行情、普通研发点、行脚商、管理员日历与代管时长。
2. 田地、畜牧、鱼塘、矿洞不消耗材料，各槽位互不影响，按完成批数直接结算，计算量与快进时长无关。
3. 加工、精制按事件先后逐批推进，重新开工沿用正常经营的同一套规则：工位顺序、保留量、行脚商预留、`availableToProduce` 取料与工位倍率。同类工位之间的产物在快进期间可以作为后续工位的材料。
4. 快进产出按真实生产结算：入库、`stats.produced`、生产总值与活动权益贡献、任务进度、订单候选登记与首单触发、`merchant.produced`、图鉴解锁沿用 `deposit` 现有路径。扣除胶囊、生产结算与 `settleTaskRewards` 在同一事务提交。
5. 设施等级、工位等级与科技速率取快进开始时的值；快进期间不发生升级。
6. 作物 `facility.planting` 与各类动画按快进后的批次起点与进度刷新；被跳过的批次不补播动画，不显示占位或回退图。
7. **按停工截断**：加工、精制在快进区间内全部停工（缺料或无配方）后不再推进。可选上限截至全部停工的时刻，超出部分不能选择，不扣胶囊。
8. **计算量保护**：快进前预估事件数（批次完成次数之和），超过 50,000 时把可选最大时长压到不超过该事件数的整分钟。该阈值在原型实测后定稿（待确认）。

## 10.4 使用界面

- 田地、畜牧、鱼塘、矿洞、加工、精制页的固定底栏：在购买／增设按钮左侧增加「加速」按钮。所选类别没有已安排配方的槽位、胶囊为 0，或预估完成 0 批时禁用。
- 点「加速」打开选择弹窗：
  - 数量用步进与快捷按钮选择，**不使用进度条**：「−」「＋」每次 100 个；快捷按钮「1 分钟」「10 分钟」「1 小时」「最大」。
  - 「最大」= min(持有数量, 12,000, 按停工截断的上限, 按计算量保护的上限)，按 100 取整。
  - 显示：快进时长、消耗胶囊、预计完成批数。确认后执行，成功浮字「已快进 X 分钟」。
- **只有时空胶囊的数量选择采用步进与快捷时间按钮；其余数量选择（出售、送礼等）仍使用进度条。**
- 大地图顶栏：金币显示右侧新增胶囊数量（图标 + 数字，按[数字显示规则](../ui/numbers.md)缩写）；金币显示宽度相应缩短，两者在 320 逻辑像素竖屏下不重叠、不截断。

## 10.5 管理员与行脚商回礼掉落

行脚商为 12 个管理员岗位之一，适用同一规则。

**触发条件**（每岗每天最多一次）：

- 当天该岗位的好感已达每日上限后继续送礼；
- 当天超出上限部分的礼物货值（`value − affinityCharge` 的当日合计）≥ 当天计入好感的礼物货值（`affinityCharge` 的当日合计）的 20%。

**结算**：换日（`synchronizeManagerCalendar` 进入新的一天）时，对满足条件的岗位按该岗位当时的好感等级，在下表区间内抽取整数数量（含两端），用 `accountRandom(accountSeed, 'manager-capsule:<id>:<day>', completedRuns)` 固定结果。数量并入该岗位可领回礼，与回礼物品一同领取；仅有胶囊时也可领取并点亮回礼提醒。

| 好感等级 | 每岗每天（个） | 折合快进 |
| --- | --- | --- |
| 0 | 0–100 | 0–1 分钟 |
| 1 | 0–200 | 0–2 分钟 |
| 2 | 50–300 | 0.5–3 分钟 |
| 3 | 150–450 | 1.5–4.5 分钟 |
| 4 | 250–600 | 2.5–6 分钟 |
| 5 | 400–850 | 4–8.5 分钟 |
| 6 | 600–1,100 | 6–11 分钟 |
| 7 | 800–1,400 | 8–14 分钟 |
| 8 | 1,100–1,800 | 11–18 分钟 |
| 9 | 1,400–2,200 | 14–22 分钟 |
| 10 | 1,800–2,700 | 18–27 分钟 |

12 岗位全部 10 级时，每天期望 27,000 个、最多 32,400 个（约 4.5–5.4 小时单类快进）。回礼物品、回礼率、送礼额度与好感规则不变。

## 10.7 存档与迁移

| 字段 | 说明 |
| --- | --- |
| `capsules` | 持有数量；读档校验 0 ≤ 值 ≤ 144,000 |
| `managers.roles.<id>.capsuleCharged` | 当日计入好感的礼物货值合计；换日清零 |
| `managers.roles.<id>.capsuleOverflow` | 当日超出上限的礼物货值合计；换日清零 |
| `managers.roles.<id>.readyCapsules` | 待领胶囊；领取清零，出售庄园保留；校验 ≤ 2,700 |

- 旧档缺字段按 0 读取，不升 `schemaVersion`；新增校验与回归测试同步。
- 更新前已领取回执的任务是否补发胶囊：**待确认**（缺用户决定；默认实现前须确认）。

## 10.8 数值依据

- 100 个 = 1 分钟：回礼区间可按 50～100 个的粒度错开，低等级不必挤在个位数。
- 单次 2 小时：按停工截断与计算量保护共同约束；田地类为常数计算，加工、精制最坏约 20 工位 × 5.6 秒一批 × 2 小时 ≈ 2.6 万事件。
- 持有上限 24 小时：满级每天最多 32,400 个，4～5 天不用即满；高于单笔最大任务奖励 24,000；等于 12 次单次上限。
- 定位：代管时长科技提供全部建筑 6–72 小时离线生产，胶囊为定点补短板，日收入上限约为单类 5 小时。
- 产出计入生产总值并影响出售庄园的高级研发点；胶囊总量受任务一次性发放与回礼日上限约束。
- 已知风险：6 级以上回礼率超过 100%，超上限送礼本身可循环放大；用户决定本次不处理。

## 10.9 开发测试模式

[开发测试模式](../development.md#开发测试模式)触发时，在现有发放之外把胶囊设为持有上限 144,000，经同一保存事务提交；不伪造生产或统计。`vite build` 产物移除触发器与发放模块的规则不变。
