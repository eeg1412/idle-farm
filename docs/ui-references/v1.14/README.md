# v1.14 游戏界面参考图

[游戏式样书](../../expansion/README.md) · [交互与反馈](../../ui.md) · [数字显示](../../ui/numbers.md)

下图是 v1.14 早期历史绘制稿，各屏为独立档案状态。图注记录稿件所示的导航、交互和数值。现行页面与入口见[逐页交互规格](../../ui.md)。

## 田地、畜牧与鱼池

| 界面 | 参考图 | 状态和操作 |
| --- | --- | --- |
| 田地首页 | [01-fields.png](01-fields.png) | 购地、空地播种、已种地块换种和升级。4 级小麦地每批收成 5 份 |
| 畜牧 | [01b-livestock.png](01b-livestock.png) | 购买畜牧场、安排养殖、更换和升级。1 级蛋鸡场每批产出 1 份鸡蛋，基础周期 24 秒 |
| 鱼池 | [01c-fish-pond.png](01c-fish-pond.png) | 购买鱼池、安排养殖、更换和升级。1 级鲫鱼池每批产出 1 份鲫鱼，基础周期 28 秒 |
| 畜牧场升级 | [01d-upgrade.png](01d-upgrade.png) | 等级 1 → 2，每批鸡蛋 1 → 2，金币 1,280 / 300 |

购买畜牧场或鱼池打开购买 Dialog。无折扣时首座各 600 金币，第二座各 720 金币。升级 Dialog 列出目标等级、下一批产量和持有／所需金币。一级升二级各 300 金币，基础批产由 1 增至 2。更换打开品种选择 Dialog，当前批次按原对象完成，下一批使用新对象。田地、畜牧、鱼池均自动续批。

## 工坊与仓库

| 界面 | 参考图 | 状态和操作 |
| --- | --- | --- |
| 工坊 · 精制 | [02-workshop.png](02-workshop.png) | 双类商品鲫鱼蛋羹封口杯正在待料。鲫鱼鱼糜 2 / 3、全蛋液 24 / 3、浓缩牛乳 16 / 3。每批 1 件，基础耗时 3 分钟 |
| 仓库 · 出售鲫鱼 | [03-warehouse.png](03-warehouse.png) | 20% 滑条示例。库存 100.25M、单价 210、出售数量 20.05M、预计得款 4.21B |

工坊可按农业、畜牧、水产筛选。复合商品命中任一包含来源。更换配方在生产中和待料时均可用。持有／所需逐项显示，点击「查看来源」定位相应品项。仓库中确认出售后，在点击位置浮出本次所得金币。库存及金额示例为缩写显示，成交按精确整数结算。

## 研究

| 界面 | 参考图 | 状态和操作 |
| --- | --- | --- |
| 品质提升 | [04-research.png](04-research.png) | 鲫鱼品质 1 → 2，单价 210 → 235。无折扣需鲫鱼 5、面粉 2、金币 1,600。高级研发点独立一行 |
| 品种与配方 | [04b-research-instant.png](04b-research-instant.png) | 蛋鸡研发可用。需小麦 6、金币 260。点击研发立即解锁 |
| 经营改良 | [04c-efficiency.png](04c-efficiency.png) | 鱼池议价 0 → 1 级消耗 1 点。首座鱼池价格 600 → 540。水产周期改良需鱼群培育 5 级和已研发鳜鱼 |

研发成功显示短 Toast。品质成功后在点击处浮出简短提示。资料与余额使用「持有 / 所需」，右侧金额预留字母后缀宽度。高级科技未满足前置时逐项列出条件。
