# 生产页面的单层环境音

## 用户要求与范围

用户要求：加工或精制有机器运转时增加机器声，「只用一层音效，别机器越多音效越多」；畜牧增加动物声，矿洞增加挖矿的叮叮声，田地增加洒水声。

按当前页面播放对应生产环境音；加工、精制、田地、矿洞只在对应类别有真实进行中批次时启用。畜牧音效已按R4用户要求取消。选了配方但尚未开批不计运行。离开该页、停止生产、开屏加载、离线恢复／busy、后台或音效静音时停止。环境音受原有音效音量控制，默认静音、BGM、雨声、对白和主动操作音保留。此需求不恢复自动收获／完工事件音，也不改变生产、统计或存档。

全局同时最多一个实际播放的生产环境音源；不按设施数量建声源、加音量或提高播放频率。其他页面不播放这些生产声。
