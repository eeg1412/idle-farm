三项独立工作使用新上下文。新背景为 320×320，蜂图集为四帧横排，每帧 64×64，蚕使用原有独立图集与桑叶。产品图复用各自 96×96 仓库图。静态资料图沿用同 ID 详情入口。动物放置、轨迹及产物停留为本轮表现实现参数。用户确认本轮仅做实装和静态审图。

## 接入与审阅

- 极小牲畜配置由 `src/content/tiny-livestock.json` 定义。畜牧卡片复用现有纹理缓存、资产清单和可见性挂载，详情使用专用场景图。
- 前台同槽同种的实际批次完工后，产物停留取 2 秒与前批时长三分之一的较小值，末段淡出。可由逐槽开批时点和真实产出增量证明的胶囊完工也使用这段展示；离线完工没有补播。换养、清空或会话重置清理该槽的产物提示。
- [静态审图](../art-reviews/2026-11-28-tiny-livestock.md)覆盖两幅原画、发布背景和详情、飞蜂四帧及 130 像素合成示例。资源检查规则已接入新路径。
- 按本轮授权完成代码和静态审图。资源检查、构建、浏览器实播和方向切换未验证。

## 六只与蚕架铺叶

用户反馈家蚕过大，要求极小牲畜每种显示六只。两层蚕架的托盘表面均铺满桑叶，缩小后的家蚕每层三只。中华蜜蜂在蜂箱周围显示六只。完工产物、经营结算、其他畜牧布局和选择图沿用各自现有路径。

本次延续同一素材与审阅目标，复用 tiny_art 和 tiny_review 的上下文。运行配置所有权由已结束的 tiny_runtime 转交 tiny_art，历史场景、当前源图及导出文件由素材所有者负责。根代理维护式样、反馈、资源检查规则和审图报告。验收使用 320 与 130 像素静态合成，核对数量、桑叶覆盖、托盘落位、版式与产物位置。游戏预览、测试、资源检查和构建无本次授权。

六只与铺叶版已接入。两种动物的资料图与活动动画共用运行布局，家蚕线性尺度为 0.16～0.21。320 与 130 像素静态审图通过，真实画布动画、资源检查与构建未运行。
