# 挑战订单冷却倒计时与加速

## 用户确认的需求

- 放弃已接受的挑战订单后 2 小时内不生成新挑战订单（现行规则不变）。
- 订单中心显示冷却倒计时，并允许用时空胶囊加速。

## 式样

- 显示条件：`orders.challengeHoldUntilMs` 大于当前 `clockMs`，且当前没有挑战订单。订单中心在订单与占位卡之后显示一张冷却卡：标题「挑战订单暂停中」，内容为到 `challengeHoldUntilMs` 的倒计时（沿用现有逐帧倒计时，不按时钟重建），附「加速」按钮（样式同检查点加速按钮：胶囊图标 + 数量）。
- 加速费用：剩余冷却每开始的 1 分钟 100 个时空胶囊（与检查点加速同价），`ceil((challengeHoldUntilMs − clockMs) / 60000) × 100`。胶囊不足时按钮禁用，原因「时空胶囊不够」。
- 点击加速后弹确认（文案沿用检查点加速确认的写法：消耗 x 个时空胶囊…），确认后提交新动作。动作在同一事务内：扣胶囊；`challengeHoldUntilMs` 置为 `null`；若此刻满足挑战条件则立即按现行规则生成一张挑战订单。下一个定时检查点时刻 `nextAttemptMs` 不变。世界时钟、生产与换日不动。
- 失败（无冷却、已有挑战订单、胶囊不足、报价变化）不改任何状态。确认时按当前状态重算费用，与弹窗报价不同则拒绝。
- 冷却自然结束后，仍在之后的定时检查点按现行规则生成挑战订单。
- 存档字段不变。
