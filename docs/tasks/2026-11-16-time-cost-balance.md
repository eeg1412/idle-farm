用户已明确删除代际及行业售价溢价，按自身周期与逐层摊入所耗材料工时定批总价，统一乘十并除基础批量。基础批量按配方耗用件数自动重算。品质与单品产量用高级研发点，品质额外付金币，首级费用 1 点，品质每级价差为 1 加基价的 10% 四舍五入。保留设施增产算法及条件，取消普通研发点，取消主线品质任务，保留六项长期品质任务。本次强制新档。经营改良按类型换行。

独立审查首轮退回任务奖励、交接门槛和长线判据。作者修正后，二审复算 525 项物品、437 条生产配方、523 个研发报价，核对 66 项任务、40,152 高级点任务上限及存档和活动批次接口，定稿通过。价格与本轮生产改动仍须按规范运行验证。

实施后 `npm run balance:check` 通过。最慢单批 P169 为 15,246 秒，在线与离线实际结算一致。共同窗口 2,604 秒，小麦、面粉、面包毛产值为 13,020／24,552／33,264 金，保有余料。每日两次、每日一次和每三日一次均进入三行业正净现金循环；首科技为第 4／4／12 天。每日一次路线第 164 天完整图鉴，第 416 天从同一存档合法支付六项长期品质目标与全部 1,050 级经营改良。模拟不等同于玩家实盘耗时。

修复 L08、L09、L10 三组原画脚位注册后，全素材检查通过。保存与画布回归通过。托管预览 relay 不可用，部署前用户路径由画布输入和存档自动化用例覆盖。
