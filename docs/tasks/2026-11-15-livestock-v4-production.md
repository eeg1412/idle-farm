## 冻结的跨任务接口

素材代理生成 `src/content/livestock-visuals.json`，每个 ID 保留 `stages`、`slaughter`，新增 `grounding` 数组，与阶段数量一一对应：

```json
{
  "x": 138,
  "y": 270,
  "radiusX": 50,
  "radiusY": 10
}
```

上例半径仅说明格式，实际按物种／阶段的固定脚印登记，需为正数；同阶段四个 idle 帧不能变化。程序在 `(x,y+3)` 绘制，透明度乘动物透明度。`atlas.json` 记录每帧稳定脚点、共同 `stageScale` 与 `anchorMethod`，保持可追溯。

原画与程序任务可按冻结接口并行。资源检查在源数据实际输出后接入；PM 收齐后查看源图、帧分镜、静态回退与阴影调用路径，再执行最终构建。本次不重复请求已经获得的风格与全量绘制授权。
