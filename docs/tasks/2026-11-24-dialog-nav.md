## 用户原要求

还没研发任何牲畜时，点空养殖场「安排养殖」打开「选择牲畜」弹窗，写着「研发对应品种后即可安排。」，下方金色按钮「前往研究」点了却回到畜棚。修复，并找到所有类似问题一并修复。

## 根因（PM 审计）

按钮先 `close()` 再 `go()`。`close()` 经 `returnToRecordedParent()` 调用 `navigation.backTo()`，触发 `history.back()` 并进入 `returning` 状态；随后的 `go()` 因 `navigation.returning` 直接返回，最终只完成关闭弹窗、回到原页。`go()` 本身会关闭当前弹窗（`activateDialog(undefined)`）并把来源弹窗记为返回上下文，无需先关闭。

同类位置（均在 `src/view/production-pages.js`）：

1. 批量更换弹窗无可选品种／配方时的「前往研究」（`dlg.close(); dlg.go('研究', …)`）。
2. 设施「选择品种／牲畜／鱼／矿」弹窗无已研发品种时的「前往研究」。
3. 工位选择配方弹窗无已研发配方时的「前往研究」。
4. `sourceButton`「查看来源 · 物品」（`ui.close(); ui.go('图鉴', { id })`），用于工位缺料行与「查看材料来源」弹窗。

已排除：出售庄园成功后的 `panel.close(); panel.go('庄园')`——`sellFarm` 成功时 `resetSession()` 已回到庄园首页，行为正确，不改。其余 `go()` 调用前无 `close()`。
