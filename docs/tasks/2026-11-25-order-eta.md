# 已接受订单的预计完成时间

## 用户确认的需求

- 未接受的订单继续显示「标准完成时间」；已接受的订单不显示标准完成时间，改为在「当前产能」下方显示「预计完成时间」。卡片与订单详情都按此规则；缩小视图不显示。
- 计算只看该商品此刻正在运行的产线（设施或工位有进行中的批次）；停着等料的工位不计入。
- 进行中的批次在其结束时刻到账该批锁定的件数；之后每隔该配方当前周期到账一批，件数按当前等级的每批产量，不检查后续原料是否足够。
- 从「库存 − 行脚商预留」开始累加，第一次达到订单件数的时刻为完成时刻。
- 显示：
  - 库存已够：「订单完成」，绿色。
  - 未研发、未安排生产或没有正在运行的产线：「无法计算」，红色。
  - 其余：剩余时长，格式与订单页现有倒计时相同（`remainingTime`：一小时以上「3 小时 20 分」，不足一小时「20 分 5 秒」），随时钟每秒倒数。
- 同一商品的多张订单各自按当前库存计算；一张交付后库存减少，其余订单的时间随之变长。
- 后续批次缺料与离线超过代管时长不计入，实际完成可能晚于显示。

商品（P 类）不是任何配方的原料（目录核对：313 个商品类品项均未出现在 inputs 中），因此不计下游消耗。

## 冻结接口

`src/game/world.js` 新增导出：

```js
orderCompletion(world, order) →
  { status: 'ready' }                 // 库存 − 行脚商预留 ≥ order.count
  | { status: 'unknown' }             // 未研发、无运行中产线
  | { status: 'scheduled', atMs }     // atMs：世界时钟毫秒（与 world.clockMs 同一时基），安全整数
```
