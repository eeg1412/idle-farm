# 订单奖励提示与任务奖励一致

## 用户确认的需求

- 订单交付成功的奖励提示改为与任务奖励相同的 Toast 形式，奖励以「图标＋数量」显示。

PM 解释：
- 手动交付与「立即交付」成功时，不再显示飘字「已交付 +X 金币 +Y 研发点」，改为 Toast：「已交付 · 订单奖励 [金币图标]X [普通研发点图标]Y [时空胶囊图标]Z」，胶囊只在本次实际入账（挑战首次完成）时出现；数量为 0 的项不显示。成功音效不变。
- 同一次交付也完成任务时，订单奖励与任务奖励在同一个 Toast 中依次显示（「已交付 · 订单奖励 … · 任务奖励 …」），不互相覆盖。
- 任务奖励 Toast 的现有样式与其他 Toast 不变。
