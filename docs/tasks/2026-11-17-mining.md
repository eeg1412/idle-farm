# 矿业完整接入任务卡

## 需求、授权与冻结接口

- 需求：牧场新增「矿洞」页签，设施卡与田地一致；10 原料、16 加工、14 商品按用户确认表接入。生产、研发、品质、经营改良、任务、仓库、图鉴、行情、离线、存档与相关文档一起覆盖。
- 用户确认：满载车在完工前 2 秒开始出洞、完工时到站；矿图标 300ms 淡出，停留 1 秒，空车 2 秒入洞；展示最低 5.3 秒，与真实经营结算分离。首次空车 2 秒入洞。矿图标在车斗上方独立层，仓库 canonical 图标复用。
- 背景含矿洞和轨道，车体是独立透明层。像素原画必须内置 image_gen，提示词逐件给 ID 与原料/商品名字，不能程序画替代。原稿、PNG、WebP、提示词和裁切登记保留。原有动画无回退规则沿用。
- 后续反馈修订：洞口原画层置于矿车及货载下方。320px 场景在车斗、轮组经过的高度登记内缘 x=28–108，矿车贴轨经过该区间时按自身可见左缘渐隐，满载沿同一段轨道渐显。装卸相位沿用用户确认的时长。
- 原料 M01–M10，二级 IM01–IM16，三级 PM01–PM14；source 为「矿业」，facility kind 为 M，工坊仍共用 I/P 工位。旧 ID、旧配方及研发拓扑不改。
- 新品生成后的无科技 durationMs 与全目录任一不同品项绝对差必须 >10000ms，含新品互比；仅固定 525 既有项彼此配对豁免。不能按类别豁免、不能把现有品新加入豁免。
- 7 项矿业经营改良对齐水产，各 50 级；总 33 项、1474 级、5798060 高级点。高阶开采周期要求矿产增产20级和 M05，精制专精要求矿业加工20级和 PM01。其他费率/效果同水产，通用叠加速率仍至多2.5倍。
- 品质沿用全局随机抽取，每抽100普通点，新研发品进入池。旧档新增 M 设施空数组、矿业科技0级；保留旧库存、批次快照、权益、随机序号、领取回执。矿洞无免费初始设施，费率/上限同畜牧水产。
- 已授权：实现、读取、内容生成、素材生成转换；子代理合成关键帧并实际看图，失败返工。其余测试/内容经济美术检查/浏览器验收另行询问中，未答前不执行。最终编译仅 PM。当前推送及发布授权：无。
