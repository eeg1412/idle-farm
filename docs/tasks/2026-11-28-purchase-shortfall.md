# 增加产线金币不足时显示差额

## 用户确认的需求

- 增加产线（购置设施、增购料坊位／工房位）的按钮在金币不足时，提示文字写明还差多少金币，不只是「金币还不够」。

## 式样

- 适用范围：田地、养殖场、鱼塘、矿洞的购置按钮，料坊位、工房位的增购按钮，以及这些购置的确认弹窗中的确认按钮。
- 金币不足时禁用原因为「金币还差 X」，X = 购置费用 − 当前金币，按现有 `compact` 显示。达到上限仍为「已经建满了」。
- 不改升级、研发、行脚商等其他按钮的提示（局部反馈，不推导为全局规则）。
