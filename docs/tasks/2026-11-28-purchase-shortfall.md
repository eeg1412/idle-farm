# 增加产线金币不足时显示差额

## 用户确认的需求

- 增加产线（购置设施、增购料坊位／工房位）的按钮在金币不足时，提示文字写明还差多少金币，不只是「金币还不够」。
- 用户追加：凡是因金币不足而禁用、显示「金币还不够」或「金币不足」的地方，都改为显示差额。

## 式样

- 适用范围：
  - 田地、养殖场、鱼塘、矿洞的购置按钮，料坊位、工房位的增购按钮，以及这些购置的确认弹窗中的确认按钮。
  - 设施与工位的升级按钮（卡片、缩小视图卡片、详情弹窗）、升级确认弹窗的确认按钮、批量管理的「升级」按钮与批量升级确认按钮。
  - 研究页配方研发按钮。
  - 行脚商买入确认按钮的禁用原因，以及货架卡片在金币连 1 件都买不起时的说明。
- 金币不足时显示「金币还差 X」，X = 该操作的金币费用 − 当前金币，按现有 `compact` 显示。行脚商货架卡片的费用为买 1 件的单价。
- 费用或金币不是 BigInt、或差额不大于 0 时，显示原文案（「金币还不够」，货架卡片为「金币不足」）。
- 保持不变：达到上限的「已经建满了」；批量管理未勾选时的「先勾选要处理的…」；研发按钮的前置与材料原因；行脚商数量弹窗已显示差额的「金币不足，还差 X 金币。」说明。
- 管理员台词与指导文案（`src/view/manager-help-text.js` 等角色对白）不在本次范围。
