# 订单与产线界面优化

## 用户确认的需求

1. 立即交付：未接受且可交付（库存扣行脚商预留后 ≥ 件数）的订单，「接受」按钮替换为「立即交付」，位置不变、不新增按钮、卡片高度不变；文字按按钮通用字号缩放规则适配。一次操作内完成接受与交付。库存不足时仍显示「接受」。挑战订单同时至多一张，与其他订单同样处理。
2. 订单产线标签：生产已接受订单商品的产线，以及这些商品的全部上游原料产线（传递追溯至作物、牲畜、鱼、矿），在田地、畜牧、鱼塘、矿洞、加工、精制的产线卡片上显示「订单」标签。
3. 飘字提示（点击触发的 float，例如「+金币」「已升级」、按钮不可用原因）默认显示在画布中央，不拦截下层点击；点击位置落在中央文字区域（上下各留余量）内时，改为在点击处上方显示（现行方式）。鼠标与触控同规则。Toast 不变。
4. 产出飘字：产线一批完工入库时，在倒计时区域上方显示「产物图标 + 数量」，上飘并淡出。只在该产线当前可见时显示；离线、后台期间完成的不补播；短时间内连续完成多批合并为一个总数。产线卡片与产线详情弹窗都显示。
5. 产线详情弹窗新增产物当前库存一行；弹窗内的产出飘字显示在该库存数字上方。

## 差异

- 需求 5「新增产物当前库存一行」：设施详情的「仓库库存」与工位详情的「当前库存」原已存在。本次只为工位库存补单位「件」，并把产出飘字锚定在该库存数字右上方，没有新增行。
- 需求 4「数量」：工位在一批进行中途缺料时，完工件数按时长估算，再以该产物的真实入库增量封顶，显示数量不超过真实入库增量。
- 需求 4「短时间内连续完成多批合并」：合并窗口为同一槽位飘字存续的 900 毫秒；该期间同品项再完工（含时空胶囊快进）累加到同一个数字。
