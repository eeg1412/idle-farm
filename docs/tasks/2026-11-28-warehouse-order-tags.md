# 仓库订单标签与批量管理筛选

## 用户确认的需求

- 仓库品项显示「订单商品」「订单原料」标签。
- 仓库「批量管理」（批量出售面板）的品项也显示相同标签。
- 批量管理增加筛选：全部／订单／非订单。

## 式样

- 判定沿用 `src/game/orders.js` 的 `orderItemTags(world)`：已接受（`locked`）订单的商品为「订单商品」，其配方上游递归全部投入为「订单原料」；同一品项可同时带两个标签。与配方选择弹窗（`production-pages.js` `replacementChoices`）口径一致。
- 仓库列表放大与缩小两种视图都显示标签；样式与配方选择弹窗的订单标签一致或复用现有徽章样式，不新增说明文字。
- 批量管理筛选在面板内，默认「全部」；「订单」只列带任一标签的品项，「非订单」列其余品项。筛选在仓库页现有类型／来源筛选的结果上再过滤。切换筛选时已选项中不在当前列表的取消选择（沿用面板现有行为），「全选」只选当前列表。
- 不改出售数量、报价、保留库存与确认出售流程。
