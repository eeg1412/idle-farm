# 仓库出售按比例成交

## 用户确认的需求

- 仓库出售（单个与批量）在确认前后库存变化时不再失败，按确认时选择的比例与成交时库存成交。
- 预览随库存实时更新（现状），成交后不另加实际得款提示。

## 式样

- 成交时对每个选中品项按 `tradeOffer(world, id, percent)` 以当时库存重算件数与得款并成交。
- 仍拒绝（整批不成交，不改任何状态，沿用现有失败提示与重新确认流程）：
  1. 任一品项当时单价与确认时报价的单价不同；
  2. 任一品项当时将动用的保留库存件数大于确认时报价的件数。
- 重算后件数为 0 的品项跳过；全部为 0 时按失败处理（现状）。
- 不改单价、行情、保留库存语义、统计与行脚商记录（`recordMerchantSales`）。
