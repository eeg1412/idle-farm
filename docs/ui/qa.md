# 界面验收

[UI 索引](../ui.md) · [数字显示](numbers.md)

- 320、390、480 逻辑像素竖屏验证首页、各页签和二级页。文字放大时仍可滚动到确认按钮。横屏两侧黑边不响应点击。
- 从田地、工坊、仓库、研究和任务依次走通首条生产线。倒计时结束自动入库，普通批次无需玩家确认。
- 验证出售 Dialog 的取消、再次确认和双击。取消不扣库存，预览变化时保留百分比，成功只弹一次金币小字。
- 点击高频控件时，小字从该次触点升起。键盘触发从控件中心显示。连续操作、切页、旋转和开启减弱动态时，提示不挡住操作。
- 检查任务页随入门完成自动切换为长期目标。两次出售牧场并重新加载后，累计进度和已完成状态保留。
- 验证出售牧场确认、离线收获和备份恢复均有明确关闭路径。确认结果与实际保存记录一致。

### 超长数字

- 在 320、390、480 逻辑像素与 100%、200% 文字大小下，核对顶部余额、库存列、任务进度、研究持有量和牧场预览。以 `100.25M`、`200.25B`、`300.35T`、`1.23BJ` 覆盖缩写，保持数字、物品名与按钮互不遮挡。
- 完整数超过单行可见宽度时，在数值详情验证分组折行或受控横向滚动能查看全部数字，复制能取得无逗号的原值。验证横竖切换后输入、滚动和确认状态。
- 验证实际金额变化而缩写文本相同的交易仍要求重新确认。负加工增值带负号；库存、交易输入、任务进度及存档都保持整数。
- 逐条使用数字显示文档的定值样例测试格式，至少覆盖单位边界、两位截断、负值、`10^120+9` 和宽度降级。

- 验证出售滑条 0%、50%、100% 和小库存取整。0% 禁用确认，奇数库存向下取整，100% 出售全部。多选逐项计算，报价刷新后保留百分比。
- 研究与牧场出售预览、最终确认在 320 宽和 200% 文字下核对高级研发点独立数字行，数字、图标、单位和按钮互不遮挡。
- 田地卡与详情只提供种植相关操作。换种立即开始新作物的周期，未成熟批次取消。
- 工坊和研究验证「持有 / 所需」及不足标识。以持有 8、所需 10 断言显示 8 / 10。工坊按可投入库存，研究按总库存计算。
- 工位正在生产时，产物库存与在制产量分别显示。以面粉库存 300.35T、本批产出 1 校验；完工后库存增加 1，显示缩写可能保持一致。等待材料时「本批产出」改为「每批产出」，进度条留在原位置且为空，剩余为红字「暂停」，等待原因使用红底白字。
- 验证 15 级及 1,001 级仍可继续升级。测试 +1、+10、+100 与升到可负担等级，批量价与逐级累计一致。
- 对比工坊提速前后。以面粉配方验证耗时从 9 秒减至 7.5 秒时，每批仍投入 2 份小麦、产出 1 份面粉。工位和配方列表只展示固定投入和产出。

- 工坊待料时能换任一已研发同类配方。用原料齐全和仍不足两种新配方分别确认，核对即时开工与新材料行。生产中换配方时，以新配方继续并退回未完旧批次记录的全部投入。完工后自动检查下一批材料。
- 品质费用区显示「升级所需材料」。材料不足时保持关闭和查看来源可用，确认升级禁用。
- 研发点击后当次存档事务即可解锁。在首轮验证后期项目：前置与成本齐备时当次点击即可解锁。
- 出售牧场只展示一个本轮生产总值。620 时确认可用并发 0 点，达到 1,000 时按公式发点。

- 科技树核对纵向真实依赖、共享箭线、移动、缩放、全图、起点与索引。全图覆盖所有节点，移动视口时位置保持稳定。
