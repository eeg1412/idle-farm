# 仓库

[UI 索引](../../ui.md) · [数字显示](../numbers.md) · [反馈规则](../feedback.md)

页头沿用工坊的横幅尺寸和页签样式。横幅下方是滚动时固定的「全部／原料／中间产物／商品」品类页签，再下方是「全部／农业／畜牧／水产」来源筛选。列表连续滚动，只列当前周目获得过的物品。库存清零时保留该行和位置，数量显示「库存 0」。物品行显示图标、名称、数量、品质、单价。详情直接显示完整整数。列表或筛选无结果时显示「库存 0」，本周目尚未获得物品时另显示「前往田地」和「前往工坊」。

售价、得款均为整金币，沿用 `unitPrice` 与 `tradeOffer` 的当前报价。同ID所有库存同价，品质独立，不继承材料价值；全局基价调整直接适用于旧库存。低价品某级品质可能不涨价，仓库如实显示当前整数单价。

| --- | --- | --- |
| 查看产出／支出图表 | 仓库顶部 | 打开每小时产出与支出。立即估算一次，顶部用一行文字与圆形进度提示每 3 秒更新，关闭弹窗后停止 |

| 确认出售 | 预览有效 | 重新校验数量、价格和保留量。成功关闭 Dialog，确认按钮原位置显示「+N 金币」。预览变化时保留 Dialog、刷新报价，并在内文要求再次确认 |

### 每小时产出与支出

按已安排的品种、配方、等级与科技估算连续满负荷运行时的件数。待料工位也按配方计入，便于看出材料缺口。表中支出指工坊配方耗料。每种物品以数值显示产出、支出与带正负号的净变化。比如每小时产出 10 份小麦、工坊耗用 12 份，净变化为 −2 份／小时。

### 数字布局

库存和单价分别右对齐。窄屏时库存和单价放到物品名下一行，保持「出售」完整可点击。出售数量和预计得款分别占一行，允许缩写。出货浮动小字可缩写。

### 百分比出售

- 单品默认 0%，可拖动或点击轨道选取 0% 至 100% 的整数百分比。键盘左右箭头调整 1 个百分点，Home 与 End 跳到两端。百分比取库存总量为基准，包含预留库存。
- 实际出售数量为 `库存快照 × 百分比 // 100`，向下取整；100% 出售全部库存。预计得款用该整数数量乘以当前单价。数量为 0 时禁用确认。仓库不提供多选或跨品项批量出售界面。
- 出售面板用百分比滑条和两行摘要。若库存为 `100.25M` 小麦、基础单价 3，选择 50% 时显示「出售数量 50.12M」「预计得款 150.37M 金币」。底层按 50,125,000 份和 150,375,000 金币处理。
- 确认以当前库存、价格及保留量重新计算。若实际出售数量、预计得款或保留量影响发生变化，保留所选百分比并刷新预览，要求再次确认。取消不改变库存和余额。
