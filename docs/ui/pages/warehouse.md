# 仓库

[UI 索引](../../ui.md) · [数字显示](../numbers.md) · [反馈规则](../feedback.md)

仓库横幅沿用工坊的横幅尺寸，在有库存和空仓时都紧贴顶部导航下方。品类页签在滚动时吸顶，来源筛选在其下方。列表连续滚动，只列当前周目获得过的物品。库存清零时保留该行和位置，数量显示「库存 0」。物品行显示图标、名称、数量、品质和单价。详情直接显示完整整数。列表或筛选无结果时显示「库存 0」。本周目尚未获得物品时，正文继续显示居中的 120×120 透明像素空仓图标，「库存 0」在图标下方水平居中，再下方显示「前往田地」和「前往工坊」操作。

售价与得款以 `marketUnitPrice` 和 `tradeOffer` 显示整金币。相同 ID 的库存按当前品质和当日行情统一成交。涨跌图标和倍率紧随品名，空间不足时换行。上涨为绿，下跌为红。

### 每小时产出与支出

来源筛选增加「矿业」。M归原料、IM归中间产物、PM归商品；来源判定读取真实sources，矿业交叉加工品及其下游同时保留农业、畜牧或水产标签。矿洞开采纳入每小时产出，矿业配方纳入工坊支出；矿产可设置保留量、品质计价和按行情出售，与其余物品使用相同事务。

按已安排的品种、配方、等级与科技估算连续满负荷运行时的件数；工位用目录基础批量及配方投入分别乘当前工位倍率计算，设施用目录基础批量、设施倍率与增产科技倍率计算。每条产线按当前生产周期折算为每小时件数。待料工位也按配方计入，便于看出材料缺口。表中支出指工坊配方耗料。每种物品分别显示产出、支出与净变化，三列都按[图表数字规则](../numbers.md#仓库每小时产出与支出)以整数或无小数的缩写显示。净变化数字为正时显示绿色和 `+`，为负时显示红色和 `−`，绝对值不足 1 件／小时则以默认颜色显示 `0`。排序使用百分之一件／小时精度的净变化估计值。

### 数字布局

库存和单价分别右对齐。窄屏时库存和单价放到物品名下一行，保持「出售」完整可点击。出售数量和预计得款分别占一行，允许缩写。出货浮动小字可缩写。

### 百分比出售

- 单品默认 0%，可拖动或点击轨道选取 0% 至 100% 的整数百分比。键盘左右箭头调整 1 个百分点，Home 与 End 跳到两端。百分比取库存总量为基准，包含预留库存。
- 实际出售数量为 `库存快照 × 百分比 // 100`，向下取整；100% 出售全部库存。预计得款用该整数数量乘以当前单价。数量为 0 时禁用确认。批量出售对所选品项逐项应用同一比例，合计为各项报价之和。
- 出售面板用百分比滑条和两行摘要。若库存为 `100.25M` 小麦、出货单价 150，选择 50% 时显示「出售数量 50.12M」「预计得款 7.51B 金币」。成交按 50,125,000 份和 7,518,750,000 金币处理。
- 确认以当前库存、价格及保留量重新计算。若实际出售数量、预计得款或保留量影响发生变化，保留所选百分比并刷新预览，要求再次确认。取消不改变库存和余额。

仓库不提供行脚商入口；从大地图摊车或菜单进入。
