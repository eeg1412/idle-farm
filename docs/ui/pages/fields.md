# 牧场 · 田地

[UI 索引](../../ui.md) · [数字显示](../numbers.md) · [反馈规则](../feedback.md)

从上到下为金币与设置、场景横幅、田地／畜牧／鱼池页签、种植地块标题与购地按钮、当前入门任务卡、可滚动地块列表、底栏。入门完成后任务卡收起，仍可通过底栏「经营」进入任务。每种作物使用独立的满幅像素种植场景。卡片显示作物名、等级、每批收成、成熟倒计时和逐帧移动的进度条，按购买顺序排列。已播种地块持续自动收获、入库并复种。

| 按钮或点击区域 | 可用条件 | 点击动作与反馈 |
| --- | --- | --- |
| 底栏经营 | 常驻 | 进入经营页。可打开任务、图鉴和出售牧场 |
| 右上角齿轮 | 常驻 | 直接打开设置 |
| 当前任务卡 | 有待完成的入门任务 | 打开任务页并定位当前任务 |
| 购地 | 未达地块上限 | 打开购地 Dialog，显示金币成本和购买后地块数量。确认后创建空地并定位。成功 Toast「已购入田地」 |
| 地块卡 | 任意地块 | 打开田地详情 Dialog |
| 播种／换种 | 空地显示播种，有作物显示换种 | 打开种子选择 Dialog。选中新作物后立即开始计时，旧作物未完工的批次没有收成。卡片更新，点击处显示「已播种」或「已换种」 |
| 升级 | 已购地块 | 打开升级 Dialog。选择「+1」「+10」「+100」「升到可负担等级」。展示总金币成本、目标等级及每批产量变化。确认后一次扣费，新产量用于下一批。点击处显示「田地升至 N 级」 |

作物、牲畜和鱼种使用可滚动的选择网格。同一格显示小图、品种名与当前生效的生产周期。普通宽度三列，窄屏两列，宽屏四列。

### 作物成长动画

全部作物的已播种地块卡启用成长动画。播放周期均分四期。播种后先显示种子，进度到 25%、50%、75% 时依次显示幼苗、成长、成熟。实际生长时间达到 5 秒时按实际批次播放。短于 5 秒的作物固定以 5 秒为动画周期，实际收获继续按原时间结算，连续收获时保持动画相位。

成熟期末尾仅作物层淡出，时长固定为 300 毫秒。作物完全消失后，到下一次动画循环才显示种子。田中央的洒水器四向循环，喷头转到下一方向后，已喷出的水滴继续落地。

只更新滚动区域内实际可见的地块卡。滚出视口、离开田地页、打开弹窗或隐藏网页时停掉动画。再次进入时按当前批次进度直接显示对应阶段。开启「减弱动效」时洒水器静止，作物按周期直接切换。

### 数字布局

顶部余额用缩写。等级、收成和倒计时单独成组。高等级和收成可用字母后缀缩写，购地和升级成本移到独立行。升级 Dialog 按实际金币计算可负担目标。无可负担等级时禁用确认。田地等级持续成长。

### 替换弹窗

牧场与工坊共用显示偏好。默认每格显示小图标、名称与当前生产周期，宽度决定 2–4 列。点「显示：详细」切到仅图标，点「显示：仅图标」恢复详细。仅图标模式使用更密的网格。两种模式均连续滚动，只加载可见卡片的图标。偏好写入存档，刷新和出售牧场后保留。
