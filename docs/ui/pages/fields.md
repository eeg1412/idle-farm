# 田地、畜牧、鱼塘与矿洞

[UI 索引](../../ui.md) · [数字显示](../numbers.md) · [反馈规则](../feedback.md)

庄园地图的四个入口分别直达田地、畜牧、鱼塘和矿洞。页面从上到下为返回按钮与标题、纯图场景横幅、列表管理按钮、可滚动的设施列表和购买按钮。购买按钮固定在页面底部，不随列表滚动，其左侧为「加速」按钮（[时空胶囊](../../expansion/10-time-capsule.md#104-使用界面)：本类全部已安排配方的槽位一起快进；没有正在进行的批次或胶囊为 0 时禁用）；空列表、单卡片、长列表和缩小模式均同样固定在底部。田地、畜牧、鱼塘的购买按钮不显示红点；金币足够且未达上限时为黄色可点击，否则灰色禁用。矿洞维持原购买提示规则。每种作物使用独立的满幅像素种植场景。卡片显示作物名、等级、每批收成、成熟倒计时和逐帧移动的进度条，按购买顺序排列。已播种地块持续自动收获、入库并复种。

新建存档和清档重开时两块免费田地均为空地，不默认种小麦；先点击空田「播种」才能产生第一批收成。初始解锁小麦和面粉，金币为 `600m`（当前 3,000）。已有档保留作物，出售后的两块新田已播小麦。

「缩小／放大」切换紧凑和普通视图。「批量管理」在当前设施页面内选中设施，可全选或取消选择，支持更换品种、停止生产和统一升 1／5／10 级。升级显示合计费用。空地及空设施也可勾选，用于安排生产或升级。

作物、牲畜和鱼种使用可滚动的选择网格。同一格显示小图、品种名与当前生效的生产周期。普通宽度三列，窄屏两列，宽屏四列。切换为只显示图标的缩略模式时，图标下方的行情标记与「订单商品」「订单原料」标记按同一行高从上往下依次排列，不为未出现的信息预留位置；同一排格子等高，取本排信息行最多的一格；没有信息行的一排只保留图标高度。牲畜使用 `livestock-<ID>` 独立透明活体图，不能用棚舍缩略图、仓库蛋奶肉或动画产品替代；实际产出仍在产物栏、收成和仓库使用对应物品图标。

### 作物成长动画

全部作物的已播种地块卡启用成长动画，另分整株采收和保留植株采收两类。首次播种或换种分四期：种子、幼苗、成长、成熟。展示不设保底，跟随真实批次时长：≥5秒四期均分；3–5秒只播种子与成熟；不足3秒只显示成熟期，不逐批淡出。实际收成照常结算。整株采收每轮沿用四期；果实、花或叶等保留植株采收第二个展示周期起只从成年采后状态变到成熟，桂花为无花到有花，不能每轮消失后重新长苗；该两态在真实批次不足3秒时只显示成熟状态。

整株采收成熟期末尾仅作物层淡出300毫秒，下一轮显示种子。保留植株采收只淡出成熟的采收状态，底层成年植株保持可见。首次换种起点持久保存，同品种续批、切页和读档不重新播种；旧档没有首轮历史的作物直接按成年采收循环兼容。田中央洒水器四向循环，喷头转向后已喷出的水滴继续落地。

全部作物按 `assets/plot/crop-layout.json` 显式分大、中、小。C02–C68每期一张独立单株图片，画布按各根位逐株创建精灵并设置透视大小，不能使用整田合成图代替。四期共用根位，前排植株可遮住洒水器和水花。小麦C01是先前已认可整幅前景例外，保持原像素、密度、尺寸，不按高度截断麦穗。

中、大型按真实背景田垄的完整列族布置：9条原田垄逐排求交，列可在田界自然进入／退出，覆盖可种两端，不能只种成两列窄条。远排按可用高度保留完整树冠；正常垄沟／田边土带、树冠遮挡与真正漏种分别判断。带背景合成图仅是素材摆位交接，运行始终逐株绘制。

只更新滚动区域内实际可见的地块卡。滚出视口、离开田地页、打开弹窗或隐藏网页时停掉动画。再次进入时按当前批次进度直接显示对应阶段。

庄园和工坊已安排产线的动画区域一律不使用回退图标、静态场景或程序占位图。加载中、失败、资料缺失、尚无活动批次和卸载后均保留原区域；后续不得擅自新增回退。空设施的初始选择图与配方选择／材料／产物的正常图标保留。

庄园与工坊的清空控件只显示小号厚重图形叉，禁止文字X或大关闭按钮底框；不为它另加整排空白，标题和等级局部避让，保留动画图块大小。右上角透明命中区与详情分开，点击不同时打开详情，不删除设施，也不新增重复确认或关闭按钮。清空与退款随成功经营动作一并保存，保存失败保留原状态。

### 畜牧动画

畜牧主界面覆盖目录全部10种牲畜，均使用固定棚舍。所有idle都为吃饲料动作；附属产品类全程成年，肉类按周期三等分显示幼年、成长、成熟，每期四张独立进食帧、每帧300毫秒。每只动物对应独立饲料，按站位近大远小，口部与饲料落点按实际原画登记。分类由显式 `slaughter` 登记决定。

同一棚舍内的动物按固定站位错开进食起始帧和切帧时刻。滚动或切页后重新显示时，按当前渲染时钟继续进食循环。

每只动物嘴前都有共用复合饲料图片和独立轻影，运行与静态回退用同一布局，不以贴地细黄点代表饲料；小型料堆在130px仍须看得见。当前V8采用冷暗低沿料盘和米白／褐／绿色混合料，轮廓与金黄地板分开，旧v6-r3黄料堆已因用户反馈重新设计。选择网格使用普通抬头站立图，全部从各自当前动画帧输入绘图工具重新生成，身份/毛色/角耳与动画一致，不能复用旧版抬头图。选择图与低头进食帧分别维护。

动物保持阶段内尺度和解剖脚点稳定，idle 切帧不能整体跳动或忽大忽小。脚下椭圆阴影使用独立程序地面层，位于棚舍之上、动物之下，更深且按真实站立脚印确定大小与位置；不挪动动物迁就影子，不烘焙进图片。同阶段四帧的阴影几何恒定，只随成长阶段切换，并跟随动物透明度淡出。透明牲畜选择图与回退使用的新动物也不带烘焙地面阴影。

动画产物与仓库共用原有物品图，不另外绘制一版；物品图与活牲畜选择图分开。产物按可见主体底边接地，忽略纹理透明边距；肉品在成熟牲畜落脚位置，附属产物仍在动物附近。每项产物有自己的程序椭圆地面影，大小按可见宽度确定，显隐跟随产物，与动物影独立管理。

畜牧动画不设保底，跟随真实批次时长，实际生产时间不变。肉类三期：≥4秒完整，3–4秒只播幼年与成熟，不足3秒只显示成熟动物；附属产品类以无产品／有产品两态为首末：≥3秒交替，不足3秒常显产品。距展示收获还剩 3 秒（末阶段不足3秒时为整段末阶段）时，附属产品类淡入对应蛋奶等产物，动物保持原状；肉类动物淡出并在成熟落脚点淡入肉品。展示收获后产品及其阴影淡出，跨阶段边界保持该产品落点，不跳到幼年位置，随后进入下一展示周期。淡入、淡出均为 300 毫秒 smoothstep；末帧档不逐批淡变。每个实际批次从自身起点展示，不跨批次延续相位。

动物按 `src/view/livestock-layout.js` 显式体型分类：小型鸡、麻鸭、肉兔显示三只；中型鹅、番鸭显示两只；大型牛、羊、猪显示一只。每只动物对应一个可见产物和独立阴影，远处缩小、近处放大，展示只数不改变经济产量。肉品在对应站位左右居中，单只大型动物及其肉品位于场景水平中心，落脚高度固定取成熟阶段。

点击动画仍打开原设施详情；不新增牲畜操作按钮。换养立刻替换物种，不能带入上次产品；滚出视口、打开弹窗、切页或进入后台时卸载动画。加载期间或失败不显示回退图片；历史同ID静态素材不作为运行替代。完整规则见[畜牧动画](../../development.md#畜牧动画)。

牲畜选择图不可辨识的用户反馈已重新打开，需确认独立透明活体图已进入实际选择网格及两种显示模式；资源存在与旧检查结论不能代替实际界面验收。

### 鱼塘动画

全目录鱼种按显式 `habitat` 使用河水或海水固定鱼塘背景。鱼苗、成长期、成熟期各有独立四帧 idle 原画，完整档按真实批次周期三等分切换。按显式体型分类：小型三只、中型两只、大型一只；站位留在中央水面，远小近大，不改变真实收成件数。

成熟期结束前鱼体淡出，下一周期鱼苗再淡入，固定鱼塘不参与淡变。展示不设保底，跟随真实批次时长：≥4秒三期完整，3–4秒只播鱼苗与成熟，不足3秒只常显成熟鱼且不淡变；每帧 300ms、淡出／淡入各 300ms smoothstep。实际生产照旧，每个批次从自身起点展示。仅可见活跃鱼塘挂载，滚出、弹窗、切页、后台卸载；加载失败不显示回退图片。

鱼塘按「背景层 → 鱼层 → 水色半透明遮罩层 → 动态水波层」绘制。水色表现水体不透明度，让鱼像在水下而仍可辨认；鱼、水色和波纹都按当前背景的开放水域多边形裁切，不能染到岸石、草木。水波用程序绘制轻薄短弧并持续扩散、漂移和淡变，30fps 更新；圆弧独立起笔，不连到画布原点。水色和波纹不跟随鱼体收获淡出。

选鱼网格使用 `fish-<ID>` 独立透明活鱼图，仓库继续用原 canonical 渔获图。固定身体锚点、来源与生成规范见 [farm-fish](../../../.agents/skills/farm-fish/SKILL.md) 和[鱼塘动画开发规范](../../development.md#鱼塘动画)。

### 矿洞

「矿洞」从庄园地图直达。卡片、详情、矿种选择、升级、批量管理、缩小／放大和清空均沿用田地的结构与命中方式，操作文案使用「开采／更换矿种／购买矿洞」。矿洞初始为0座，购买后为空；购买、升级和40座上限对齐畜牧、鱼塘，各自独立累计购买次数。每座矿洞同一时刻只开采一种已研发矿产；换矿取消未完成批次，不发收成。

普通卡片左侧使用320×320像素场景，依次绘制矿洞与铁轨背景、洞口原画层、矿车和当前矿种的仓库图标。首次空车用2秒进入洞内，完工前2秒开始满载出洞，完工时到达装卸位。到站后矿物图标用300ms淡出，车保持可见。停留1秒后，空车再用2秒入洞。最低展示时长5.3秒；批次真实时长不足5.3秒时不拉长，只静态显示满载矿车到达装卸位的一帧，不播进出洞、行驶与卸货。真实完工和入库按经营批次进行。每轮只展示当前矿种。

矿车轮脚贴合真实轨道。以车斗和车轮经过高度的洞口内缘定淡化范围，当前画面约为 x=28–108。车体左缘从右侧内缘驶向左侧内缘时，车体用 smoothstep 从全显过渡到全隐。满载出洞时，车体和货载沿同一区间同步渐显。背景和洞口保持固定。矿种图标与仓库共用canonical WebP。按可见卡片加载共享背景和矿车，离屏、弹窗、切页、后台卸载；异步完成不得复活旧卡。加载中、失败和缺资料时保留动画区域，不显示静态场景或程序占位。

动画关键帧必须由消费运行布局与同一时序函数的合成器输出，覆盖首次进洞渐隐、洞内等待、满载出洞渐显、到站、货物半透明、空车停留、重新进洞渐隐和循环接缝。独立子代理在320px和约130px使用尺寸打开图片审阅，不合格退回所有者重画或修正布局；关键帧通过只证明分镜，不代替真实Pixi体验。

### 通用数字布局

等级、收成和倒计时单独成组。「距收获」与时间强制单行，不能因分钟秒数变化增加行高。高等级和收成可用字母后缀缩写，购地和升级成本移到独立行。升级 Dialog 按实际金币计算可负担目标。无可负担等级时禁用确认。田地、养殖场和鱼塘的「升级」入口不显示红点；可负担升一级时为黄色可点击，否则灰色禁用，普通／缩小卡片与详情入口一致。批量管理的升级按已选目标默认升一级的合计报价判断可用性。田地等级持续成长。

### 替换弹窗

庄园与工坊共用显示偏好。详细模式每格显示小图标、名称、当前生产周期和已安排该品种或配方的产线数。产线正在生产或暂时停工均计入，数量独立于列表筛选。右侧图形按钮切换详细与仅图标，后者使用更密的网格。两种模式均连续滚动，只加载可见卡片的图标。偏好写入存档，刷新和出售庄园后保留。配方选择不显示即时生效说明，也不设置重复的底部关闭按钮。

行情生效后，庄园卡和品种选择中有涨跌的品项显示倍率与方向图标，品名使用涨绿跌红。

批量升级弹窗顶部有「平均分配」开关（记入存档 `settings.batchUpgradeEven`，默认关）：开启后总升级级数不变（档位 × 所选数量），每级依次给当前等级最低的一项（同级按选择顺序），等级显示为升级后的实际区间；关闭时每项加同一档位。「等级」对比行与 +1／+5／+10 按钮组之间留 9 逻辑像素。

批量升级成功后保持升级弹窗和已选升档，更新余额、合计费用及按钮可用状态，玩家可再次点击；保存提交期间防止重复提交，资金不足或失败时不退出弹窗。
