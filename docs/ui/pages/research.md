# 研究

高级研发点永久科技各50级，品质等级仍无上限。科技减费用当前效果统一“降低X%”、提速统一“提速X%”，使用真实累计百分比；不以建造价格或某配方耗时替代。三类增产每级+2%（设施批量按(100+2级)/100乘算），满50级增产100%，效果显示“增产X%”。旧档保持原等级数字，开发满科技入口发50；高阶前置仍要求对应科技满50及原品项条件。科技报价直接读取 `techOffer.cost`，按各项收益分组定价，24项总价2,151,000点。

经营评估倍率显示至必要小数，如1.02倍。升级只影响以后实际生产事件的点数收益，不重算此前收益；活动权益点数仍仅在确认出售牧场时领取；任务研发点奖励随任务结算的成功提交到账，不受评估倍率影响。代管效果将真实分钟数格式化为小时及分钟，0／10／50级分别24／48／72小时，首级显示24小时→26小时24分钟，前10级每级+144分钟，11级起每级+36分钟。

品种配方、品质、经营改良分别保留视口。品种配方显示完整科技树，已有 `tab=recipes` 链接保持兼容。前置在上，后续在下，节点在图中的位置由真实依赖确定。请从全图拖动或使用索引直达目标。经营改良使用相同方向。品质为每个已研发品项分别显示当前与下一等级。任一品种或配方可研发、任一品项可升一级品质或任一经营改良可升一级时，对应页签显示红点。至少一个页签有红点时，底部「研究」同样显示红点。

- 普通视图用浅线表示附近关系。点中节点后高亮直接前置与直接后续，再打开详情。多个直接前置汇入当前节点时共享汇入段；当前节点通往多个后续时共享分出段。各端保留方向与独立箭头。
- 「全图」一次显示完整科技树。缩小时用状态点显示位置，放大后显示图标、名称与状态。节点无需逐层展开。
- 「起点」回到最早的可读视图。「查找节点」打开索引，可按类型、来源、农业用途和研发状态筛选。结果连续滚动，选择后定位到原图中对应节点。
- 单指和鼠标可平移。双指、滚轮和画布加减键可缩放。详情关闭后回到原处。

前置完成、材料和金币齐备即可一次付清并立即研发。523项研发前置与耗材种类保持原值，金币与耗材数量按[LT-v4生成规则](../../expansion/07-balance-validation.md#74-研发生成规则)（仅P01引导覆盖）取自运行数据，详情以「持有 / 所需」逐项显示费用。品种配方详情通过 `unitPrice` 显示解锁品项的整金币单价，未解锁时按品质 1 计价，已解锁时按当前品质计价。周回仍清空未支付库存，没有分批提交入口。

品质只对已研发品项开放，保留＋1／＋10／＋100及最高可升操作。详情显示当前与目标等级、整金币单价、所选升级范围的实际每件价差及累计费用；价差直接读取 `qualityOffer.priceDelta`。LT-v4全部基价≥30，每级价差至少3金币，例如小麦品质1／2／3／4的单价为30／33／37／40金币；若数据出现价差为0，仍明确显示「本次升级单价不变，没有现金售价提升」。品质金币按品项单线产值U计价（见[经营规则1.2](../../expansion/01-operations.md#12-解锁与独立品质)），例如小麦品质1→2为1,000金币。每ID品质独立，同ID全库存按当前价计价，材料品质不传递给成品。品质100级以上另需高级研发点：`qualityOffer.researchPoints` 大于0时，费用表加一行「高级研发点」（写法同科技费用行），研发点不足时与金币不足同样禁用确认；不受降费科技影响。「品质」页签与「经营改良」一样显示高级研发点余额。经营改良使用高级研发点。
