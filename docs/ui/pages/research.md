# 研究

高级研发点永久科技各50级，品质等级仍无上限。科技减费用当前效果统一“降低X%”、提速统一“提速X%”，使用真实累计百分比；不以建造价格或某配方耗时替代。三类增产每级每批+2件，满50级额外100件。旧档保持原等级数字，开发满科技入口发50；高阶前置仍要求对应科技满50及原品项条件。科技报价直接读取 `techOffer.cost`，按各项收益分组定价，24项总价2,151,000点。

经营评估倍率显示至必要小数，如1.02倍。升级只影响以后实际生产事件的点数收益，不重算此前收益；点数仍仅在确认出售牧场时领取。代管效果将真实分钟数格式化为小时及分钟，0／40／50级分别8／24／36小时，首级显示8小时→8小时24分钟。

品种配方、品质、经营改良分别保留视口。品种配方显示完整科技树，已有 `tab=recipes` 链接保持兼容。前置在上，后续在下，节点在图中的位置由真实依赖确定。请从全图拖动或使用索引直达目标。经营改良使用相同方向。品质为每个已研发品项分别显示当前与下一等级。

- 普通视图用浅线表示附近关系。点中节点后高亮直接前置与直接后续，再打开详情。多个直接前置汇入当前节点时共享汇入段；当前节点通往多个后续时共享分出段。各端保留方向与独立箭头。
- 「全图」一次显示完整科技树。缩小时用状态点显示位置，放大后显示图标、名称与状态。节点无需逐层展开。
- 「起点」回到最早的可读视图。「查找节点」打开索引，可按类型、来源、农业用途和研发状态筛选。结果连续滚动，选择后定位到原图中对应节点。
- 单指和鼠标可平移。双指、滚轮和画布加减键可缩放。详情关闭后回到原处。

前置完成、材料和金币齐备即可一次付清并立即研发。523项研发金币、材料与前置保持原值，详情以「持有 / 所需」逐项显示费用。周回仍清空未支付库存，没有分批提交入口。

品质只对已研发品项开放，保留＋1／＋10／＋100及最高可升操作。详情显示当前与目标等级、整金币单价、所选升级范围的实际每件价差及累计费用；价差直接读取 `qualityOffer.priceDelta`。低价品部分等级价差可为0，此时明确显示「本次升级单价不变，没有现金售价提升」。例如小麦品质1／2／3／4的单价为3／3／3／4金币，不承诺每级必涨整金币。每ID品质独立，同ID全库存按当前价计价，材料品质不传递给成品。经营改良使用高级研发点。
