# 设置

[UI 索引](../../ui.md) · [数字显示](../numbers.md) · [反馈规则](../feedback.md)

| 页面内容 | 按钮或点击区域 | 动作与反馈 |
| --- | --- | --- |
| 音乐、音效、文字大小和操作说明 | 音乐／音效／静音 | 更新并保存设置。控件本身展示当前状态 |
| 同上 | 文字大小 | 用步进按钮或滑杆调整，立即重排并保存 |
| 同上 | 重看操作说明 | 打开说明 Dialog，保持任务阶段和累计进度 |

### 数字布局

文字大小、音量等有限取值按实际整数显示。200% 时标题与控制区可上下排列。重看操作说明不影响经营和任务进度。
