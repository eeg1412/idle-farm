### 数字布局

文字固定为 100%。音乐与音效分别按实际整数显示音量。新庄园的两项音量默认均为 0%，已有存档读取各自保存的音量。设置页不提供操作说明。

自动收获与工坊完工不播放音效，切到其他游戏页面也静默结算；主动出售、研发、升级等操作音和背景音乐仍由原音量控制。

大地图雨声使用音效音量，随天气雨势渐变；离开地图或进入后台时停止。首页菜单和弹窗保留雨声。首次用户操作解锁音频后，已开启的音效按当前雨势播放。

设置页标题水平居中。

### 存档管理

校验存档 schema 3、交换格式 2 和当前正式／开发环境。数量用十进制字符串保存，导入后由既有完整记录校验恢复 BigInt。无效 JSON、版本不符或内容损坏只显示错误，不改当前记录。

导入摘要显示金币、研发点、设施数、解锁数与周回次数。确认替换时重新解码原文并核对本地修订号；提交成功后清理旧页面、弹窗和排队命令，回庄园。源存档生产进度保留，墙钟锚点改为当前时间，不补导出至导入的离线收获。导入前当前档保留为上一份备份；清除同时删除旧备份，避免旧进度复活。

导出与确认导入面板不显示「存档类型」行，导入说明提示选择本游戏导出的存档。

选择文件在原始点击调用栈内启动，之后重绘读取状态。读取中、取消、版本／环境不符、文件为空或损坏及读取失败均在弹窗首部显示，滚动回顶部；成功先出现摘要确认，实际替换成功后回庄园并提示。已离开原面板的迟到文件结果不再打开新确认。原生文件选择器不受支持或未获准时明确显示原因及粘贴／拖入方式，不静默失败；拖入与选择文件共用读取接口（File.text／非DOM FileReader），不新增DOM输入框。

系统文件窗口往返可能触发前后台结算，离线汇总不能覆盖正在读取或确认的导入面板。`flow:'save-import'`沿当前／待显／父弹窗链标记导入过程；经营照常结算，汇总延后到导入流程结束，再由既有5秒保存循环重试呈现，不新增轮询计时器。

未取得文件不直接断言用户取消，说明可能取消或受隐私／权限限制，并明确可拖入JSON或粘贴存档文本。不探测隐私模式，不添加隐藏输入框。导入读取、版本／环境／损坏校验和实际替换失败均用现有红色提示；重新读取、核对中和成功摘要恢复正常颜色，不能整段状态一律红色。

导入、清除及文件读取期间禁止重复操作。原生选择文件不受支持时，使用剪贴板或画布内的粘贴／JSON 文件拖入。所有游戏确认与提示仍在唯一 PixiJS 画布；不挂载隐藏文件输入框。

### 开发专用入口

用户指定的开发测试入口位于 `/#/settings` 的页头标题「设置」。仅在 `npm run dev`（Vite `serve` 且模式为 `development`）时，连续点击这两个字 11 下可解锁全部品种与配方、将 21 项经营改良升至 50 级，并追加 1T 金币（`1_000_000_000_000n`）。离开设置页或点击其他控件时重置计数；不增加可见按钮，也不改变画布布局。

发放沿用现有动作与保存事务，提交成功后反馈。品质等级不在「全部科技」范围内，发放不计为生产、出售或经营收入。开发存档使用独立数据库 `idle-farm-v7-development`，正式存档使用 `idle-farm-v7`。

所有 Build 构建（包括 `--mode development`）必须移除触发器与发放模块，`npm run preview` 中无效。完整边界见[开发测试模式](../../development.md#开发测试模式)。
