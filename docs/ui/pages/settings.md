# 设置

[UI 索引](../../ui.md) · [数字显示](../numbers.md) · [反馈规则](../feedback.md)

| 页面内容 | 按钮或点击区域 | 动作与反馈 |
| --- | --- | --- |
| 音乐、音效、文字大小和操作说明 | 音乐／音效／静音 | 更新并保存设置。控件本身展示当前状态 |
| 同上 | 文字大小 | 用步进按钮或滑杆调整，立即重排并保存 |
| 同上 | 重看操作说明 | 打开说明 Dialog，保持任务阶段和累计进度 |

### 数字布局

文字大小、音量等有限取值按实际整数显示。200% 时标题与控制区可上下排列。重看操作说明不影响经营和任务进度。

### 开发专用入口

用户指定的开发测试入口位于 `/#/settings` 的页头标题「设置」。仅在 `npm run dev`（Vite `serve` 且模式为 `development`）时，连续点击这两个字 11 下可解锁全部品种与配方、将 24 项永久科技升至 5 级，并追加 1T 金币（`1_000_000_000_000n`）。离开设置页或点击其他控件时重置计数；不增加可见按钮，也不改变画布布局。

发放沿用现有动作与保存事务，提交成功后反馈。品质等级不在「全部科技」范围内，发放不计为生产、出售或经营收入。开发存档使用独立数据库 `idle-farm-development`，正式存档保持为 `tianjian-workshop`。

所有 Build 构建（包括 `--mode development`）必须移除触发器与发放模块，`npm run preview` 中无效。完整边界见[开发测试模式](../../development.md#开发测试模式)。
