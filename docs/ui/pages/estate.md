# 庄园首页

[UI 索引](../../ui.md) · [全局导航](../navigation.md)

庄园首页沿小路串起十个入口。田地在首屏内，便于开始生产。金币余额为只读显示，右上角菜单固定显示，场景滚动时仍可打开。地图支持触控拖动、鼠标滚轮和拖动滚动条。独立的建筑、动件和木牌叠在像素地景上，随地图一起滚动。建筑和对应木牌共用一个点击与键盘焦点区域。地景、建筑、动件和木牌采用生成的像素画。各入口有独立的局部循环动效，可见时更新，与经营结算无关。

| 从上往下 | 入口与动效 |
| --- | --- |
| 经营与任务 | 经营厅红旗轻动。路边任务公告栏的挂灯轻晃，当前引导通常在公告栏上方。 |
| 畜牧与田地 | 羊缓慢呼吸，田地中的稻草人轻摆。 |
| 鱼池与矿洞 | 海湾集中在鱼池旁，淡水池在岸内，海水网箱在岸外，共用鱼池入口。锦鲤在淡水池游动，矿车沿轨道短距离往返。 |
| 加工与精制 | 水轮慢转，烟囱飘烟。 |
| 研发与仓库 | 研发屋外的望远镜轻摆，仓库吊钩升降。 |

每组两个入口随地形错开位置，尺寸按各建筑地块调整。十块门牌使用同一尺寸和字号，在对应主体下方水平居中。经营和研发以主门定轴，鱼池以淡水池定轴。建筑按默认坐标绘制。顶部空间不足时，任务引导挪到任务门牌下方，任务点击区从金币栏下方开始。地图滚动时，入口可从固定控件下经过。

地图重绘时，已缓存的素材在当帧重新挂载，画布尺寸调整与绘制在同一帧完成。

## 摆放编辑器

直接打开 `#/estate-layout`。拖建筑移动，拖空地或滚轮查看地图下段。选中后用「−」「＋」缩放。可切换全图与放大视图、撤销编辑或恢复默认。草稿保存在当前浏览器。

「导出 JSON」下载 `estate-layout.json`。`schemaVersion` 为 1，`mapAspect` 为地图高宽比，`buildings` 包含十座建筑。每项的 `id` 对应首页设施，`center` 是纹理中心的横纵坐标，`widthRatio` 是建筑可见宽度。三个数均以地图宽度为单位。导出用于后续更新首页布局。
