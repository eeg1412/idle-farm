# 庄园首页

[UI 索引](../../ui.md) · [全局导航](../navigation.md)

庄园首页沿小路串起十二个入口。田地在首屏内，便于开始生产。金币余额与其右侧的时空胶囊数量均为只读显示，金币显示宽度相应缩短，两者在 320 逻辑像素竖屏下不重叠、不截断；右上角菜单固定显示，场景滚动时仍可打开。地图支持触控拖动、鼠标滚轮和拖动滚动条。独立的建筑、动件和木牌叠在像素地景上，随地图一起滚动。建筑和对应木牌共用一个点击与键盘焦点区域。地景、建筑、动件和木牌采用生成的像素画。原十个入口的局部循环动效可见时更新，与经营结算无关；行脚商保留稳定旅行摊车，按是否已解锁显示开摊或盖布收摊状态，开放后只有独立小旗和挂灯运动。

| 从上往下 | 入口与动效 |
| --- | --- |
| 经营与任务 | 经营厅红旗轻动。路边任务公告栏的挂灯轻晃，当前引导通常在公告栏上方。 |
| 行脚商 | 布篷木轮摊车 center[0.4923,0.504]、widthRatio0.198；未达到开摊条件时货物盖布收摊；已解锁后展示货物，独立四帧小旗随风变化、挂灯小幅摆动。点车或“行脚商”木牌打开原行脚商页面，未开摊时查看原条件。 |
| 畜牧与田地 | 羊缓慢呼吸，田地中的稻草人轻摆。 |
| 订单中心 | 建于主路右侧，田地下方、鱼塘上方的空地。独立的建筑动件随地图可见区域播放，点击建筑或门牌打开订单页。有可交付的锁定订单时门牌右上角亮圆点，与其他建筑提醒圆点同位置同样式。[订单中心](orders.md) |
| 鱼塘与矿洞 | 海湾集中在鱼塘旁，淡水池在岸内，海水网箱在岸外，共用鱼塘入口。锦鲤在淡水池游动，矿车近侧车轮贴合近侧铁轨、车身随轨道倾斜约 10°，沿轨道短距离往返。 |
| 加工与精制 | 加工水轮慢转，加工与精制的烟囱各自冒烟。 |
| 研发与仓库 | 研发屋外的望远镜轻摆，仓库吊钩升降。 |

原五组各两个入口随地形错开位置，行脚商位于三叉路右空地，订单中心位于田地与鱼塘之间。十二个地图对象的默认中心与可见宽度以 `src/view/estate-map.js` 的 `sites` 登记为准，例如订单中心 `center` 为 [0.5017, 0.9955]、`widthRatio` 为 0.258。十二块门牌使用同一尺寸和字号，在对应主体下方水平居中。经营和研发以主门定轴，鱼塘以淡水池定轴。建筑按默认坐标绘制。顶部空间不足时，任务引导挪到任务门牌下方，任务点击区从金币栏下方开始。地图滚动时，入口可从固定控件下经过。

地图重绘时，已缓存的素材在当帧重新挂载，画布尺寸调整与绘制在同一帧完成。

## 新手开场

`world.introPending` 为 `true`（`newWorld` 新建的庄园：首次启动无存档、设置中清除存档、存档损坏后新建）时，加载后播放开场：

1. 强制进入大地图并滚到顶部，露出任务公告栏；天气锁定为晴天。
2. 地图以 0.55 不透明度压暗，任务管理员立绘在 0.4 秒内从画布底部中间升起，头顶气泡逐字讲 3 句，按当前任务管理员性别分男女两版。点击任意处：打字中补全当前句，补全后进入下一句；不设跳过。
3. 第 3 句讲完后点击，管理员退下。任务公告栏（建筑与「任务」木牌）周围亮圈，其余区域保持压暗，上下跳动的箭头指向公告栏；此时只有公告栏可点。
4. 点击公告栏进入任务页，开场在任务页继续，见[任务页新手开场](tasks.md#新手开场)。

开场完成前关闭或刷新，下次加载从第 1 步重新开始。

## 天气

大地图初始与后续每次天气抽取均为晴天 80%、雨天 20%。每隔随机 10–30 分钟重新抽取，同天气保持现状，晴雨改变时用 8 秒平滑过渡。抽取间隔按加载完成后的应用前台时间累计，访问其他页面仍计时，浏览器后台暂停。晴天云影数量在 3–10 片内随机调整，覆盖建筑及建筑名称；各片独立从左向右漂移；前一片开始从右侧离场时，同一高度区域的下一片即从左边缘入场，不等待前一片或整批离场。雨天地图色调变暗，雨丝掠过画面，雨声随雨势渐变。天气不改变经营。[新手开场](#新手开场)期间天气锁定为晴天、雨势为 0 且不抽取；进入任务页时解除锁定，下一次抽取在解除时刻后随机 10–30 分钟。金币、菜单和弹窗保持在天气层之上，云影和雨丝不参与点击命中，建筑、路牌和地图滚动沿用原交互。

云影轮廓由十种普通云形及兔、猫、鲸、龟四种动物云形共同构成，动物云形也以阴影显示，头部均朝右；它们共用同一数量范围，随转雨淡出。云影在互不相交的高度区域内分散漂移，区域内的形状、大小、位置及速度随机；补入时与前一片保持间隔，速度更快的下一片推迟入场，移动中不重叠。

雨声使用现有音效音量，首次用户操作解锁音频后播放；新庄园音效仍默认 0%。离开大地图、进入后台或关闭音效时停止雨声；首页菜单和弹窗保持当前雨声。

## 摆放编辑器

直接打开 `#/estate-layout`。拖建筑移动，拖空地或滚轮查看地图下段。选中后用「−」「＋」缩放。可切换全图与放大视图、撤销编辑或恢复默认。草稿保存在当前浏览器。

「导出 JSON」下载 `estate-layout.json`。`schemaVersion` 为 1，`mapAspect` 为地图高宽比，`buildings` 包含十二个地图对象（含行脚商摊车和订单中心）。每项的 `id` 对应首页设施，`center` 是纹理中心的横纵坐标，`widthRatio` 是建筑可见宽度。三个数均以地图宽度为单位。导出用于后续更新首页布局。
