# 工坊

[UI 索引](../../ui.md) · [数字显示](../numbers.md) · [反馈规则](../feedback.md)

「加工」「精制」两个页签分别显示连续滚动的中间产物和商品工位列表。每张卡显示工位等级、当前配方、本批产出、产物当前库存、倒计时和材料状态。

| 按钮或点击区域 | 可用条件 | 点击动作与反馈 |
| --- | --- | --- |
| 加工／精制 | 常驻 | 切换工位列表，分别记忆滚动位置 |
| 增设加工位／增设精制位 | 对应工位未达上限 | 黄色按钮，打开增设工位 Dialog，显示成本（加工位 750m×25ⁿ、精制位 950m×25ⁿ，无折扣）和现有数量。确认后创建 1 级空工位并定位。成功 Toast「已增设加工位」或「已增设精制位」 |
| 工位卡／详情 | 任意工位 | 打开工位详情 Dialog，显示工位等级、本批产出、产物当前库存、续批预计耗时与材料、加工增值及优先级 |
| 升级工位 | 工位详情内，任意工位（空闲、等待材料、生产中均可） | 复用设施升级 Dialog，提供 +1、+10、+100、最高可升，显示当前等级→目标等级、已安排配方的每批产出变化（目录基础批量乘 W，W=1+j+⌊j²/64⌋，j=等级−1）、每批投入倍数与金币报价（`750m／950m × [j(j+1)(2j+1)/6 + ⌊j⁶/24000⌋]` 端点差，无折扣）。金币不足禁用确认。确认后只改等级，当前批次不变，说明文字「升级自下一批生效」；成功 Toast「工位已升级」 |
| 选择配方／更换配方 | 空闲、等待材料和生产中均可进入 | 空工位的「选择配方」用绿色按钮。打开配方选择 Dialog，可选已研发的同类配方。更换配方后未完成的旧批次停止，已记录的投入退回仓库。新配方立即生效，材料齐备时开工，完工后自动续作 |
| 产线卡右上角叉号图标 | 已安排配方或存在活动批次 | 直接清空安排与活动批次，恢复「选择配方」空闲卡；保留工位和购买序号，优先级恢复普通。只退回本批明确记录的投入，不发放未完成产品；缺少投入明细的旧批次不虚构退款 |
| 优先／普通 | 工位详情内 | 切换下一批争料优先级。点击处显示「已设为优先」或「已设为普通」 |
| 查看来源 | 材料不足时 | 直接进入对应物品的来源详情 |
| 查看研发条件 | 工坊来源链接指向尚未研发的品项 | 来源卡显示品项和对应工位，点击进入该品项的研发节点 |
| 调整保留量 | 库存够用但被预留 | 打开对应物品的加工保留量 Dialog |

配方选择使用可滚动的网格，保留来源筛选。每格显示小图、配方名和应用当前提速后的耗时。普通宽度三列，窄屏两列，宽屏四列。

### 数字布局

输入材料和产出区域分开。产出区明确列出「当前库存」和「本批产出」，例如 5 级新开批的面粉工位「当前库存 300.35T」「本批产出 60」。当前库存取仓库现有总量，排除在制品；本批产出取活动批次锁定数量（开批时按工位等级倍数 W 锁定的件数）。尚未开批时显示「每批产出」，取配方的目录基础批量乘当前工位等级倍率 W。升级后到下一批开批前，本批产出仍显示旧锁定量，「每批产出」与材料所需已按新等级显示。窄屏把两项堆叠，保留标签与数字。

工位等级显示为「Lv.L」，与卡片标题同行；数字过长时按[数字显示](../numbers.md)缩写。可升一级的工位在「升级」旁显示红点。下一级报价只在升级 Dialog 内显示，卡片不常驻报价。

材料行用「材料名 持有 / 所需」，如 3 级乡村面包工位「面粉 2 / 6」。持有指可投入库存，等于总库存扣除保留量后与 0 取较大值，所需按下一批「配方数量 × W」计算（W 为工位等级倍数），不足时等待整批。工位材料区仅展示继续生产所需的持有／所需。未满足时加图标和警示色，并提供「查看来源」；保留量造成不足时提供「调整保留量」。

工坊提速只缩短下一批的预计耗时，与工位等级无关。新批产出是配方的目录基础批量乘 W。面粉的基础批量为 12，工位等级 1／2／3／5／10／20 时，每批分别为 12／24／36／60／132／300 件。库存随实际完工变化。

### 本批与续作

「生产中」显示本批配方、剩余时间与本批产出。工位固定保留剩余栏和进度条。停工时进度条为空，剩余栏显示红字「暂停」，工位用红底白字标记「等待材料」「材料已预留」或「等待安排」。材料齐备自动开工。「更换配方」与「查看来源」仍可用。

居右显示模式图标按 [替换弹窗](fields.md#替换弹窗) 的偏好切换详细与仅图标；配方选择不显示额外即时生效说明和底部关闭按钮。生产进度条随画布帧更新，完工入库和新批次按实际模拟结算。

### 传送带动画

已安排配方的加工／精制卡使用绘图技能生成的独立素材，机器与流水线采用严格正俯视相机。最新美术要求是木质机身与木板履带，替换旧金属柜机和黑色橡胶带面；必须重新绘图，不能只给旧图改色。纵向长条机器居中，两边平直无突出接口；机身等比放大到超出动画块的上下边缘，由动画区域裁切，抖动时也不能露出顶部或底部空隙。左右各是一片满场景高度的无边传送带，延伸到场景边缘并贴住机身，不再按材料数拆成多条。

实际配方材料从最左侧画面之外成组向右滚入，入口X固定为负半个图标宽度，随机的是每件物料的Y高度与同时进入数量；允许重叠、同时多个，单材料配方也可多件。不能在带面内部随机X后闪现，也不固定在中线或几条预设行。每个物料的身份与高度在发射时确定，之后只向右移动，不能逐帧随机闪换。材料完整覆盖配方集合。成品从右侧中央出来，保持不透明，直接滚到最右侧并完全离开区域后结束，不使用fade out。两边图标继续放大。运行按「传送带层 → 材料与产物层 → 机器层」组装，不加载或绘制背景图。素材不烘焙物品或固定产线，材料与产品复用仓库 canonical 图标，按侧遮挡，不能从机身另一侧漏出。机身运行时独立抖动，待料停止；保持已交付长条原画，不旋转或非等比拉伸。

展示按当前活动批次和共享展示时钟运行，不代表额外扣料、产出或任务事件，不播放自动完工音效。仅可见卡片挂载，滚出、弹窗、切页或进入后台时卸载；异步图标加载完成后不得复活已销毁页面。已安排产线的动画加载中、失败、缺资料或卸载时均保留区域，不显示任何回退图标、静态场景或程序占位图。空工位仍显示原设施与「选择配方」。所有绘制、命中与动画位于现有 PixiJS 单画布内。

随机进料使用稳定的展示时间与事件队列，跨重绘和续批保持连续，切新配方时重新开始该配方的展示。暂停／待料／尚未开批时不显示材料，不改变真实库存或配方投入。机身与图标保持等比，动画块匹配方形场景，左右带面铺满该区域高度。

传送带只使用独立可平铺的滚动带面，不显示护栏、边框、螺丝或端口套。带面和物品均从左往右；纹理的真实采样间距与相位周期同步放大，改善细密重复条纹的方向辨识，不能只反转相位符号或只移动物品。机器独立抖动。程序遮罩仅用于裁切，不能代替真正绘图纹理。

### 烟囱、烟雾与齿轮

加工机和精制机各有两个放大烟囱，沿机身中心线上下对称，分别位于齿轮组上方和下方。机身中央的两枚齿轮使用独立透明像素原画。完整顺序为传送带和物料 → 机身 → 齿轮与烟囱 → 半透明烟雾。齿轮与烟囱随机器抖动，两枚齿轮以相反方向自转，停工时保持当前角度。

运行时两个烟囱错相发出半透明烟团。烟团向上及两侧飘散，逐渐变大并淡出，最高不透明度为 54%。每个烟口使用 6 个固定精灵，暂停或待料时隐藏全部烟团。显示采用既有展示时钟和按需纹理加载，离开可见区时卸载。

工坊显示当日有涨跌的产物和材料品名、倍率与方向图标，「选择配方」同样显示。详情中的直接机会增值按当日各品项实际成交价计算。
