# 工坊

[UI 索引](../../ui.md) · [数字显示](../numbers.md) · [反馈规则](../feedback.md)

庄园地图的「加工」「精制」入口分别直达中间产物和商品工位的滚动列表。每张卡显示工位等级、当前配方、本批产出、产物当前库存、倒计时和材料状态。

| 按钮或点击区域 | 可用条件 | 点击动作与反馈 |
| --- | --- | --- |
| 增设加工位／增设精制位 | 金币足够且对应工位未达上限 | 不显示红点；满足条件为黄色可点击，否则灰色禁用。打开增设工位 Dialog，显示成本（加工位 750m×25ⁿ、精制位 950m×25ⁿ，无折扣）和现有数量。确认后创建 1 级空工位并定位。成功 Toast「已增设加工位」或「已增设精制位」 |
| 工位卡／详情 | 任意工位 | 打开工位详情 Dialog，显示工位等级、本批产出、产物当前库存、续批预计耗时与材料、加工增值及优先级 |
| 升级工位 | 已有工位且至少可负担升一级（空闲、等待材料、生产中均可） | 复用设施升级 Dialog，提供 +1、+10、+100、最高可升，显示当前等级→目标等级、已安排配方的每批产出变化（目录基础批量乘 W，W=1+j+⌊j²/64⌋，j=等级−1）、每批投入倍数与金币报价（`750m／950m × [j(j+1)(2j+1)/6 + ⌊j⁶/24000⌋]` 端点差，无折扣）。金币不足禁用确认。确认后只改等级，当前批次不变，说明文字「升级自下一批生效」；成功 Toast「工位已升级」 |
| 选择配方／更换配方 | 空闲、等待材料和生产中均可进入 | 空工位的「选择配方」用绿色按钮。打开配方选择 Dialog，可选已研发的同类配方。更换配方后未完成的旧批次停止，已记录的投入退回仓库。新配方立即生效，材料齐备时开工，完工后自动续作 |
| 产线卡右上角叉号图标 | 已安排配方或存在活动批次 | 加工与精制卡的叉号带白色描边。直接清空安排与活动批次，恢复「选择配方」空闲卡；保留工位和购买序号，优先级恢复普通。只退回本批明确记录的投入，不发放未完成产品；缺少投入明细的旧批次不虚构退款 |
| 优先／普通 | 工位详情内 | 切换下一批争料优先级。点击处显示「已设为优先」或「已设为普通」 |
| 查看来源 | 材料不足时 | 直接进入对应物品的来源详情 |
| 查看研发条件 | 工坊来源链接指向尚未研发的品项 | 来源卡显示品项和对应工位，点击进入该品项的研发节点 |
| 调整保留量 | 库存够用但被预留 | 打开对应物品的加工保留量 Dialog |

配方选择使用可滚动的网格，保留来源筛选。详细模式每格显示小图、配方名、提速后的耗时和已安排该配方的工位数。普通宽度三列，窄屏两列，宽屏四列。

「缩小／放大」切换紧凑和普通视图。「批量管理」只列当前页面与来源筛选中的工位，支持批量更换、取消配方和统一升 1／5／10 级。升级合计沿用工位费用，更换和取消时退回中断批次已记录的材料。

### 数字布局

输入材料和产出区域分开。产出区明确列出「当前库存」和「本批产出」，例如 5 级新开批的面粉工位「当前库存 300.35T」「本批产出 60」。当前库存取仓库现有总量，排除在制品；本批产出取活动批次锁定数量（开批时按工位等级倍数 W 锁定的件数）。尚未开批时显示「每批产出」，取配方的目录基础批量乘当前工位等级倍率 W。升级后到下一批开批前，本批产出仍显示旧锁定量，「每批产出」与材料所需已按新等级显示。窄屏把两项堆叠，保留标签与数字。

工位等级显示为「Lv.L」，与卡片标题同行；数字过长时按[数字显示](../numbers.md)缩写。工位「升级」不显示红点；可负担升一级时为黄色可点击，否则灰色禁用，普通／缩小卡片与详情入口一致。批量管理升级按已选目标默认升一级的合计报价判断。下一级报价只在升级 Dialog 内显示，卡片不常驻报价。

材料行用「材料名 持有 / 所需」，如 3 级乡村面包工位「面粉 2 / 6」。持有指可投入库存，等于总库存扣除保留量后与 0 取较大值，所需按下一批「配方数量 × W」计算（W 为工位等级倍数），不足时等待整批。工位材料区仅展示继续生产所需的持有／所需。未满足时加图标和警示色，并提供「查看来源」；保留量造成不足时提供「调整保留量」。

工坊提速只缩短下一批的预计耗时，与工位等级无关。新批产出是配方的目录基础批量乘 W。面粉的基础批量为 12，工位等级 1／2／3／5／10／20 时，每批分别为 12／24／36／60／132／300 件。库存随实际完工变化。

### 本批与续作

「生产中」显示本批配方、剩余时间与本批产出。工位固定保留剩余栏和进度条。停工时进度条为空，剩余栏显示红字「暂停」，工位用红底白字标记「等待材料」「材料已预留」或「等待安排」。材料齐备自动开工。「更换配方」与「查看来源」仍可用。

居右显示模式图标按 [替换弹窗](fields.md#替换弹窗) 的偏好切换详细与仅图标；配方选择不显示额外即时生效说明和底部关闭按钮。生产进度条随画布帧更新，完工入库和新批次按实际模拟结算。

### 传送带动画

普通视图中，已安排配方的加工与精制工位在生产信息上方显示横向动画，工坊背景铺到卡片顶边和左右边缘。镜头平视机身正面，木质机器居中，两条木板带分别从左右画面边缘接入机身。运行时两侧带面均向右滚动。紧凑视图沿用配方图标与简要生产信息。

配方材料复用仓库图标，单行贴着传送带，从左侧画面外向右进入并被机身遮住。进料件数等于本批实际扣料（`batch.inputs` 各材料件数之和 n），先进料再制作：开工时第一件从左侧画面外进入，之后按进料最高密度连续送入，尽早送完；送完后带面照常转动但没有材料，直到下一批开工。只显示能在本批完工前进入机身的件数，材料不在带面中途出现或消失；批次短于一段可见带的穿越时间（约 3.1 秒）时不显示进料。材料顺序按配方与批次起点的稳定种子混排，不每帧随机。出料件数等于本批实际产出（`batch.amount`，Q 件）：完工时第一件立即从机身右侧吐出，其后在与该批同长的窗口内均匀吐出，后吐出的一件画在前一件之上；成品保持不透明，以带速滚出画面右边缘。进料间距固定为最高密度，即图标宽加 7 像素，互不重叠；本批时长内送不完时整批按该间距不停输送，显示件数少于实际数量。出料件数少时间距大，件数多时间距缩小，最小间距为成品图标宽的一半，后一件压住前一件约一半，每件可见；超过最高密度时按最小间距在整个窗口内不停吐出，带上不堆叠，显示件数少于实际数量。动画随真实批次展示，扣料、入库与任务统计由生产结算处理。

加工机、精制机、可平铺的木板带面、带体、齿轮、烟囱和烟团分别使用独立原画素材，材料和成品在运行时叠加。运行时机身轻微抖动，齿轮自转，烟囱排出向上飘散的半透明烟雾。停工时传送带、机身和齿轮停止，停止进料和排烟；已出料的成品可继续滚出画面。

动画仅挂载于可见卡片。滚出可见区、打开弹窗、切页或进入后台时卸载，异步素材完成后仅在卡片当前可见时挂载。已安排产线在素材加载中、加载失败、资料缺失或动画卸载时保留原区域，区域留空。空工位仍显示设施与「选择配方」。绘制、命中与动画均在现有 PixiJS 单画布中执行。

工坊显示当日有涨跌的产物和材料品名、倍率与方向图标，「选择配方」同样显示。详情中的直接机会增值按当日各品项实际成交价计算。

批量升级成功后保持升级弹窗和已选升档，更新余额、合计费用及按钮可用状态，玩家可再次点击；保存提交期间防止重复提交，资金不足或失败时不退出弹窗。
