# 工坊

[UI 索引](../../ui.md) · [数字显示](../numbers.md) · [反馈规则](../feedback.md)

「加工」「精制」两个页签分别显示中间产物和商品工位。每张卡显示当前配方、本批产出、产物当前库存、倒计时和材料状态。

| 按钮或点击区域 | 可用条件 | 点击动作与反馈 |
| --- | --- | --- |
| 加工／精制 | 常驻 | 切换工位列表，分别记忆滚动位置 |
| 增设加工位／增设精制位 | 对应工位未达上限 | 打开增设工位 Dialog，显示成本和现有数量。确认后创建空工位并定位。成功 Toast「已增设加工位」或「已增设精制位」 |
| 工位卡／详情 | 任意工位 | 打开工位详情 Dialog，显示本批产出、产物当前库存、续批预计耗时与材料、加工增值及优先级 |
| 选择配方／更换配方 | 空闲、等待材料和生产中均可进入 | 打开配方选择 Dialog，可选已研发的同类配方。更换配方后未完成的旧批次停止，已记录的投入退回仓库。新配方立即生效，材料齐备时开工，完工后自动续作 |
| 优先／普通 | 工位详情内 | 切换下一批争料优先级。点击处显示「已设为优先」或「已设为普通」 |
| 查看来源 | 材料不足时 | 直接进入对应物品的来源详情 |
| 查看研发条件 | 工坊来源链接指向尚未研发的品项 | 来源卡显示品项和对应工位，点击进入该品项的研发节点 |
| 调整保留量 | 库存够用但被预留 | 打开对应物品的加工保留量 Dialog |

配方选择使用可滚动的网格，保留来源筛选。每格显示小图、配方名和应用当前提速后的耗时。普通宽度三列，窄屏两列，宽屏四列。

### 数字布局

输入材料和产出区域分开。产出区明确列出「当前库存」和「本批产出」，例如面粉「当前库存 300.35T」「本批产出 1」。当前库存取仓库现有总量，排除在制品；本批产出取活动批次锁定数量。尚未开批时使用「每批产出」和当前配方计划量。窄屏把两项堆叠，保留标签与数字。

材料行用「材料名 持有 / 所需」，如「甘蔗 0 / 2」。持有指可投入库存，等于总库存扣除保留量后与 0 取较大值，所需按下一批配方的固定投入计算。工位材料区仅展示继续生产所需的持有／所需。未满足时加图标和警示色，并提供「查看来源」；保留量造成不足时提供「调整保留量」。

工坊提速只缩短下一批的预计耗时。产出区按配方显示固定件数，库存随实际完工变化。

### 本批与续作

「生产中」显示本批配方、剩余时间与本批产出。工位固定保留剩余栏和进度条。停工时进度条为空，剩余栏显示红字「暂停」，工位用红底白字标记「等待材料」「材料已预留」或「等待安排」。材料齐备自动开工。「更换配方」与「查看来源」仍可用。

居右显示模式图标按 [替换弹窗](fields.md#替换弹窗) 的偏好切换详细与仅图标；配方选择不显示额外即时生效说明和底部关闭按钮。生产进度条随画布帧更新，完工入库和新批次按实际模拟结算。
