# 图鉴

页面顶部保留经营管理员块，不再在其下显示图鉴小横幅。

| 页面内容 | 按钮或点击区域 | 动作与反馈 |
| --- | --- | --- |
| 已解锁数量 / 574、物品列表 | 全部／原料／中间产物／商品 | 切换品类 |
| 已开放和未开放条目 | 物品卡／查看研发 | 打开物品详情。未开放时可前往对应研发条目 |

一级品类页签滚动时吸附顶部。「商品」下的「全部／单类／双类／三类／四类」采用较小字号，五个等宽按钮单行铺满可用宽度，文字按按钮宽度缩放。物品列表和详情中的用途列表连续滚动，使用双栏物品卡。同一行的卡片按内容较高的一张对齐底边，完整显示标题与解锁状态。窄屏时使用单栏。

### 数字布局

图鉴包含 49 项矿业品项，详情的获取来源可跳转庄园矿洞或工坊。商品按实际生产来源数量筛选，三个来源归入「三类」，四个来源归入「四类」。跨产业商品可在其每个来源的筛选结果中找到。

总进度使用准确整数「已解锁 N / 574」。图鉴详情展示品类、配方或获取来源。库存查询放在仓库。

「配方材料」标题右侧的种类数与「共N件」保持完整单行，按真实文字宽度预留数量栏，必要时调整字号；不能把单位折到下一行或用固定行高裁掉文字。
