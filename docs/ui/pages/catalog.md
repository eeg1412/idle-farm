# 图鉴

[UI 索引](../../ui.md) · [数字显示](../numbers.md) · [反馈规则](../feedback.md)

| 页面内容 | 按钮或点击区域 | 动作与反馈 |
| --- | --- | --- |
| 已解锁数量 / 300、物品列表 | 全部／原料／中间产物／商品 | 切换品类 |
| 已开放和未开放条目 | 物品卡／查看研发 | 打开物品详情。未开放时可前往对应研发条目 |

物品列表和详情中的用途列表用双栏物品卡。同一行的卡片按内容较高的一张对齐底边，完整显示标题与解锁状态。窄屏或放大文字时使用单栏。

### 数字布局

总进度使用准确整数「已解锁 N / 300」。图鉴详情展示品类、配方或获取来源。库存查询放在仓库。
