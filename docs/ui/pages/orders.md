# 订单中心

订单中心建在大地图主路右侧，位于田地下方、鱼塘上方。点击建筑、门牌或右上菜单的「订单中心」进入，网址为 `#/orders`。每张订单显示商品名称、所需件数、当前库存和固定报酬；列表与弹窗均在同一 PixiJS 画布内操作。

所需件数和库存以件计，固定报酬以金币计。三项均按[数字显示规则](../numbers.md)缩写，例如 10,500 金币显示为「固定报酬　10.5K 金币」。

列表沿用田地的「缩小／放大」切换紧凑与普通视图，按可用宽度排布卡片。两档卡片与订单详情顶部的标题区居左排列：左侧为商品图，右侧上行为商品名称、下行为状态标签，文字块相对商品图垂直居中。商品图边长普通视图为 50，紧凑视图与订单详情为 34。浅蓝色「未接受」表示还可接单，金色「待备货」表示已接受但库存未齐，绿色「可交付」表示可以一次交齐。

点击普通或紧凑视图中的订单卡即打开详情，卡上省去箭头。生产链树直接显示在详情内，原料在上，经过各级加工品连到下方的订单商品；多条路径共用同一材料时只画一个节点，保留所有生产连线。每条配方只画一次、统一棕色：各材料向下汇到产物上方，以一个箭头进入产物；生产链不做选中高亮，卡片不加关系色边框。每张卡片的标签显示本单需要件数「需 N」：从订单件数起逐级按基础批量取整批数（批数 = ⌈需要件数 ÷ 每批产出⌉），乘以每批材料用量得到下级需要件数，多条路径共用的材料累加。

树的高度在底部固定的「接受／替换／交付／放弃」按钮栏测得后确定，铺满上方信息到按钮栏之间的可见空间，不被按钮栏遮挡；可见空间不足 170 逻辑像素时保持 170 并由详情滚动。树不设工具栏和图例说明，没有「查找节点」「－」「＋」按钮。树沿用[科研树](research.md#品种配方)的拖动平移、滚轮与双指缩放。打开详情时以常规缩放定位到订单商品，超出画框的部分可按住拖动平移；整条链在当前缩放下完全可见时，树居中且不平移。点树上节点打开全局物品详情（`src/view/item-chain.js` 的 `showItemDetail`，任何页面可调用）：顶部左图标、右名称与来源，下列当前库存，从订单进入时另列「本单需要」；其下以生产链树呈现，该物品居中高亮，上方为完整上游材料链，下方为直接以它为材料的物品（一层）。树的样式、拖动与高度规则同订单生产链；从订单进入时卡片标签显示本单「需 N」，否则显示来源。「本单需要」与「需 N」只在来源订单仍未结束，且商品、件数和报酬与进入时一致时显示；订单交付、放弃、过期、被替换或件数报酬变化后，已打开的物品详情保留，并按非订单形式显示：不列「本单需要」，卡片标签显示来源。点树中其他节点再打开该物品的详情，关闭后逐层返回。生产链与物品详情的树节点以指针点选。

| 状态 | 玩家操作 |
| --- | --- |
| 未接受 | 接受后锁定。当天还有替换次数、本轮已有至少三种候选商品且有可替换品时，可替换为另一种商品。 |
| 已接受 | 库存够整单时手动交付，也可放弃。加工保留量不减少可交件数。交付按确认时的实际库存结算。 |

点「放弃」先打开居中的「放弃订单」确认弹窗，正文为「确定放弃「商品名」×件数 的订单吗？」，下方一行灰色小字「订单作废，不发报酬，今日订单名额不返还。」，按钮为「再想想」和危险样式的「确认放弃」。点「确认放弃」才放弃订单；从详情进入时，放弃成功后同时关闭确认弹窗与详情。列表卡与详情的放弃流程相同。接受、替换、交付不经确认。

交付成功浮现「已交付 +报酬 金币」，报酬按[数字显示规则](../numbers.md)缩写；替换成功浮现「已替换」。操作失败不浮字。

有任一锁定单可整单交付时，地图订单中心门牌右上角亮圆点，位置与样式同其他建筑的提醒圆点；右上菜单的「订单中心」格子右上角同时亮圆点，与该格的回礼提醒为同一圆点，同位置同样式，任一条件成立即显示。订单中心页面自身的标题旁不显示圆点。交付、放弃、库存变化、周回及恢复存档后重新判断；另一张可交订单仍在时继续点亮。

配方和品种选择弹窗按锁定订单标记「订单商品」及「订单原料」。原料取整条实际生产链，包括中间产物，按物品 ID 去重。订单结束后，仅保留其他锁定单仍需要的标记。

订单中心使用独立岗位背景。男女管理员各有四表情立绘和一张完整开屏场景画，开屏按本岗当前选择抽取。新档与旧档缺少该岗位时默认选男性。两人沿用岗位资料、形象切换、送礼和回礼。打开 Dialog 后原对白继续，收礼后立即逐字感谢；从管理员列表点资料不触发额外对白。

订单列表在现有订单之后，为今日剩余名额各画一张统一空列表样式的占位卡（`orderPlaceholders`，不可点击），原因、倒计时与进度条都在卡内。第 i 张预计时刻为下次尝试 + i × 30 分钟，依次判定：可接商品不足→「能接的商品种类不够」；订单栏已满→「订单接满了」；晚于本地次日零点→「今天赶不上了」；否则「下一张订单在路上」+ 到该时刻的倒计时。本周目未产出商品时第 1 张显示最早商品批次的倒计时与进度条（无排产时提示去精制位做点商品），其余为「排在第一张订单之后」「首单后约 N 分钟到」。今日名额用完时只显示一张「今天的订单都来过了」卡，卡内为距次日倒计时。

订单管理员按其他岗位的情境帮助机制，在订单中心依当前订单给出帮助：有可整单交付的锁定单时提示交付，有未接受订单时提示接受，暂无订单时说明当前没有订单。可交付与未接受两条情境同时成立时两条都列出；全部订单已接受但均未备齐时不加情境帮助。奥林与茜梨各有一套帮助文案，分别符合各自人设；触发、对白队列、送礼与回礼机制同其他岗位。[经营、计价与跨日规则](../../tasks/2026-11-22-order-center.md)
