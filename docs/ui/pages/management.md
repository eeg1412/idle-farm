# 经营

[UI 索引](../../ui.md) · [全局导航](../navigation.md)

点击庄园地图的「经营」建筑或路牌打开此页，网址为 `#/management`。入口按下表顺序排列。每张浅奶油色圆角卡包含图标、标题、说明与向右箭头，整张卡均可点击。

| 入口 | 打开的页面 |
| --- | --- |
| 管理员管理 | [管理员与经营记录](../../tasks/2026-11-19-manager-expansion.md#管理员管理) |
| 统计 | [产销与累计统计](../../tasks/2026-11-19-manager-expansion.md#统计) |
| 出售庄园历史 | [出售时间与产值](../../tasks/2026-11-19-manager-expansion.md#出售庄园历史) |
| 图鉴 | [图鉴与收集](catalog.md) |
| 出售庄园 | [出售预览与确认](sell-farm.md) |

从上述页面返回时回到经营页。右上菜单也可直达这些页面。五个子页顶部沿用经营管理员，并介绍当前页面用途；对话与资料遵守[管理员提示规则](../../tasks/2026-11-19-manager-guidance.md)。

活动权益累积到出售庄园确认时结算为高级研发点。任务奖励在达成并成功保存时自动到账。
