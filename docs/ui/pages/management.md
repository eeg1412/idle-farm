# 经营

[UI 索引](../../ui.md) · [全局导航](../navigation.md)

点击第五个底栏标签「经营」打开此页，网址为 `#/management`。入口按下表顺序排列。每张浅奶油色圆角卡包含图标、标题、说明与向右箭头，整张卡均可点击。

| 入口 | 打开的页面 |
| --- | --- |
| 任务 | [入门与长期任务](tasks.md) |
| 图鉴 | [图鉴与收集](catalog.md) |
| 出售牧场 | [出售预览与确认](sell-farm.md) |

从以上页面返回时回到经营页。从页头右侧进入[设置](settings.md)。

活动权益累积到出售牧场确认时结算为高级研发点。任务奖励在达成并成功保存时自动到账。
