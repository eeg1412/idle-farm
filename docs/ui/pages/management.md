# 经营

[UI 索引](../../ui.md) · [全局导航](../navigation.md)

点击庄园地图的「经营」建筑或路牌打开此页，网址为 `#/management`。入口按下表顺序排列。每张浅奶油色圆角卡包含图标、标题、说明与向右箭头，整张卡均可点击。

| 入口 | 打开的页面 |
| --- | --- |
| 图鉴 | [图鉴与收集](catalog.md) |
| 出售庄园 | [出售预览与确认](sell-farm.md) |

从上述页面返回时回到经营页。设置入口位于[庄园首页](estate.md)。

活动权益累积到出售庄园确认时结算为高级研发点。任务奖励在达成并成功保存时自动到账。
