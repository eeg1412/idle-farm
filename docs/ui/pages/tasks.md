# 任务

[UI 索引](../../ui.md) · [数字显示](../numbers.md) · [反馈规则](../feedback.md)

从庄园地图的「任务」入口打开任务页。

「烤出乡村面包」之后显示「完成1件订单」，条件为手动交付成功一次，目的地为[订单中心](orders.md)。旧档已开放的长期目标继续可见，新任务仍可查看与完成。「第一次出货」的条件包含仓库销售和订单交付；同一次操作可完成两项任务，按各自回执结算一次。

| 页面内容 | 按钮或点击区域 | 动作与反馈 |
| --- | --- | --- |
| 根据进度自动显示入门任务、产业支线或长期目标；每卡显示完成条件、进度与奖励行 | 前往 | 导航到对应页面。入门主线与产业支线任务到达后由该页管理员讲本页指导，见[前往演出](#前往演出)。生产、交易、升级和研究仍由玩家操作，完成后自动发放一次金币与研发点 |
| 「未完成」页签的入门主线与产业支线任务卡 | ？（位于「前往…」左侧） | 任务管理员讲该任务的固定说明，见[任务讲解](#任务讲解)。长期任务与「已完成」页签不显示 |

产业支线所需品项尚未研发时，任务卡按钮显示「前往研究」并定位到要研发的品项（研发缺口最少，并列取研发金币最少，再并列取 ID 最小）。升级类任务金币不足时按钮显示「前往出货」，与扩建田地缺钱时相同。

说明文字下方为吸顶分段页签「未完成」「已完成」，网址分别为 `#/tasks?tab=active`、`#/tasks?tab=done`，无有效页签时打开「未完成」。「未完成」在入门期显示尚未完成的入门任务及已显示的产业支线；入门完成后先列未完成的产业支线，再列未完成的长期目标；「已完成」按入门与已显示支线在前、长期目标在后列出全部已完成任务。已完成任务永久冻结：进度按目标封顶显示为「目标 / 目标」，按钮显示禁用的「已完成」。列表为空时分别显示「全部任务已完成。」「暂无已完成任务。」。切换页签回到列表顶部，并替换当前浏览器记录。

任务自动完成时，任务列表和庄园地图的当前任务提示同步更新。入门任务完成后，「未完成」页签自动改为先列未完成的产业支线、再列长期目标，并显示一次 Toast「长期目标已开放」。长期目标继承此前累计的进度。出售庄园后继续使用已保存的入门完成记录、长期目标及累计进度。旧档按实际完成的入门步骤判断当前阶段。

全部 74 项任务分为入门主线 17 项、产业支线 19 项、长期 38 项，其中六项长期任务累计成功品质抽数。首次出货只发金币，另发 300 个时空胶囊；`collection200/300/400`、`itemCollection`、`runs5/20/50/100` 另发高级研发点，与金币同一 Toast 显示。[逐任务奖励](../../game-design.md#83-任务系统)每个任务 ID 只奖励一次，完成与领取不要求当前正在显示该任务。余额、未花研发点和领取记录一起保存，成功后才在 Toast 显示本次任务奖励合计，格式见[反馈](../feedback.md)。原有成功 Toast 与奖励合并，不增加领取按钮、弹窗或音效。周回和读档保留领取状态；关闭或重看操作说明不改变任务状态。奖励增加金币，部分长期任务另加固定研发点；均不计售货数量、收入、产值或 T/credit。

产业支线在首次成功出货后显示，按畜牧、水产、矿业、复合、经营分组。未完成任务按当前计数显示进度，完成并到账后永久完成，出售庄园或等级重置不再改变其进度与状态。

「经营交接」与「五次／二十次／五十次／百次交接」共 5 项带累计产值门槛：次数达标但累计产值未达门槛时不算完成、不发奖，任务卡奖励行在图标项之后接文字「需累计产值 X」，X 按[数字显示](../numbers.md)缩写；达到门槛后的下一次成功提交自动到账。不新增控件。

### 管理员横幅指导

顶部横幅由任务管理员讲当前任务的下一步。入门主线进行中讲当前主线任务；主线全部完成后讲第一个未完成的产业支线。指导按存档实际状态点名对象：

- 支线所需品项未研发时，点名要研发的品项（选取顺序同任务卡「前往研究」），研究页同样显示该指导；矿业另列出研发材料与金币。
- 升级类任务金币不足时，先指向仓库出售。
- 「扩充配方」点名下一项要研发的配方。
- 已有田地或工位时，「扩建田地」「添置料坊位」「添置工房位」说「再添一个」。
- 高级研发点不足时，说明高级研发点来自出售庄园。
- 「研发乡村面包」材料不足时，点名所缺材料。
- 「完成1件订单」备货期间显示还差几件；当前没有订单时，显示距下一单的分钟数，并给出下一项主线任务的指导。

气泡逐字换行时，开引号后紧跟闭合标点（如「？」）作为一组排版，不拆到两行。

### 任务讲解

点击任务卡「？」：

1. 顶部横幅背景保留；横幅中的任务管理员立绘向下沉出横幅（被横幅裁切），气泡与按钮在 0.2 秒内淡出。
2. 画面压暗，任务管理员从画布底部中间升起，头顶气泡逐字讲该任务的固定说明。打字中点击补全当前句；讲完后点击，管理员退下。
3. 退下后顶部横幅的立绘从横幅底边升回，气泡与按钮淡入，对白从原句继续。

第 1 步与第 2 步、第 2 步退下与第 3 步依次进行：顶部立绘在视口内可见时，先完成下沉，底部管理员才升起；底部管理员退下完成后，顶部立绘才升回。顶部立绘不在视口内时不播放下沉与升回，底部管理员立即升起，结束后横幅直接恢复显示。压暗在点击「？」时立即出现，底部管理员升起前的点击无效。

讲解期间页面其他操作不可用。固定说明共 36 项（入门主线 17 项、产业支线 19 项），按任务管理员性别分男女两版。

### 前往演出

入门主线与产业支线任务卡的「前往…」「前往出货」「前往研究」，每次点击都把该任务 ID 作为来源带到目标页；长期任务的「前往」不带来源。来源不写入网址：浏览器后退、刷新或直接打开网址进入页面时不演出。

到达目标页后：

1. 该页顶部横幅的管理员直接处于隐藏状态，不播放消失动画；画面压暗。
2. 该页自己的管理员按岗位当前性别从画布底部中间升起，逐字讲来源任务在本页的动态指导。岗位对应：田地 field、畜牧 livestock、鱼塘 fish、矿洞 mine、料坊 processing、工房 refining、仓库 warehouse、研究 research、订单中心 orders、图鉴与出售庄园 estate。
3. 讲完后点击，管理员退下；顶部横幅的管理员按可见性规则升回，对白从原句继续。

点击补全、讲完关闭、演出期间其他操作不可用，均与[任务讲解](#任务讲解)相同。

指导按来源任务取，不按当前主线取，并覆盖全部落点分支：

- 本页落点：按该页各状态讲下一步（与横幅指导同口径）。
- 「前往出货」到仓库：金币不足时讲去出售攒钱；金币已足够时讲回原页操作。
- 「前往研究」到研究页：点名要研发的品项；已解锁时讲回原页安排生产。
- 出售庄园页：入门主线未完成时讲先完成入门主线。出售庄园页横幅的日常指导在同一条件下也这样讲。

指导为空（来源任务已完成、本页不是该任务的落点等）时不演出，页面照常显示。

### 新手开场

新建庄园的开场在大地图点击任务公告栏后进入任务页（地图段见[庄园首页](estate.md#新手开场)）：

1. 进入任务页时解除大地图的晴天锁定，之后按天气规则在 10–30 分钟后重新抽取。
2. 顶部横幅的任务管理员直接处于隐藏状态，不播放消失动画。
3. 画面压暗，任务管理员从画布底部中间升起，逐字讲 3 句任务页说明。点击任意处：打字中补全，补全后进入下一句；不设跳过。
4. 第 3 句讲完后点击，管理员退下，此时开场记为完成并保存（`completeIntro`）。顶部横幅的管理员按[任务讲解](#任务讲解)第 3 步回来，对白从原进度继续。

开场完成前关闭游戏或刷新，下次加载从大地图段重新开始。

### 数字布局

任务标题占独立一行，下一行用玩家能执行的操作说明完成条件。当前值和目标各占固定的右对齐区域，空间不足时使用上下两行，尤其是累计经营收入。有限目标如扩建 10 块田仍显示准确整数。

奖励行在完成条件下方，「未完成」「已完成」两页签相同：金币、高级研发点、时空胶囊依次显示为「图标＋缩写数值」项，图标约为字号的 1.2 倍，项间留间距，宽度不足时换行；值为 0 的项不显示，不写资源名称、不用「+」连接。未领取时奖励行文字为灰色。

品质任务目标依次为 6／30／120／360／1,080／3,240 次成功抽取。旧档已有的品质等级不折算抽数。已领取的六项品质任务继续显示「已完成」。科技全满目标为 1,762 级，首次完成发放 11,000,000 金币。已领取的科技全满卡显示完成条件与「已完成」，不显示奖励行。
