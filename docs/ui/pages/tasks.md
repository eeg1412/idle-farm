# 任务

[UI 索引](../../ui.md) · [数字显示](../numbers.md) · [反馈规则](../feedback.md)

从庄园地图的「任务」入口打开任务页。

「烤出乡村面包」之后显示「完成1件订单」，条件为手动交付成功一次，目的地为[订单中心](orders.md)。旧档已开放的长期目标继续可见，新任务仍可查看与完成。「第一次出货」的条件包含仓库销售和订单交付；同一次操作可完成两项任务，按各自回执结算一次。

| 页面内容 | 按钮或点击区域 | 动作与反馈 |
| --- | --- | --- |
| 根据进度自动显示入门任务、产业支线或长期目标；每卡显示完成条件、进度、奖励金币、有研发点奖励的另显示研发点数，以及「已到账」状态 | 前往 | 导航到对应页面。生产、交易、升级和研究仍由玩家操作，完成后自动发放一次金币与研发点 |

说明文字下方为吸顶分段页签「未完成」「已完成」，网址分别为 `#/tasks?tab=active`、`#/tasks?tab=done`，无有效页签时打开「未完成」。「未完成」在入门期显示尚未完成的入门任务及已显示的产业支线；入门完成后先列未完成的产业支线，再列未完成的长期目标；「已完成」按入门与已显示支线在前、长期目标在后列出全部已完成任务。已完成任务永久冻结：进度按目标封顶显示为「目标 / 目标」，按钮显示禁用的「已完成」，并保留「已到账」。列表为空时分别显示「全部任务已完成。」「暂无已完成任务。」。切换页签回到列表顶部，并替换当前浏览器记录。

任务自动完成时，任务列表和庄园地图的当前任务提示同步更新。入门任务完成后，「未完成」页签自动改为先列未完成的产业支线、再列长期目标，并显示一次 Toast「长期目标已开放」。长期目标继承此前累计的进度。出售庄园后继续使用已保存的入门完成记录、长期目标及累计进度。旧档按实际完成的入门步骤判断当前阶段。

全部 74 项任务分为入门主线 17 项、产业支线 19 项、长期 38 项，其中六项长期任务累计成功品质抽数。首次出货及 `collection200/300/400`、`itemCollection`、`runs5/20/50/100` 另发高级研发点，与金币同一 Toast 显示。[逐任务奖励](../../game-design.md#83-任务系统)每个任务 ID 只奖励一次，完成与领取不要求当前正在显示该任务。余额、未花研发点和领取记录一起保存，成功后才显示「已到账」及本次任务金币与研发点合计。原有成功 Toast 与奖励合并，不增加领取按钮、弹窗或音效。周回和读档保留领取状态；关闭或重看操作说明不改变任务状态。奖励增加金币，部分长期任务另加固定研发点；均不计售货数量、收入、产值或 T/credit。

产业支线在首次成功出货后显示，按畜牧、水产、矿业、复合、经营分组。未完成任务按当前计数显示进度，完成并到账后永久完成，出售庄园或等级重置不再改变其进度与状态。

「经营交接」与「五次／二十次／五十次／百次交接」共 5 项带累计产值门槛：次数达标但累计产值未达门槛时不算完成、不发奖，任务卡奖励文字同一行后接「 · 需累计产值 X」，X 按[数字显示](../numbers.md)缩写；达到门槛后的下一次成功提交自动到账。不新增控件。

### 数字布局

任务标题占独立一行，下一行用玩家能执行的操作说明完成条件。当前值和目标各占固定的右对齐区域，空间不足时使用上下两行，尤其是累计经营收入。有限目标如扩建 10 块田仍显示准确整数。

品质任务目标依次为 6／30／120／360／1,080／3,240 次成功抽取。旧档已有的品质等级不折算抽数。已领取的六项品质任务继续显示「已完成」「已到账」。科技全满目标为 1,762 级，首次完成发放 11,000,000 金币。已领取的科技全满卡只显示「完成」「已到账」状态，不再显示奖励金额。
