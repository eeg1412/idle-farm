# 任务

[UI 索引](../../ui.md) · [数字显示](../numbers.md) · [反馈规则](../feedback.md)

| 页面内容 | 按钮或点击区域 | 动作与反馈 |
| --- | --- | --- |
| 根据进度自动显示入门任务或长期目标；每卡显示奖励金币与「已到账」状态 | 前往 | 导航到对应页面。生产、交易和研究仍由玩家操作，完成后自动发放一次金币 |

任务自动完成时，任务列表和牧场的当前任务提示同步更新。入门任务完成后，任务页自动切换到长期目标，并显示一次 Toast「长期目标已开放」。长期目标继承此前累计的进度。出售牧场后继续使用已保存的入门完成记录、长期目标及累计进度。旧档按实际完成的入门步骤判断当前阶段。

全部 24 个任务使用[逐任务金币表](../../tasks/rewards-2026-11-15.md)。每个任务 ID 只奖励一次，完成与领取不要求当前正在显示该任务。余额和领取记录一起保存，成功后才显示「已到账」及本次任务奖励合计。原有成功 Toast 与奖励合并，不增加领取按钮、弹窗或音效。周回保留领取状态，旧档依据可证实的完成条件补发一次；跳过或重看导览不当作完成。任务奖励不计售货收入、出售数量、产量或生产总值。

### 数字布局

任务标题占独立一行。当前值和目标各占固定的右对齐区域，空间不足时使用上下两行，尤其是累计经营收入。有限目标如扩建 10 块田仍显示准确整数。

「百级名品」读取已研发品项中的最高品质等级，目标为 100。品质超过目标时显示已完成，经营数据继续累积。
