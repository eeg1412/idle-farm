# 出售牧场

[UI 索引](../../ui.md) · [数字显示](../numbers.md) · [反馈规则](../feedback.md)

页面保留本轮生产总值、评估倍率、预计高级研发点、保留与清空内容及新一轮配置。生产总值使用单个缩写金额，例如 `620`，不是领取门槛。预计点数独占一行，直接读取 `farmSaleOffer.reward`，包含未结新制收益及尚未领取的旧制冻结奖励，不用本轮总值在界面另算点数。

倍率标为「后续生产评估倍率」：升级只影响之后实际生产事件，不重算已有收益。点数只在确认出售时领取，未满一点的收益跨轮保留。内部累计账与精度余额不显示为新货币，也不提供园内领取入口。

| 按钮 | 动作 |
| --- | --- |
| 出售牧场 | 任意生产总值均可打开确认面板 |
| 确认出售 | 提交最新完整报价快照。经营记录或点数变化时刷新并要求再次确认。成功后在同一事务发点、重置本轮并返回田地 |
| 继续经营 | 关闭确认面板，继续本轮 |

任意产值均可出售，包括0。实际报价为0点时，确认面板明确说明此次可获得0点，「确认出售」仍可用。累计3000活动金币对应无评估加成的300基础点，只是收益示例，不是资格门槛。出售取消时保留原记录。图中金额、点数和倍率均可缩写。

出售后不保留原工位，恢复加工位、精制位各1个初始空闲工位。旧配方、优先级与在制批次清空，原投入不返还。预览、确认清单和操作说明均按此规则显示；研发、品质、经营改良和历史任务进度仍保留。

基础开局金币仍为60；首次出售且尚未领取的「经营交接」任务另奖励50金币，与出售事务一起到账，故首次空轮新周回为110金币，以后60。任务原条件仍为 `completedRuns≥1`，不增加产值或出货资格要求。预览／确认通过任务奖励映射单独显示该奖励；以后周回不重复发钱。任务奖励与高级研发点分开，领取ID跨周回保留。
