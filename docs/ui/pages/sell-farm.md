# 出售牧场

[UI 索引](../../ui.md) · [数字显示](../numbers.md) · [反馈规则](../feedback.md)

页面保留本轮生产总值、评估倍率、预计高级研发点、保留与清空内容及新一轮配置。生产总值使用单个缩写金额，例如 `620`，不是领取门槛。预计点数独占一行，读取 `farmSaleOffer.reward`，由累计活动权益按兑换门槛计算。

「保留」「清空」「工坊重置」「新一轮」使用纯文字清单，行背景随文字换行增高。

倍率标为「后续生产评估倍率」：升级只影响之后实际生产事件，不重算已有收益。点数只在确认出售时领取，未满一点的收益跨轮保留。内部累计账与精度余额不显示为新货币，也不提供园内领取入口。

| 按钮 | 动作 |
| --- | --- |
| 出售牧场 | 任意生产总值均可打开确认面板 |
| 确认出售 | 提交最新完整报价快照。经营记录或点数变化时刷新并要求再次确认。成功后在同一事务发点、重置本轮并返回田地 |
| 继续经营 | 关闭确认面板，继续本轮 |

任意产值均可出售，包括0。实际报价为0点时，确认面板明确说明此次可获得0点，「确认出售」仍可用。新档两块基准麦田连续两小时产值 360,000 金，评估 0 级时可领取 18 点。出售取消时保留原记录。图中金额、点数和倍率均可缩写。

出售后不保留原工位，恢复加工位、精制位各1个初始空闲工位。旧配方、优先级与在制批次清空，原投入不返还。预览、确认清单和操作说明均按此规则显示；已研发品项、品质、经营改良、未花高级点、普通点与时间余量、抽取累计、当日行情和已用额度、累计产值、活动权益余量和任务进度跨轮保留。

新一轮使用 `600m` 金币（当前 3,000）、两块已播小麦的一级田及各一个一级空闲加工位和精制位。「经营交接」任务需完成至少一次出售并累计产值达到 `520,000m`（当前 2,600,000），达成时一次发 `5,200m` 金币（当前 26,000）。首次出售时已达到产值门槛且未领奖，预览与确认另列这笔金币。任务奖励单独结算，领取凭据跨轮保留。
