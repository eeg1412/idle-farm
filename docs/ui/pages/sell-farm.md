# 出售牧场

[UI 索引](../../ui.md) · [数字显示](../numbers.md) · [反馈规则](../feedback.md)

页面依次显示预计高级研发点、单个本轮生产总值、经营评估倍率、保留与清空内容、新一轮配置。生产总值使用单个缩写金额，例如 `620`。预计点数独占一行。生产总值低于门槛时可显示「生产总值满 1K 开始发点」。

| 按钮 | 动作 |
| --- | --- |
| 出售牧场 | 任意生产总值均可打开确认面板 |
| 确认出售 | 同步最新生产总值和倍率。点数变化时刷新并要求再次确认。成功后发点、重置本轮并返回田地 |
| 继续经营 | 关闭确认面板，继续本轮 |

生产总值低于 1,000 时显示预计 0 点，确认面板明确说明此次可获得 0 点。「确认出售」保持可用。出售取消时保留原记录。图中金额、点数和倍率均可缩写。

出售后不保留原工位，恢复加工位、精制位各1个初始空闲工位。旧配方、优先级与在制批次清空，原投入不返还。预览、确认清单和操作说明均按此规则显示；研发、品质、经营改良和历史任务进度仍保留。
