# 数字显示与窄屏布局

[UI 索引](../ui.md) · [界面验收](qa.md)

## 1. 显示格式

金币、库存、产出、成本与研发点使用任意精度整数。缩写仅用于显示，其中的小数位表达量级。实际交易、研究、生产和存档仍以原始整数处理。需要直接录入整数的其他控件，例如加工保留量，接受整数字符串和规范化后的全角数字，拒绝小数、逗号、后缀及指数写法。出售使用百分比滑条。

| 绝对值 | 默认摘要格式 |
| --- | --- |
| 小于 10000 | 分组整数，如 `9,999` |
| 10000 至小于 10⁶ | 除以 10³ 后加 `K` |
| 10⁶ 至小于 10⁹ | 除以 10⁶ 后加 `M` |
| 10⁹ 至小于 10¹² | 除以 10⁹ 后加 `B` |
| 10¹² 至小于 10¹⁵ | 除以 10¹² 后加 `T` |
| 10¹⁵ 及以上 | 继续按千进位使用大写字母后缀，例如 `AA / AB / AC / … / AZ / BA` |

取绝对值计算。在摘要格式中最多保留两位小数，向零截断，去掉末尾零及空小数点。单位按原始绝对值决定。用整数运算取得 `abs × 100 // divisor`，其中 `divisor = 1000^g`，`g = floor((十进制位数−1)/3)`。第 1–4 组使用 K、M、B、T。第 5 组起，把 `g+22` 转成以 A=1、Z=26 的列名编码。每次先减 1，再除以 26 取余数映射 A–Z，从后向前拼接。序列为 AA、AB、…、AZ、BA、…、ZZ、AAA。玩家界面统一使用字母后缀。加工增值为负时，缩写前加负号。零统一显示 `0`。数量比较、研发条件、成交校验和进度条都读取原值。

| 原值 | 期望显示 |
| --- | --- |
| `9999` | `9,999` |
| `10000` | `10K` |
| `999999` | `999.99K` |
| `1000000` | `1M` |
| `100250000` | `100.25M` |
| `200250000000` | `200.25B` |
| `300350000000000` | `300.35T` |
| `-100250000` | `-100.25M` |
| `10^15` | `1AA` |
| `10^18` | `1AB` |
| `10^120+9` | `1BJ` |
| `123 × 10^118` | `1.23BJ` |

## 2. 哪些位置可缩写

| 场景 | 显示 |
| --- | --- |
| 顶部余额、库存列表、持有量摘要、长期任务进度、牧场出售预览 | 可缩写。长数字放入独立列或独立行，相关详情可查完整值 |
| 金币或物品浮动小字、Toast | 可缩写。状态详情或主页面余额提供准确值入口 |
| 出售数量、单价、预计得款、研发扣费、购买和升级确认、周回最终奖励 | 可缩写，必要时可从详情查看完整值。出售确认面板默认显示缩写 |
| 田地等级、每批产量、库存和成本可缩写；图鉴计数、百分比与时间 | 图鉴计数和百分比使用整数，时间按时分秒展示 |

确认时始终用原始整数重新校验。原值发生变化时，即使摘要相同，也按对应交易规则刷新报价。

## 3. 窄屏与超长值

- 数字优先使用等宽数字，库存与单价列分别右对齐。用当前字体、字号及 PixiJS 文本测量结果判断宽度。
- 摘要先用两位小数。放不下时依次尝试一位、零位，再把金额移到单独一行。按钮、品名和单位保持可识别。字母后缀过长仍无法容纳时，显示「查看完整数值」入口。
- 完整数占独立行，按三位数字分组折行。数量编辑时保持画布内的水平滚动及光标可见。确认面板内容可纵向滚动，操作按钮保留在可到达区域。完整值可复制，剪贴板返回原始数字字符串。
- 在320逻辑像素和固定100%文字下，数字与操作可上下排列。旋转后重新测量并保留输入值、选项和Dialog。

## 4. 高级研发点的显示空间

研究页余额、牧场出售预览与确认均采用同一排版。上方单独显示「高级研发点」或「预计获得高级研发点」，图标和查看详情入口放在标签行。下方整行用于数值，右对齐。数值行覆盖整个游戏内容区，只从游戏区安全宽度扣除总计 32 逻辑像素的左右留白，不与单位、图标、按钮或第二个金额分列。320 宽且无额外安全区时，可用数字行宽至少 288 逻辑像素。

验收在320宽及固定100%文字下用 `999.99T`、`1.23BJ` 和更长的字母后缀走查。常用缩写以两位小数优先，异常长的后缀走第3节的降级与查看完整数值入口。确认按钮保持独立一行。

## 倒计时与批次进度

倒计时数字与进度条使用同一连续模拟展示时钟，格式仍向上取整到秒。文字仅在显示内容变化时更新，进度条逐帧绘制；不以全局整秒快照作为剩余时间的唯一来源，不将展示推进封顶为1秒。

田地、畜牧、鱼池和工坊按稳定设施／工位引用读取当前展示批次；旧条满格后不能停止监听下一批。主显示在真实批次结束边界及时只读投影，按压／拖动延后重绘时现有数字与条仍从新批次读取，不能卡在旧批次的1秒或满格。普通异步保存不阻止只读展示，真实经营推进与提交顺序保持原规则。

换档、清档和出售成功重置展示时钟，防止旧档较大的时刻影响新档。前后台恢复仍先完成受离线上限约束的结算，再恢复连续展示；不能用前台外推绕过离线时长上限。验收需获得用户授权，本轮仅源级实现。
