# Dialog、Toast 和浮动小字

[UI 索引](../ui.md)

| 反馈 | 何时使用 | 位置与时长 | 交互规则 |
| --- | --- | --- | --- |
| Dialog | 需要选择、输入、确认，或读取重要详情 | 从底部打开面板。周回确认、存档恢复用居中面板；标题栏和底部操作区固定，仅内容可滚动 | 同时只显示一个。遮罩拦截底层事件。关闭图标使用厚重图形交叉；关闭后恢复来源焦点。涉及扣费或重置时通过明确按钮确认 |
| Toast | 需要在页面上被注意的短消息，例如解锁、建造、阶段切换或操作失败 | 游戏区顶部安全区下方，同一时刻只显示一条，默认 2.5 秒 | 不阻断操作。重复同类提示合并。能当场处理的失败持续显示在原控件或 Dialog 内 |
| 点击处浮动小字 | 高频操作的轻反馈，内容可由余额、卡片、列表或状态复核 | 以触点为起点，向上约 24 逻辑像素，约 650 毫秒后渐隐消失 | 不拦截点击、不跟踪指针。键盘触发以控件中心为起点。同一控件短时间重复触发时替换旧文字 |
| 行内状态 | 持续信息、材料不足、按钮不可用原因 | 就近放在相关卡片、输入框或确认按钮旁 | 条件改变时更新。无法执行时显示持有／所需和可用入口 |

浮动小字约束在游戏区安全边界内。确认后关闭 Dialog 时，用提交瞬间记录的点击坐标绘制。横竖切换时清除旧布局的短暂动画，保留业务状态。相同操作只显示一种成功反馈。所有扣费、出货和研发的成功提示在 IndexedDB 提交成功后出现。浮动小字按[数字显示](numbers.md)缩写。出售确认展示百分比、对应数量与预计得款。

## Dialog 清单

| Dialog | 内容 | 确认与关闭 |
| --- | --- | --- |
| 田地详情／工位详情／物品详情 | 当前状态、投入或产出、来源、用途和可执行操作 | 标题栏唯一关闭图标回显式上级；不重复放底部关闭／纯返回按钮 |
| 种子选择／配方选择 | 已研发选项、产出和时间；显示模式用居右图标切换 | 选中立即提交安排；配方选择不显示重复说明或底部关闭按钮，使用标题栏关闭图标 |
| 购地／增设工位／地块升级 | 成本、当前金币和结果 | 确认购买或升级／取消 |
| 加工保留量 | 整数，显示实际效果 | 保存／取消 |
| 单品出售 | 百分比滑条、对应出售数量、预计得款和保留量影响 | 确认出售／取消。报价变化时重新确认 |
| 种子与配方研发／品质提升／经营改良 | 费用、前置、效果与持有／所需 | 对应研发或升级按钮／关闭 |
| 操作说明 | 收获、工坊、研发、出售、购地流程 | 上一步／下一步／关闭 |
| 离开期间收获 | 离线有效时长、实际产出和库存变化 | 知道了。产出已写入存档 |
| 出售庄园确认 | 本轮生产总值、倍率、最终奖励、保留与清空项目、新一轮配置 | 确认出售／继续经营 |
| 存档恢复 | 记录无法读取时展示可用备份时间及回退影响 | 恢复上次记录／返回。无可用备份时显示相应状态 |

从详情进入编辑 Dialog 时替换当前面板。取消编辑可返回原详情。返回键与 Escape 执行当前 Dialog 的取消或关闭动作。焦点留在已打开的 Dialog 内。提交期间禁用确认键，待提交结果确定后恢复关闭操作。涉及支付、出售、跳过和存档恢复时，点击遮罩保持面板打开。

每个弹窗只有一个通用关闭入口，位于标题栏；纯「关闭」「返回」尾按钮移除。底部仍保留取消／确认、说明完成、收获汇总确认等业务动作。关闭恢复创建时标记的父弹窗或来源页面，不能简单退回浏览器历史的上一条筛选／URL。

## 提示分配

| 场景 | 反馈 |
| --- | --- |
| 自动收成、批次完成、自动开批 | 更新卡片和库存。离线收成合并展示 |
| 保存换种或配方、改优先级 | 点击处浮动小字，卡片保留最终状态 |
| 出售成功、地块升级、品质提升、保存保留量、复制成功 | 点击处浮动小字，仓库或详情更新 |
| 增设工位、购地、首次开放长期任务、永久改良、庄园出售成功 | Toast |
| 研发解锁 | Toast |
| 资金不足、数量无效、材料不足、报价变化 | 行内展示。确认操作无法执行时保留当前输入 |
| 复制失败、暂时无法保存 | Toast。存档无法恢复时打开存档恢复 Dialog |
| 切换页签、筛选、翻页、数量加减、点击任务入口 | 控件选中态或页面变化 |
