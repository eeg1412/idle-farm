# 全局导航与画布布局

[UI 索引](../ui.md) · [数字显示](numbers.md)

首次进入打开[大地图](pages/estate.md)，网址为 `#/farm`。地图固定显示金币和菜单按钮。游戏各页右上角均可展开菜单，入口采用上方像素图标、下方名称，包含大地图、各设施和全部功能页；「设置」排在最后并独占一整行。点击条目切页，点击菜单按钮或菜单外区域可收起。菜单格子的提醒圆点统一画在格子右上角：对应岗位有可领回礼时亮点，「角色管理」在任一岗位有可领回礼时亮点，「订单中心」在有可整单交付的锁定订单时亮点，同一格的多个条件合并为一个圆点。页签和 Dialog 在所属页面内打开。

含「全部」的紧凑筛选组各占一行，包括工坊和配方选择、仓库和图鉴，以及研究查找节点的来源筛选。组内按钮等宽，整组铺满与相邻内容相同的可用宽度，首尾按钮分别与相邻内容的左右边缘对齐。标签以 15 逻辑像素为基准单行显示，按钮间距 2 逻辑像素，命中高度至少 44 逻辑像素。320 逻辑像素竖屏下仍保持单行和边缘对齐。

其他页面的页名由顶栏显示，左侧放置图形返回按钮。场景横幅保留原图，省略重复页名和标题遮罩。研究的「品质」显示普通研发点，「经营改良」显示高级研发点。出售庄园显示预计获得的点数，含点数奖励的任务显示对应额度。方向、返回、展开和翻页箭头均用图形。图鉴从经营、仓库或研究详情进入，行脚商从地图摊车或菜单进入，与仓库同为独立功能页，出售庄园从经营进入。跨页跳转到具体物品或研发节点时，打开目标所在页签并定位到该项。

页面与主操作页签使用 URL 片段，例如 `#/research?tab=quality`。图鉴与研发的指定品项可附加 `item`。游戏内的浏览器后退按当前页面、详情或弹窗记录的上一级返回。浏览器前进仍可恢复有效的游戏记录。弹窗的数字输入与筛选保留在当前游戏会话中。重新打开链接时恢复页面、页签及品项，已失效的确认窗口回到所在页面。

### 返回上级与来源

从地图进入的页面点返回按钮或按 Escape 时回到地图原滚动位置。页内继续跳转时，返回按实际来源还原页面、页签、物品、弹窗、筛选、用途展开、滚动和研究视口。返回优先处理当前弹窗和详情父层，其次处理页面来源。行脚商的页面父级固定为大地图，不继承仓库或其他跳入页；地图上下文存在时保留其原滚动位置。

图鉴列表进入详情时保存列表原筛选和滚动；详情的材料／用途再进入另一物品时保存上一物品完整快照。返回优先当前弹窗的父弹窗／来源页，再本页物品父层，最后页面父上下文。外部直接进入某物品详情时不虚构一个先访问过的图鉴列表。研究从外部打开指定节点详情时，该首个详情关闭返回来源；本页正常选择的新节点关闭后留在研究页。

关闭弹窗时优先复用浏览器里已存在的父级记录。通过菜单或直接打开页面链接时，图鉴、出售庄园、角色管理、统计、出售庄园历史的上一级是经营，行脚商的上一级是大地图，其余功能页的上一级是大地图。直接打开页面链接时，父级返回记录在首次点击或按键时补入；首次互动前直接按浏览器返回，受浏览器限制会离开网站。研究的「品种配方／品质／经营改良」、行脚商的「买入／卖出」和任务的「未完成／已完成」页签切换替换当前浏览器记录，不额外堆积后退层级；从大地图进入后，无论切换多少次页签，浏览器返回仍回到大地图。研究详情和业务弹窗继续逐层返回。行脚商切页签仍释放临时销售预留并清除旧报价／数量，不改变交易规则。其他普通游戏页签的前后切换保留可恢复记录。不带页签的 `#/workshop` 打开加工。导入、清除存档或成功出售庄园后回到地图并清理旧返回状态和确认弹窗。

竖屏画布铺满视口，交互控件避开系统安全区。横屏游戏区以 390:844 限制最大宽度，居中显示，两侧纯黑且不响应游戏操作。方向切换保留当前页面、选项、数量输入和 Dialog。游戏画面、点击区域、数字键盘和反馈均在同一个 PixiJS 画布内。

### 画布样式

功能页使用暖米色背景与圆角卡片，文字使用深绿，分隔线使用浅棕，选中页签为绿色。购买与播种采用绿色，升级及重要确认采用金黄色。画布图形与字体边缘平滑，所有像素贴图采用最近邻采样和像素位置对齐。

### 数字区域

首页金币使用独立数字区域，菜单按钮与金币块等高。窄屏自动缩小金币字号，余额只读。功能页装饰横幅紧贴顶部导航，设置页标题在游戏区水平居中。页签之间不画分割线，图鉴一级页签滚动时吸附顶部。游戏区内的宽度测量以 PixiJS 实际字形为准。
# 滚动

可滚动容器的半透明滚动条贴右边缘，不占内容宽度。滑块随可见比例改变长度，支持直接拖动。手指或鼠标滑动内容后，松手保留惯性并逐步减速；到达边界、切页或再次按下时停止。弹窗只允许内容区滚动，标题栏和底部按钮区始终固定。


### 网页图标与PWA

页面head提供favicon、Apple触屏图标与manifest。安装后使用独立窗口显示同一单画布游戏，启动进入大地图；不增加HTML游戏UI或安装说明弹窗。沿现有离线缓存和存档机制，未加载过的资源不承诺离线可用。安装入口与显示由浏览器提供，实际安装未作本轮运行验收。
