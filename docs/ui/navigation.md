# 全局导航与画布布局

[UI 索引](../ui.md) · [数字显示](numbers.md)

共 9 个页面。首次进入打开庄园的田地页。底栏有 5 个常驻入口，另有 4 个二级页面。页签和 Dialog 在所属页面内打开。

庄园首页的「田地／畜牧／鱼池／矿洞」保留普通页签样式。矿洞使用`#/farm?tab=mining`直链，前后进与方向切换保留页签、筛选和弹窗。

含「全部」的紧凑筛选组各占一行，包括工坊和配方选择、仓库和图鉴，以及研究查找节点的来源筛选。组内按钮等宽，整组铺满与相邻内容相同的可用宽度，首尾按钮分别与相邻内容的左右边缘对齐。标签以 15 逻辑像素为基准单行显示，按钮间距 2 逻辑像素，命中高度至少 44 逻辑像素。320 逻辑像素竖屏下仍保持单行和边缘对齐。

常驻页显示金币与右上角齿轮图标。研究的「品质」和「经营改良」显示高级研发点余额。出售庄园显示预计获得的点数，含点数奖励的任务显示对应额度。进入二级页时底栏收起，顶部显示页面标题和纯图形返回按钮，不显示「返回」文字。所有方向、展开和翻页箭头由图形绘制，不使用小于号、大于号或其他箭头文字。跨页跳转到具体物品或研发节点时，打开目标所在页签并定位到该项。返回时恢复来源页的筛选与滚动位置。

页面与主操作页签使用 URL 片段，例如 `#/research?tab=quality`。图鉴与研发的指定品项可附加 `item`。浏览器后退和前进恢复本次打开游戏期间访问的页面、主操作页签和弹窗。弹窗的数字输入与筛选保留在当前游戏会话中。重新打开链接时恢复页面、页签及品项，已失效的确认窗口回到所在页面。

### 返回上级与来源

App 内的返回按钮和 Escape 按显式上级返回，不以浏览器历史前一项代替。进入页面时记录来源页面、页签、物品、弹窗、筛选、用途展开、滚动和研究视口及其父链；多入口图鉴、设置和物品详情分别恢复本次进入的实际来源。目标主页面若从详情跨页进入，也要提供实际可点的返回入口；正常底栏跳转为根页面并清理来源链。

图鉴列表进入详情时保存列表原筛选和滚动；详情的材料／用途再进入另一物品时保存上一物品完整快照。返回优先当前弹窗的父弹窗／来源页，再本页物品父层，最后页面父上下文。外部直接进入某物品详情时不虚构一个先访问过的图鉴列表。研究从外部打开指定节点详情时，该首个详情关闭返回来源；本页正常选择的新节点关闭后留在研究页。

浏览器前后进单独保留各历史条目的父上下文，不让筛选或页签修改干扰 App 上级。无来源直链采用明确兜底：图鉴和出售庄园到经营，设置和任务到庄园。导入、清除存档及成功出售庄园时作废旧父引用和确认弹窗。

竖屏画布铺满视口，交互控件避开系统安全区。横屏游戏区以 390:844 限制最大宽度，居中显示，两侧纯黑且不响应游戏操作。方向切换保留当前页面、选项、数量输入和 Dialog。游戏画面、点击区域、数字键盘和反馈均在同一个 PixiJS 画布内。

### 画布样式

暖米色背景与圆角卡片，文字使用深绿，分隔线使用浅棕。选中页签为绿色，选中底栏项为浅绿色，各底栏图标使用相同绘制区域。购买与播种采用绿色，升级及重要确认采用金黄色。画布图形与字体边缘平滑，所有像素贴图采用最近邻采样和像素位置对齐。

### 数字区域

顶部金币使用独立数字区域，设置齿轮的可见按钮与金币块等高，命中区域保持可触达。窄屏自动缩小金币字号，点按余额可查看完整整数。所有页面装饰横幅紧贴顶部导航；设置页标题在游戏区水平居中。页签之间不画分割线，庄园与图鉴的一级页签滚动时吸附顶部。游戏区内的宽度测量以 PixiJS 实际字形为准。
# 滚动

可滚动容器的半透明滚动条贴右边缘，不占内容宽度。滑块随可见比例改变长度，支持直接拖动。手指或鼠标滑动内容后，松手保留惯性并逐步减速；到达边界、切页或再次按下时停止。弹窗只允许内容区滚动，标题栏和底部按钮区始终固定。
