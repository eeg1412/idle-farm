# 全局导航与画布布局

[UI 索引](../ui.md) · [数字显示](numbers.md)

共 9 个页面。首次进入打开牧场的田地页。底栏有 5 个常驻入口，另有 4 个二级页面。页签和 Dialog 在所属页面内打开。

| 页面 | 层级与入口 | 返回或切换 |
| --- | --- | --- |
| 牧场 | 首页，底栏「牧场」 | 底栏切换 |
| 工坊 | 底栏「工坊」 | 底栏切换 |
| 仓库 | 底栏「仓库」 | 底栏切换 |
| 研究 | 底栏「研究」 | 底栏切换 |
| 经营 | 底栏「经营」 | 底栏切换 |
| 任务 | 首页任务卡、经营页 | 返回来源页面 |
| 图鉴 | 经营页、仓库或研究详情的图鉴入口 | 返回来源页面 |
| 设置 | 右上角齿轮图标 | 返回来源页面 |
| 出售牧场 | 经营页「出售牧场」 | 返回来源页面。出售成功后回牧场的田地页 |

常驻页显示金币与右上角齿轮图标。高级研发点只在研究的「经营改良」和出售牧场相关内容中显示。进入二级页时底栏收起，顶部显示页面标题和「返回」。跨页跳转到具体物品或研发节点时，打开目标所在页签并定位到该项。返回时恢复来源页的筛选与滚动位置。

页面与主操作页签使用 URL 片段，例如 `#/research?tab=quality`。图鉴与研发的指定品项可附加 `item`。浏览器后退和前进恢复本次打开游戏期间访问的页面、主操作页签和弹窗。弹窗的数字输入与筛选保留在当前游戏会话中。重新打开链接时恢复页面、页签及品项，已失效的确认窗口回到所在页面。

竖屏画布铺满视口，交互控件避开系统安全区。横屏游戏区以 390:844 限制最大宽度，居中显示，两侧纯黑且不响应游戏操作。方向切换保留当前页面、选项、数量输入和 Dialog。游戏画面、点击区域、数字键盘和反馈均在同一个 PixiJS 画布内。

### 画布样式

暖米色背景与圆角卡片，文字使用深绿，分隔线使用浅棕。选中页签为绿色，选中底栏项为浅绿色，各底栏图标使用相同绘制区域。购买与播种采用绿色，升级及重要确认采用金黄色。画布图形与字体边缘平滑，所有像素贴图采用最近邻采样和像素位置对齐。

### 数字区域

顶部金币使用独立数字区域，字号和位宽独立于「设置」按钮。窄屏自动缩小金币字号，点按余额可查看完整整数。列表标题区、底栏和主要操作保留可点击空间。游戏区内的宽度测量以 PixiJS 实际字形为准。
# 滚动

可滚动容器的半透明滚动条贴右边缘，不占内容宽度。滑块随可见比例改变长度，支持直接拖动。手指或鼠标滑动内容后，松手保留惯性并逐步减速；到达边界、切页或再次按下时停止。开启减弱动态时，松手即停止。
