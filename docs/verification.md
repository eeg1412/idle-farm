# 验证

以下是取得用户明确授权后可执行的验收流程。当前开发期间不运行测试、预览或试编译。编译由主管在模块完成后执行一次。

```sh
npm run check
npm run build
node scripts/simulate-balance.mjs
codex execpolicy check --rules .codex/rules/project.rules -- git push origin main
```

浏览器验证使用 320、390、480 逻辑像素宽的竖屏，以及横屏。检查页面只挂载一张画布、横屏两侧黑边、旋转后仍停留在当前页面。

发布候选版先用新浏览器档案打开站点首页。等离线缓存安装完成后普通刷新两次，确认首页和存档正常加载。在线打开 `/index.html` 时允许站点重定向到首页。断网后刷新首页应由离线缓存加载；复网后普通刷新应加载线上版本。用已安装旧离线缓存的档案再执行一次，确认旧缓存能自动替换。

经营烟测路径为等待小麦收成、安排面粉、预留小麦、研究面包、继续磨粉并安排面包、出货与购地。提前出货可满足后续任务。完成六项后打开任务确认长期目标，刷新后核对金币、库存和任务。使用第二个标签验证过期修订不可覆盖新记录。生产构建下可离线重开；计时以已结算锚点计算，初始上限 2 小时。

出售牧场烟测覆盖0点出售、达到1,000产值后的奖励与经营评估倍率。确认后检查回到田地、金币恢复为60、加工位和精制位各重置1空闲工位，研发与任务进度保留，再刷新核对奖励、工位重置与任务状态。

正式验收使用 [式样书第 11 节](game-design.md#11) 和 [界面与交互规格](ui/qa.md)。未接入的正式玩法以架构文档为准。

用网络面板确认游戏内列表仅在图标进入视口时按需请求 WebP。构建产物的预缓存清单中应无 PNG 原图或 WebP 图标。

科技树验收覆盖单指和鼠标拖动、双指捏合和滚轮缩放、节点索引定位、拖动释放时不触发详情，以及浏览器前进后退。对照完整研发条件核对棉花 → 原棉纱 → 棉布巾盒等依赖。品质仅显示已解锁品项，高级研发点仅出现在经营改良与出售牧场。选择棉花播种后，核对独立图标和仓库产出。按 [新增研发路径](expansion/08-crop-uses.md) 核对工坊的图标及配方。
