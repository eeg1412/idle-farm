## 生成与生效

1. 沿用账户种子、有效当地日和重置序号，先从排序后的已解锁名单均匀无放回抽选，名额沿用 `max(1, floor(已解锁数/10))`。
2. 对所有入选品项抽方向。市场推广等级为 P 时，上涨阈值为 `5,000+100P` 基点，下跌取补集。0 级为 50%／50%，10 级为 60%／40%。
3. 对所有入选品项抽绝对幅度。19 张票中 0% 一张，10% 至 90% 每档两张。0% 仍占名额、按原价且隐藏标记。下跌保留原负幅。上涨抽得非零正幅 a 时，保存的上涨百分比为 `floor((a×(90+11L)+45)/90)`，L 为溢价销售等级，四舍五入至整数百分点。满级原 +10% 成为 +22%，原 +90% 成为 +200%。

本轮真实完工产值达到 100,000 且当天尚无行情时，按当时已解锁名单和两项科技等级生成首次行情，序号为 0。操作前推进时生成的行情使用购买前等级。跨日首次生成或使用市场操纵额度递增序号重抽时读取届时等级。购买两项新科技保留已生成的当日行情，同日周回再达门槛时恢复该行情。

出货按当前品质单价与已生成的倍率报价，报价变化时按原确认流程处理。真实完工产值继续按完工时品质价计入，活动权益沿用现有完工与评估口径。

预测以当前已解锁名单、两项科技等级、同一账户种子、下一有效当地自然日和序号 0 使用同一生成逻辑。预测只读；这些输入一致时，预测与次日首次盘逐项一致。

## 存档与验收

`rates` 沿用有符号整数百分比。校验接受 −90% 至 0% 的既有 10 个百分点档位，以及溢价销售 0 至 10 级全部可生成正档的并集。已生成的行情可来自较低科技等级，校验与恢复直接读取保存值。旧档缺少两项科技时各按 0 级处理，沿用现有存档、交换及权益账本版本。

| 验收 | 通过条件 |
| --- | --- |
| 研究入口 | 品质只显示普通余额；市场组在全图和查找中均有四项；五项科技各显示专用图标及简短效果；代管详情的效果区只显示离线时长 |
| 市场费用 | 四项市场科技逐级按表扣高级点，首级分别为 60、50、30、40，共 28,060 点满级 |
| 三轮确定性 | 同种子、日期、序号、名单下两科技为 0 级时逐项等同旧版；单升市场推广只改变方向阈值，单升溢价销售只拉伸正幅；0% 概率固定为 1/19 |
| 生效与报价 | 升级操作前的推进使本轮产值首次达到 100,000 时，首次行情使用购买前等级；生成后买科技，已生成的倍率和出货报价保持；实际价格变化按现有规则重新确认 |
| 周回、重置与跨日 | 当日生成行情后出售牧场，在新周回未达门槛时买科技，同日再达门槛恢复购买前的行情；用额度重置或次日首次生成应用届时等级 |
| 预测 | 升级或解锁后预览使用即时输入，次日生成输入一致时逐项相同，重置额度与当日序号保持原值 |
| 旧档与新档 | 旧档保留科技、已生成行情及全满领取记录；新档可保存、重载及同日导入 +200%，溢价销售已至 10 级的档仍能读回此前生成的 +11%；拒绝 +23%、+201% 与超上限的科技等级 |
| 全满奖励 | 未领档累计 1,124 级时发 7,000,000 金；已领档继续显示完成、已到账，奖励金额隐藏、余额无补发 |
