# 极小牲畜静态审图

范围为中华蜜蜂 L13 与家蚕 L29。现役棚舍、活体选择图和家蚕进食帧用于对照色块、轮廓及动物身份。蜂箱、蚕架和四格飞蜂由内置 image_gen 生成，提示词与复现路径见 [素材记录](../../assets/livestock/tiny/prompts.md)。

| 用途 | 静态审阅 |
| --- | --- |
| 蜂箱原画与 320×320 背景 | 木纹、边缘与现役棚舍使用同类离散像素色块。蜂箱入口清楚，右侧保留飞行与产物空间。 |
| 飞蜂原稿、64×64 帧及透明图集 | 四帧保留同一蜂身，翅膀由抬起到后压。静态放大图可见独立翅姿，正常底色未见可见邻格污染。 |
| 蚕架原画与 320×320 背景 | 两层托盘清楚。家蚕靠各自固定脚位停留在托盘内，独立桑叶贴近低头帧口部。 |
| 蜂箱、蚕架同 ID 资料图 | 320 像素和 130 像素下可辨认设施及活体。资料图为日常状态，完工示意图在设施旁另外合成现役蜂蜜与蚕茧图标。 |
| 130 像素完工静态合成 | 蜂蜜最终底部落点为 (230, 269)，避开近处飞蜂，下缘程序影与蜂巢暗孔可辨，和暖黄地面的色差偏低。蚕茧在蚕架右侧清楚可辨。 |

证据图仅本地保存，路径和 SHA-256 见 [清单](2026-11-28-tiny-livestock.json)。执行 `node assets/livestock/tiny/export.mjs` 可重制素材和证据。静态合成取代表性的飞蜂和进食姿态，真实飞行、翅动、取帧、批次提示和交互未做浏览器验证。

## 六只与铺叶版复查

已打开新版铺叶原稿、托盘合成背景、两张发布详情图及 320 和 130 像素分镜。蜂箱附近的六只蜜蜂从入口向右侧草地展开，个别相位两只距离较近。双层托盘由后缘至前缘连续铺桑叶，框沿可辨。浅色家蚕每层三只，六只都落在叶面，身体比例由 0.36～0.42 降至 0.16～0.21，约为原来一半。口部桑叶层与整层叶面衔接。

活动画面与资料图均消费同一份六只布局。现役蜂蜜及蚕茧仍按原落点显示。本次静态独审通过，浏览器运行未验证。
