# 庄园五组布局独立审图

> 术语更名（2026-11-28）：文中建筑「加工」现称「料坊」，「精制」现称「工房」；加工位、精制位现称料坊位、工房位；「工坊」现分别指料坊或工房。

2026-11-18。以 Sites v49 源码 `6f87040` 为基线。使用发布 WebP 与[最终布局参数](../../src/view/estate-map.js)静态合成 320 × 568、390 × 844、414 × 896 三种视口，复看首屏、海湾、滚动底端及整图。修订复审通过。

| 位置 | 审图结果 |
| --- | --- |
| 经营、任务 | 经营厅在左，任务板位于右侧较低处。任务板可见宽度由地图宽的 36% 降至 20%，320 px 宽时约由 115 px 降至 64 px，任务提示和门牌仍可辨读。 |
| 畜牧、田地 | 畜牧靠左上，田地在右下，占地图宽 51%。弯道穿过围栏间的地带，花树和矮石收住草地边缘。两处主要设施填入各自场地，留白未跨组连成大片。 |
| 鱼池、矿洞 | 右缘仅在鱼池附近形成一处海湾。环石淡水塘在沙岸内侧，塘水与海水隔着连贯干岸。木栈桥越过岸线，海浪透过两座网箱。矿洞在左侧岩壁下，矿轨外的步道可继续向南。 |
| 加工、精制 | 右侧加工坊在前，左侧精制坊稍低。两座建筑分居弯道两侧，主路穿过两坊之间。 |
| 研发、仓库 | 仓库居右上，研发楼居左下，建筑和门牌在三个尺寸的底端画面均完整。落脚处有草地，主路从研发门牌右侧继续延伸至底边。 |

初版畜牧和研发门牌遮住部分主路，经营和矿洞门牌贴着路缘。四处门牌向左侧草地调整后，重新用最终布局和发布图合成检查。主路从入口到地图底端连续可辨，建筑分布由弯道、草地、树丛和岩壁串起。

逐张读取十个建筑 WebP 中 Alpha ≥ 128 的外接矩形，均与源码登记一致。按[画布坐标与固定 HUD](../../src/view/canvas-ui.js)计算入口、任务提示和设置的扩大点击框，三个宽度下十处入口均在地图内，两两无正面积交叠。初始滚动位置在顶部安全区 0 px 与 47 px 时均无入口压到 HUD 或设置扩大点击框。47 px 安全区下，金币栏底边为 y=95，任务提示上边分别约为 y=101.2、128.5、137.8。整图高分别为 880、1073、1139 px。

合成使用动件的静态采样姿态和按源码尺寸复绘的 HUD。点击、拖动、连续动画和真机画面由运行验收覆盖。
