## 作物与矿洞静态结论

C69–C73 V2 单株保留透明的完整冠顶与独立根脚，C71/72、C72/73 较窄行距的导出单株未见邻行片段。九排 44 根固定种植点沿同一底图田垄展开，四阶段共用落点，远端冠顶保留余量，左右边缘由画框自然裁切。130×138 近排种子最宽约 5 像素，远排种子较难辨认。对照本轮 320 像素分镜及原作物尺寸，种子属同量级的小纹理。五张 V1 独立设施图在原画及 WebP 的 320 像素与 130 像素展示中，杉树分层针冠、马尾松伞束、香樟团冠、桢楠纵长密叶与檀香疏阔冠形可辨。[单株来源与分格](../../assets/plot/crop-atlases/C69-C73/prompts.md)

M11–M30 的 320×320 PNG 和发布 WebP 在 130 像素接触图中使用相同的洞口、矿车、车轨和装载位置。货载颜色和形态对应同 ID 仓库图，灰白原料、黑片状石墨、各色晶体和金属矿均在卡片上可分辨。真实矿车通过洞口、动态装卸及短批场景仍待运行证据。

## 水产静态结论

逐鱼查看三期各四帧的正常底分镜、实际发布图集合成、32 像素选择和 130 像素场景。F11–F20 使用河塘，F21–F30 使用海塘。分镜中躯干在共同的锚线附近，尾瓣、鳍或柔长身躯产生局部姿态变化。130 像素图可分辨一、二、三只及远小近大。F25 的成熟期格间距较窄，正式分镜上的尖吻与尾叉保留。真实水波、四层挂载、短批展示和淡出再淡入未验证。[水产生成与返修来源](../../assets/fish/prompts-expansion-2026-11-28.md)

F13 青鱼 v1 的高背轮廓过似鲫鱼，v2 改为细长低背和青黑大鳞。F20 河鲀 v1 的高背鳍及腹下鳍构图过似鲤科，v2 采用圆腹、短吻和靠尾的矮背鳍。F22 带鱼 v1 银身粗短，v2 邻格鼻尾在横向交错，v3 收低背鳍、延长渐细尾部并留出透明格间距。F22 v3 深浅正常底与正式分镜中未见黑底查看器呈现的色点和残边。F23 大黄鱼与 F24 鲭鱼 v1 高背初稿由素材所有者先退回，v2 的大黄鱼有金黄腹与双段背，鲭鱼有银腹、青波纹、双背鳍和尾柄处小离鳍。五项修订均以精确正式成品复查通过。

## 畜牧静态结论

L11–L30 逐种看了实际进食原稿、当前成年或成熟姿态、正式 96 像素及 32 像素选择成品、棚舍 130 像素分镜、固定脚点和同 ID 设施 PNG/WebP。11 种附属产物动物采用成年四帧，9 种肉类动物为幼年、成长、成熟各四帧。分镜中支撑脚与躯干位置相近，低嘴独立标给嘴部，脚区不依赖嘴框豁免。进食的低头、抬头、张口变化发生在头颈和口部。L13 中华蜜蜂口器接近花心，L29 家蚕低头接近桑叶，专用花和叶在 130 像素下可辨。本轮专用饲料只登记给这两项。其余棚舍场景使用共享饲料图。真实画布里的口部相位、程序地影、产物与位置连续性未验证。[本轮畜牧生成与来源](../../assets/livestock/feeding-prompts-expansion.md)

L28 巴马香猪 v1 身体以大块平涂为主，肩胛、腿蹄及鼻脸层次不足。v2 保留黑头黑尾和奶油色肩带，三期补清晰离散明暗与关节、脚蹄、鼻孔和脸部层次。正式分镜未见邻格污染或耳尾缺损，饲料位置固定。新活体图来自 v2 成熟 0、3 帧，抬头站立且 32 像素下仍可辨肩带、卷尾和猪鼻，复查通过。[L28 v2 原稿](../../assets/livestock/raw/l28-expansion-feeding-v2.png)

L29 成年第 2 帧的低嘴局部范围复查至 x158–207，支撑脚区 x 上限为 153。6 倍正常底局部与更新分镜显示头部左沿和口器落在局部范围内，区间内未见烘焙地影。正式纹理沿用同一版。
