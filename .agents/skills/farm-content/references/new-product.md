# 新商品（P / PL / PF / PD / PT）工作流

共通规则、研发声明、图标、分工见 [SKILL.md](../SKILL.md)。只有物品图标一项美术；规格见 `docs/assets.md`「物品图标」，验收用 [farm-art-review](../../farm-art-review/SKILL.md)。

## 0. 输入决定（目录所有者，冻结后下发）

| 类别 | 允许的投入（只能是中间产物） | 来源数 s | 冻结长度 |
| --- | --- | --- | --- |
| `P` 农业商品 | 仅 `I` | 1 | 150 |
| `PL` 畜牧商品 | 仅 `IL` | 1 | 20 |
| `PF` 水产商品 | 仅 `IF` | 1 | 20 |
| `PD` 双类商品 | 恰好两个行业的中间产物 | 2 | 20 |
| `PT` 三类商品 | 三个行业的中间产物都有 | 3 | 50 |

| 项 | 规则 |
| --- | --- |
| ID | 该类别最大编号 +1（现为 P181、PL21、PF21、PD21、PT51） |
| 名称 | 不与已有物品重名；逐件带包装（盒、杯、袋、瓶、礼盒） |
| 基础周期下界秒 s | 1–43,200 整秒，参照同期品项及 [工时公式](../../../../docs/expansion/07-balance-validation.md) |
| 等级 | `3×(档位−1) + s`，档位为 1…10。P/PL/PF 取 1…28，PD 取 2…29，PT 取 3…30。参照含料工时相近的已有商品取档 |
| 研发前置／耗材 | 前置 = 全部投入（可加一个同线前序商品，如 PT50 要求 PT49）；耗材种类通常 = 投入 |

已有品项不得改用本项作投入。

05 填周期下界 s。生成器用供料、直接上游周期与同窗要求解最短实际周期，最长 43,200 秒。

## 1. 式样（目录所有者）

1. `docs/expansion/05-catalog.md`：P 追加到「## 农业商品」P180 后；PL/PF 到「## 畜牧与水产商品」各自末行后；PD/PT 到「## 复合商品」各自末行后：
   `| <ID> | <名称> | <s> | <N×ID + …> |`
2. 说明表：PL/PF → `03-single-sector-products.md`，PD/PT → `04-mixed-products.md`（4 列 `| ID | 名称 | 每批输入 | 基础秒数 |`，基础秒数填 05 的周期下界 s）；农业用途 P → `08-crop-uses.md` 用途说明。
3. 等级：在 `08-crop-uses.md` 的 `| 商品 ID | 商品等级 |` 表追加 `| <ID> | <等级> |`。每类从冻结长度 +1 起连续（P151…已有，P181 接上；PL21、PF21、PD21、PT51 起），表内不留空行。
4. `docs/expansion/06-research.md`：P 追加到「## 农业商品」，其余到「## 新商品」同类末行后：
   `| <ID> | <名称> | <投入ID、…> | <耗材ID、…> |`
5. `kindCounts` 对应类别 +1；计数文字（README、08 第 8 行、07 §7.1/§7.5 与新增 ID 记录、01）。

## 2. 生成（需授权）

`npm run content:generate`。核对：`sources` 与类别一致，`level` 与 08 登记相符，两项价格下限符合 E-06，实际周期与吞吐符合 E-31，最终研发报价符合 E-12、E-14。

## 3. 图标（物品图标所有者，唯一；在第 2 步之后导出）

与中间产物相同：imagegen 透明网格原稿 → 96×96 透明 `assets/source/items/overrides/<ID>.png` + `overrides.json` → 图标导出器 → `public/wiki/icons/<ID>.webp`；不改 08 图标格序。商品须可辨包装并露出内容；精制产线消费该图，未交付前不发布该配方。

## 4. 审图（farm-art-review）

按「物品」用途审包装形态、内容辨识、透明边缘与 96px 可读性。

## 5. 视图接入（可选）

农业用途 P 在 `src/view/research-page.js` 的 `cropUseRanges` 追加 `['P', <n>, <n>]`。其余（精制选择、仓库、图鉴等级徽章、研究树、精制科技）按 `sources` 自动覆盖；任务 `milleCrepe`、`threeSectorGift` 不改，「完整图鉴」目标随总数自动增加。
