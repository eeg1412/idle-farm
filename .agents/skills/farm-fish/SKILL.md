# 鱼类与鱼池动画

项目路径以仓库根目录为基准。按本次任务读取 `docs/expansion/02-livestock-fish.md` 的鱼种、`05-catalog.md` 的产出、`06-research.md` 的研发条件，以及 `docs/development.md` 的鱼池动画规则；当前进展与未验收项查 `docs/feedback-checklist.md`。新增 ID 先改式样与生成数据，保留原有 ID、BigInt 经营数量和旧档兼容。

新增或改画前读取[按鱼种交付](references/delivery.md)。按目录全部 `kind: F` 覆盖，分别交付仓库物品图、独立透明活鱼选择图、同 ID 静态设施回退及完整动画；不能以静态图、仓库渔获图或缩小鱼塘代替活鱼与三期 idle。

每种鱼在 `layout.species` 显式登记海／河 `habitat`，选择两套固定背景之一；按 `size` 分小、中、大，对应三、二、一只，近处较大、远处较小。运行画面分为背景、鱼、水色透明层、程序动态水波四层，水面区域由对应背景 metadata 登记，不能涂到岸上。鱼苗、成长期、成熟期各有独立原画与 idle，成熟鱼淡出后再淡入下一周期鱼苗；展示数量与时序不制造经营事件。保底周期、帧时长与淡变按最新任务卡和运行实现记录，不把本轮参数写成用户已确认的永久数值。

原画由一名素材所有者使用 `imagegen` 技能调用内置 `image_gen` 生成，透明小素材按隔离的 5×5 网格交付。导出器只裁切、登记固定身体锚点、合成和转换，不用同一张静态鱼缩放冒充三期或 idle，不逐帧按 bbox 重居中掩盖跳动。画风对照任务卡已认可参考，保留鱼种形体、鳍尾与花纹；不能靠拟真图降采样、滤镜、提示词或帧数证明像素风与连贯性。

使用 PixiJS 单画布、最近邻贴图及同 ID 静态回退；仅可见活跃鱼池挂载，滚出、弹窗、切页、后台时卸载。鱼池不沿用畜牧的 `slaughter`、产品淡入或地面脚印逻辑，也不恢复已删除的减弱动态功能。海河背景、水色层与动态水波不参与鱼体淡变。旧单一 `pond` 只保留历史来源，不作为活跃加载或交付依据。

将精确版本源图、PNG／WebP、布局与用途交给 [farm-art-review](../farm-art-review/SKILL.md)。源图、成品和实际画布分别记录；不合格退回素材所有者修订，缺少证据保持待复查，技术门禁通过不代表画风或真实循环通过。

普通文档和源码读写、图片生成转换属于交付工作。本技能不授权测试、预览、`--check`、`quick_validate`、语法／运行检查或编译；遵守 `AGENTS.md` 的当前授权，最终编译只由 PM 在交付齐备且取得适用授权后执行。推送另需用户针对当前推送的明确指示。
