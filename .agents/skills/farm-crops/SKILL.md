# 作物与田地动画

下述项目路径以仓库根目录为基准。先读 `AGENTS.md`、`docs/development.md` 的作物成长动画段落，以及本次涉及的 `docs/expansion/05-catalog.md` 和 `docs/expansion/06-research.md`。新增作物先编辑式样再生成运行数据，保持旧 ID、BigInt 经济及存档兼容。

新增或重画时读取 [交付清单](references/delivery.md)，核对每个目录 `kind: C` ID 的图标、独立设施场景和四期动画。除 C01 已认可例外外，树和苗必须交付独立单株文件，运行时每个根位各建一个 Sprite，可共享同阶段纹理；整田合成图不能代替这项交付。

遵循 `scripts/export-crop-animation.mjs`、`assets/plot/crop-layout.json`、`src/content/crop-harvest.json` 与 `src/content/crop-visuals.json` 的真实单株导出链。四期及连续采收共用同一组固定根位，中、大型按 `crop-layout.json` 的 `fieldGeometry` 实测田面透视布植：列平行于田地左右侧边并汇向其消失点，排沿实测田垄脊线、排距平滑递增不跳变，铺满可种田面直到画面左右与近端边缘，边缘植株允许被画框裁切，远端树冠不被上缘截断，根脚不出实测土面轮廓。近端根脚离土面下沿至少 1/4 当地排距（不少于 8px）；贴边或落草的点沿所在列向远端后收（与同列前株至少隔半排），后收仍不够的外侧少数点沿田垄向田内最多平移 0.35 列距，不整列内缩，确实放不下才剔除并报告；参数与理由登记在 `fieldGeometry.nearEdge`／`sideEdge`。每排都有作物，不能用手标田垄端点当列边界、为避裁切空出边缘、只在两列窄条种植或用跨排贪心间距筛掉整排；小型沿用 `furrows.json` 原根位。近大远小，前排整株可遮住洒水器和水花。成长期和成熟期保留该品种整株特征，收获物画在植株上。**C01 沿用 `assets/plot/wheat/wheat-0.png` 至 `wheat-3.png` 的已确认整幅前景与旧图集**，不改原麦、不虚构 C01 单株目录。

已有真实四期单株原画可以复用，布局调整和格式转换不要求重画。只有新增或真正改画源图时才使用 `imagegen` 技能调用内置工具。保留源图和裁切依据；若替换种子／幼苗原画，同步实际读取路径，不能只存新图却仍发布旧的自动生成图。Python 兼容入口现已转发同一 Node 单株导出链，不另建 Pillow 整田回退，也不能恢复已淘汰的 C02 起整田运行前景。

每种作物由人工审图后的 `crop-harvest.json` 显式分为 `wholePlant` 或 `retainedPlant`，同时登记实际采收部分。先看真实 growing／mature 原画，再决定能否复用成年无果／无花植株；不能仅按名称、ID、图片存在或 growing 阶段名猜定，更不能把小苗放大充成年树。需要补画的 bare 原图先完成源图与实际尺寸配对审阅，未获对应素材结论不发布正式运行 metadata。

生成交付后，将精确版本的源图、对应 PNG／WebP 与用途证据交 [farm-art-review](../farm-art-review/SKILL.md) 验收。证据不足记待复查；实证不合格交素材所有者用 `imagegen` 重画／修订，再审新版本。技术门禁通过不代表视觉通过。`assets/plot/reviews/` 等证据图在本地生成供审阅，不提交；`docs/art-reviews/` 报告与 json 证据清单照常提交，记录本地路径与 sha256 并注明“证据图仅本地保存”，新环境用 `scripts/export-crop-animation.mjs` 重新生成。

展示周期跟随真实批次时长，无保底；短批次三档（每阶段至少 1 秒）：真实时长够全部阶段加 1 秒时完整播放，只够首末两阶段加 1 秒时只播首、末阶段，再不够只显示最后阶段。整株采收每轮四期，成熟末尾全株 300ms smoothstep 淡出并留空 30ms；保留植株采收只在首次种植／换种时走四期，第二轮起保留成年 bare 基底，在无采收部位与成熟状态之间过渡，不全株淡出或重回小苗。首次阶段依据持久 `facility.planting`，同种续批、升级和读档不能重置；旧档无法证实首次日期时直接进入成年采收。展示不改变实际产量、批次或任务事件。

仅为可见的活跃地块创建动画，按需加载、最近邻绘制；滚出、切页、后台与弹窗底板完全遮住时卸载，普通弹窗打开时背后可见的动画继续播放。失败使用同 ID 独立设施场景，保持单画布命中，不恢复已删除的减弱动态。源图／静态布植交接图、运行逐根 Sprite 和实际画布验收分别记录；本轮大型漏排、对齐与铺满的旧完成结论已撤销，不能因改为单株或交接图存在便结案。后续再次报告时同样重开，并将实际证据和限制写入持久反馈。

遵守项目验证授权：本技能不授权测试、预览、`--check` 或试编译。未取得用户明确授权时不执行这些操作；全部资源和模块完成后仅由主管执行最终构建。推送另需当前任务的明确指示。
