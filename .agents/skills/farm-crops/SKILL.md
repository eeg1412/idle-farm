# 作物与田地动画

下述项目路径以仓库根目录为基准。先读 `AGENTS.md`、`docs/development.md` 的作物成长动画段落，以及本次涉及的 `docs/expansion/05-catalog.md` 和 `docs/expansion/06-research.md`。新增作物先编辑式样再生成运行数据，保持旧 ID、BigInt 经济及存档兼容。

新增或重画时读取 [交付清单](references/delivery.md)，核对每个目录 `kind: C` ID 的图标、独立设施场景和四期动画。单有物品图或静态场景不得作为完整交付。

遵循实际 `scripts/export-crop-animation.py` 与 `assets/plot/` 布局。全部四期沿用 `furrows.json` 根位和共用天空、田地、洒水器；成长期和成熟期保留该品种整株特征，收获物画在植株上。**C01 沿用 `assets/plot/wheat/wheat-0.png` 至 `wheat-3.png` 的已确认整幅前景**，不要虚构 `assets/plot/crops/C01/` 原图目录。

新增和改画原画使用 `imagegen` 绘图技能，合成器依赖可用的 Python 3 与 Pillow。已有导出器会生成早期种子／幼苗；若任务要求替换早期原画，必须同步实际读取路径，不能只把新图存下来却仍发布旧的自动生成图。

生成交付后，将精确版本的源图、对应 PNG／WebP 与用途证据交 [farm-art-review](../farm-art-review/SKILL.md) 验收。证据不足记待复查；实证不合格交素材所有者用 `imagegen` 重画／修订，再审新版本。技术门禁通过不代表视觉通过。

展示周期取实际生长时间与 5 秒的较大值，均分种子、幼苗、成长、成熟四期。成熟末尾作物层 300ms smoothstep 淡出，留空 30ms 再到种子；短批次保留展示相位，实际收获与任务统计按经营逻辑结算。

仅为可见的活跃地块创建动画，按需加载、最近邻绘制；滚出、弹窗、切页、后台时卸载。减弱动效直接切帧且关闭喷水动态；失败使用同 ID 独立设施场景，保持单画布命中。

遵守项目验证授权：本技能不授权测试、预览、`--check` 或试编译。未取得用户明确授权时不执行这些操作；全部资源和模块完成后仅由主管执行最终构建。推送另需当前任务的明确指示。
