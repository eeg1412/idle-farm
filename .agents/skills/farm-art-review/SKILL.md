# 素材图片验收

本技能判断素材是否符合本次任务，不生成图片，不以内部审阅代替用户认可，也不扩大游戏验证或推送权限。路径以仓库根目录为准。

## 取得可判定的输入

从 PM 的任务卡取得：本次范围和例外、稳定 ID／对象与产品身份／阶段、已认可的风格参考及其认可来源、实际使用尺寸、原图与布局、输出规格及消费路径、待审版本和生成／修订来源。只读相关资料；缺少影响判定的输入时列明待补项，不自行猜尺寸、画风、阶段或用途。

按用途读取 [验收清单](references/checklist.md)。牲畜遵循 `farm-livestock` 的交付约定；作物遵循 `farm-crops`，保留已登记的 C01 整幅前景例外。设施场景可以有背景，导航、物品与动物分别按其规格审阅；不能把某类图的透明度、尺寸或阶段规则套给全部素材。

## 以图像证据判定

- 实际打开已认可参考和**精确版本**的源图、对应 PNG／WebP 成品；按实际使用尺寸看辨识度，再以最近邻放大看像素边缘。完整轮廓、格间隔离与透明边缘均需看图，不能只看提示词。
- 正常合成查看透明图；黑底查看器的低 Alpha RGB 可能显示红黄霓虹。必要时读取 Alpha／边缘像素，或向素材所有者索取正常合成证据，区分误显、实际残边与底色，不凭误显退回。
- 动画逐阶段对照四帧及固定地线分镜，查看身份、比例、躯干和解剖脚点连续性。表格数值相同不能证明无抖；只审静态分镜不能宣布真实循环体验通过。
- 技术证据与视觉证据分别记录：尺寸、格式、Alpha、字段、ID 映射及资产链可作针对性读取；文件存在、哈希、帧数、`pixel-art` 字样和自动检查通过均不能证明画风合格。

## 给出结论并闭环

每个 ID／用途／版本分别给出下列一种结论，保留证据路径和剩余项：

| 结论 | 使用条件 |
| --- | --- |
| 通过 | 本次该项必需证据齐全，视觉和适用技术项均满足规格；标明通过范围。 |
| 待复查／输入不足 | 缺参考、版本、成品、实际尺寸或动画证据，或修订尚未复查；不能算通过。可写“源图画风条件通过”，仍须列出未通过的成品项。 |
| 不合格退回 | 有具体图像／像素证据违反本次规格；填写 [退回单](references/rejection.md)，直接交 PM 与该素材所有者。 |

原画有对象、风格、轮廓、粘连或底色问题时交素材所有者按退回单重画；审阅者不私自脚本修画、补部位或替换为已有动物。裁切／格式转换不能掩盖原画缺陷。修订保留原稿、提示词和实际转换来源，以新版本逐项复查；未修复项继续打开，不能靠其他项通过抵消。

将结论写入本轮 `docs/art-reviews/` 报告，并向 PM 交付退回项和待证项，由 PM 更新持久反馈清单与实际接入状态。不能将“素材已存在”“源图通过”写成整批、运行体验或用户已认可。

## 权限

普通源图／PNG／WebP 查看、尺寸与像素读取属于图片审阅。遵守 `AGENTS.md` 的验证限制：本技能不授权测试、冒烟、浏览器预览、语法／运行时检查、试编译、`quick_validate`、`npm run art:check` 或同类检查；只有用户明确授权，或 PM 在全部交付齐备后执行最终构建流程时才按许可执行。未运行项如实记录。推送仍需用户针对当前推送的明确指示。
