# 素材退回单

有明确失败证据才退回；缺关键输入使用“待补”，不能用主观猜测要求重画。一次退回只针对明确版本与失败项，已满足部分写明保持不变。

```markdown
## 退回单 <任务编号-序号>

- 任务／范围：
- 判定：不合格退回
- ID／对象／阶段／用途：
- 精确文件／版本／来源（必要时哈希）：
- 已认可参考及本次失败条件：
- 证据：<看过的图像路径；行列、帧号或像素坐标；实际可见现象>
- 影响：<会被哪条消费路径使用、为何不符合规格>
- 保持不变：<画风基准、正确对象、已认可部位、棚舍、时序等适用项>
- 重绘要求：<只修明确失败项；需完整保留哪些部位／身份／固定解剖脚点>
- 接手所有者：<原画／导出所有者；同步 PM>
- 待交复查版本：<新文件版本、提示词／修订来源、对应成品与分镜>
- 复查结果：<待复查／通过／仍不合格；实际复查文件和证据；剩余项>
```

若错误来自裁切登记或错误消费资源，交相应所有者修复该路径；若原画本身错误，交素材所有者重画。审阅者不得私自脚本补画、抹掉有效轮廓、加滤镜或换成其他已有对象来关单。纯技术修复也必须按新版本看最终成品；不凭所有者口头报告结案。
