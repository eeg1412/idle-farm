# 按本次用途验收

先冻结任务卡与待审版本，再选适用项。没有给出的规则写“待补”，不从历史试稿参数推断统一尺寸、颜色数量或像素块大小。

| 项目 | 必须取得的证据与失败条件 |
| --- | --- |
| 身份和内容 | ID 对应正确对象、品种、成长阶段和产品。活动物、蛋／奶／肉、作物单株、设施与导航含义可区分；不能交错 ID 或用产出代替选择对象。 |
| 风格 | 并排看已认可参考和待审版本，核对形体、五官、羽毛／毛团／叶片分组、像素阶梯轮廓及离散明暗。按认可方向保留足够细节；避免被否定的拟真细毛、柔光渐变，也避免抹掉物种特征的粗块。画风不能靠降采样、滤镜或提示词自证。 |
| 完整性 | 看全幅与每个裁切格：角、耳、尾、脚、枝叶及产品外形完整，无遮挡或切断，无邻格主体、文字、网格线和多余物体污染。越名义格的部位必须在实际隔离裁切区域内完整保留。 |
| 背景和边缘 | 仅对要求透明的资源审 Alpha、正常合成边缘和内部孔洞：无实际可见底色、白雾、杂边或裁掉的有效像素。场景背景按该场景规格审；不能要求全部图透明。低 Alpha RGB 查看器误显不能单独构成失败证据。 |
| 用途和实际尺寸 | 在任务卡给定的手机／图块／导航尺寸看对象是否可辨，主要特征和轮廓是否仍清楚。源图放大好看不能代替实际尺寸；每个用途消费正确资源，不把设施缩小当动物图。畜牧动画与仓库应共用原物品图，物品图与活牲畜选择图分开。 |
| 连续帧 | 按任务规定阶段与帧数审完整序列。牲畜同阶段四帧身份、身体尺度、躯干位置和固定解剖脚点稳定，允许自然呼吸、眨眼等 idle 变化；查看 0→1→2→3→0 接缝，不用逐帧 bbox 居中或缩放掩盖跳动。没有运行循环证据时只报告源图／分镜层级。 |
| 地面阴影 | 本项目牲畜原画、透明帧、选择图和回退中的动物层不带烘焙地面椭圆影，复用原物品图也不烘焙程序影；动物与所有产物分别由独立程序地面影绘制。不要把自然蹄爪／羽毛轮廓当阴影，也不能把连续浅色椭圆当动物轮廓。其他类型按各自任务规定。 |
| 规格与资产链 | 原图、布局、裁切来源、PNG、WebP、稳定 ID、阶段、帧序及实际消费键一一可追溯；选择图、共用产出物品图、动画消费与设施回退等用途齐备，不能因用途不同要求另画动画产品。原图与发布文件格式、尺寸、透明方式按实际约定。技术读取只证明对应字段。 |
| 来源 | 原稿版本、生成来源、提示词、已拒稿及修订记录保留；说明使用的隔离／裁切／缩放／转换。不能把处理后的图冒充新画原稿，不能用无来源旧素材替代应重绘对象。 |

## 适用资源差异

- **牲畜**：以显式 `slaughter` 和阶段登记核对成年附属产品类、肉用三期；审活牲畜选择图、每期四帧、原仓库物品图在动画中的复用及同 ID 设施回退，不再要求独立 128px 产品。读取 `farm-livestock/references/delivery.md` 的脚点／共享尺度、真实脚印 `grounding` 和 `product: {icon,bounds}` 约定，核对动画与仓库使用同一 `public/wiki/icons/<ID>.webp`。动物影要更深且对应实际站立脚印，不移动动物帧迁就影子；肉品可见底边接成熟落脚点，跨收获保持，所有产物均有独立程序椭圆影并随产品显隐。尺寸和 Alpha 数值是当前实现选择，不当作用户已认可固定值；没有实际画布证据时，这些新视觉项保持未验收。共享棚舍与动物／产品地面影分层独立，不维护另一份固定 ID 名单。
- **作物**：按本次稳定 ID 核对物品图标、独立设施场景、四期植株和成长图集；读取 `farm-crops/references/delivery.md` 的原图、固定根位、阶段及可见区域规定。保留登记过的 C01 例外，不把牲畜四帧规则套到植株阶段。
- **物品／设施／导航**：按其身份、背景、使用尺寸、布局和消费路径审阅；完整设施场景与小图标各交各的，不推断它们需要动画或透明背景。

## 报告最小记录

写明任务／审阅日期、已认可参考、精确文件版本、ID 与用途、实际查看的图像、针对性像素／尺寸证据、判定及理由、退回单编号、缺失证据和复查触发条件。源图、导出成品、实际使用和用户认可分别记状态。仅经静态图片审阅时明确“未验证游戏运行与真实循环体验”。
